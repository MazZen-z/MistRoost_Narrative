# 框架 · 操作与输入方案

> 状态：🌿 成形（核心按键已定，个别键位/形态待细化） · 最后更新：2026-09-25
> 定位：多端发售（**手柄 + 键鼠**）的主角操作方案。目标：**简洁、现代、双端平权、不别扭**。
> 相关：[技术架构与实现路线](../../../MistRoost/程序设计准则.md#architecture) · [符咒系统](系统/00-核心-符咒系统.md) · [矿洞与战斗](系统/05-矿洞与战斗.md) · [岚气与岚兽](系统/01-岚气与岚兽.md) · [工具与生产加工](系统/07-工具与生产加工.md)

## 一、设计目标（已定）

1. **直接移动 + 两档瞄准**（已落地）：**平时不显示高亮**，工具直接作用于角色**面前那一格**；
   **按住 LB** 才进入瞄准模式——出现高亮格，摇杆/WASD 改为逐格挪光标（鼠标一动则跟光标走），角色原地不动。
   详见下面第「四点五」节。
2. **一个上下文键办大部分事**：`A` 管所有世界交互、`X` 管所有"使用"，把记忆负担压到最低。
3. **两个对称轮盘**：`RT` 工具轮盘、`LT` 符咒轮盘——取代星露谷主机版翻快捷栏的别扭手感。
4. **按场景切输入上下文**（UE Enhanced Input 多套 IMC push/pop）：走路 / 战斗 / 钓鱼 / 制符 / 菜单 各一套，复用同一批按键。

## 二、核心模型：两个容器 + 一个"手位"

- **工具小包**（专放工具/武器）：只经 **RT 轮盘**取用。
- **背包**（种子/料理/材料/放置物/礼物/符咒道具）：只经 **D-pad** 切栏(←→)/翻页(↑↓)。
- **"手位" = 单一激活位**，三处来源都会占用它：RT 装备的工具、D-pad 选中的背包道具、LT 选中的符咒（符咒**顶掉当前工具**占住手位）。
- **X = 使用手位物**（挥工具/武器 · 播种/放置 · 施放符咒）；消耗品用完后手位**回到刚才的工具**。
- **A = 世界交互**（不依赖手位）。

## 三、手柄映射（Xbox 命名）

| 输入 | 功能 | 状态 |
|---|---|---|
| 左摇杆 | 移动（默认小跑）；轮盘打开时＝选择 | ✅ |
| 右摇杆 | 固定视角下的受控取景／放置精瞄（形式待细化，不自由旋转Pitch/Yaw） | 🌿 |
| 方向键 ←→ | 切换背包栏位 | ✅ |
| 方向键 ↑↓ | 切换背包页 | ✅ |
| A | 世界交互：对话·拾取·徒手收获·睡觉·抚摸动物·搬运·送礼·确认 | ✅ |
| X | 使用手位物：工具/武器 · 播种/放置 · 施放符咒 | ✅ |
| B | 冲刺（带 CD 的短距位移，战斗中兼作闪避）；菜单＝返回/取消 | 🌿 形态待定（位移 / 跳跃）|
| Y | **待定**（原「岚兽指令：呼出／帮工／协战」随岚兽归档，**该键位失去对象**）| ❓ 需重新指派或释放 |
| RT（按住）| 工具轮盘 → 左摇杆选 → 松手装备 | ✅ |
| LT（按住）| 符咒轮盘 → 左摇杆选 → 松手就绪（占手位）→ X 施放 | ✅ |
| **LB（按住）** | **瞄准模式**：出现高亮格 → 左摇杆逐格挪光标 → `X` 对该格用工具；松开即退出。**工具蓄力也挂这个键** | ✅ 已落地 |
| RB | 快速切下一件工具；放置态＝旋转朝向 | 💡 建议 |
| R3（右摇杆按下）| 锁定最近目标 / 镜头复位 | 💡 建议 |
| Menu（☰）| 打开 MainUMG | ✅ |
| View（⧉）| 打开地图 | ✅ |

> 不设独立"奔跑"键——**默认即小跑**，`B` 提供带 CD 的爆发位移。

## 四、两个轮盘的交互（统一手感）

- **按住**扳机弹出轮盘 → 世界**减速**（好选、契合惬意基调）→ **左摇杆**指向扇区 → **松手即确认**。
- **RT 工具轮盘**：选中＝装备到手位，随后连续 `X` 使用。
- **LT 符咒轮盘**：只列**已画好的符**；选中＝就绪并占手位，`X` 施放。需要瞄准的符（爆破符对矿墙、**净秽符对 Boss**）＝选中后用 `X` 对目标格/目标施放。
- 键鼠：滚轮循环、数字键直选，或长按呼出同一轮盘（见第六节）。

## 四点五、两档瞄准（已落地，v0.1）

| | 不按 LB（默认） | 按住 LB（瞄准模式） |
|---|---|---|
| 高亮格 | **不显示** | 显示，落在目标格地面上 |
| 目标格 | 角色**面前一格**（随走随转） | 光标格，从面前一格起步 |
| 摇杆/WASD | 移动角色 | **挪光标**（角色原地不动） |
| 鼠标 | 不参与 | 一动就接管，光标格＝鼠标命中格 |
| 范围 | —— | 角色周围 `MaxAimRangeTiles` 的方形（默认 3 格） |
| 松开 | —— | 立刻退出，光标不保留 |

- **为什么角色会停**：按住 LB 时 push 一个高优先级的 `IMC_Aim`，把移动那根摇杆映射到 `IA_AimMove`，
  增强输入按优先级消费按键，角色的 `IA_Move` 自然收不到——**不需要改角色类**。
- **蓄力**（后续工具升级）同样挂在这个模式上：按住 LB 蓄力 → 松开或按 `X` 释放。
- 键鼠端的等价键 = **按住鼠标右键**（见 D-020），已写进 `IMC_OnFoot`。

## 五、输入上下文（Enhanced Input / IMC）

按场景 push/pop 对应 IMC，复用同一批 IA：

| 上下文 | IMC | 关键差异 |
|---|---|---|
| 徒步 | `IMC_OnFoot` | 上表全部 |
| 战斗（矿洞/Boss）| `IMC_Combat` | `X`＝攻击、`B`＝闪避、`LT` 战斗符、`Y` **待定**（原岚兽协战已归档）|
| 钓鱼 | `IMC_Fishing` | `X` 抛竿 → 小游戏（拉扯/节奏，待定）|
| 制符小游戏 | `IMC_Drawing` | 世界暂停，右摇杆/鼠标/触屏描线（见第七节）|
| 菜单 / MainUMG | **v0.1 不用 IMC** | 面板打开＝`UIOnly` 输入模式，导航交给 Slate；关闭键在面板的 `CloseKeys` 里配（Tab / Esc / 手柄 B）。`IMC_Menu`（`LB/RB` 切页签、`A` 确认、`B` 返回）留到 0.2 再上，届时改走 GameAndUI。见 D-019 |
| 放置家具/设施 | `IMC_Placement` | 右摇杆移动落点、`LB/RB` 旋转、`X` 确认、`B` 取消 |

- **IA 清单**（接到 [02](../../../MistRoost/程序设计准则.md#architecture) 已有的 `IA_Move`）：
  **资产已生成**（`Content/MistRoost/Input/`，2026-09-13）：`IA_Move`、`IA_UseHand(X/左键)`、`IA_AimMode(LB/鼠标右键，按住)`、
  `IA_AimMove(左摇杆/WASD，仅在 IMC_Aim 里)`、`IA_Interact(A/E)`、`IA_Menu(☰/Tab)`、`IA_HotbarSlot(数字键 1-9，每键一个 Scalar 修饰符)`、`IA_HotbarCycle(滚轮/RB/D-pad ←→)`。
  **待建**：`IA_Dash(B)`、`IA_Beast(Y)`、`IA_ToolWheel(RT,按住)`、`IA_TalismanWheel(LT,按住)`、`IA_WheelSelect(左摇杆)`、`IA_BackpackPage(D-pad ↑↓)`、`IA_Map(⧉)`。
- **IMC 清单**：`IMC_OnFoot`（优先级 0，角色移动 + 用手位 + 交互 + 快捷栏 + 菜单，共 26 条映射）、
  **`IMC_Aim`（优先级 10，按住瞄准键期间 push，把移动键改绑到 `IA_AimMove`）**。两者均已生成。
  菜单**不占 IMC**（见上表）；`IA_Menu` 挂在 `IMC_OnFoot` 里，由 `AMistHUD` 绑在 PlayerController 的输入组件上。
- 轻按/长按用 Trigger：`Pressed` + `UInputTriggerHold` + `Released`（轮盘＝Hold 开、Released 确认）。

## 七、制符小游戏输入（非战斗，独立小游戏）

符咒是**道具**：在制符台的小游戏里**预先画好**、存入背包，战斗中只从 `LT` 轮盘**选用**、不现场画。

- 参照 **Ōkami（大神）**：进入画布**暂停/减速世界**，安静作画。
- 建议**模板描线 + 引导笔画（按顺序连节点）+ 大容差 + 吸附**，规避手柄自由画的别扭；判定沿用 [符咒系统](系统/00-核心-符咒系统.md) 的相似度四档（拙/常/灵/妙）。
- 三端：鼠标自由描 / 右摇杆当笔 / 触屏手指描（若纳入触屏）。
- 💡 **建议尽早出原型**：手柄手感是差异化成败点。
