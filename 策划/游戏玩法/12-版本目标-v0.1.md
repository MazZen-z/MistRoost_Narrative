## 一、一句话目标

**在一张农场验证关卡里，玩家能：起床 → 用工具锄地/播种/浇水 → 睡觉过夜 → 作物按天生长 → 收获 → 投出货箱 → 次日金币结算**，
全程可用 `Tab` 呼出主面板（七页签）与背包。**美术全占位，无存档，单关卡。**

> 关卡/地图本身由**你自己搭建**，不在代码交付范围内；代码侧只依赖"有一块水平的农田区域 + 一张床 + 一个出货箱"。

## 二、验收清单（DoD · 逐条走一遍就算 0.1 达成）

这是一条**可照着操作的通关脚本**，每条都必须在编辑器 PIE 里可复现：

| # | 操作 | 期望结果 |
|---|---|---|
| 1 | 进入关卡 | HUD 显示 `第1年 春 1日 06:00` + 金币数；角色可 WASD 移动 |
| 2 | 按 `1` 选锄头 | 手位＝锄头；**画面上没有高亮格**（这是预期行为） |
| 2b | 按住 `LB` | 出现高亮格（起始＝面前一格）；摇杆/WASD 逐格挪光标，**角色原地不动**；松开高亮消失 |
| 3 | 对空地按 `左键`(X) | 不按 LB 时作用于**面前一格**，按住 LB 时作用于**高亮格**：`未开垦 → 已开垦` |
| 4 | 按 `2` 选种子，`左键` | 该格种下作物，出现**第 0 阶段**幼苗；背包种子 −1 |
| 5 | 按 `3` 选水壶，`左键` | 该格标记"今日已浇水"（地表湿润状态清晰变化，具体3D表现按美术合同） |
| 6 | 走到床边 | 出现交互提示"Sleep"；按 `E`(A) → 淡出 |
| 7 | 醒来 | 时间跳到**次日 06:00**；浇过水的作物**阶段 +1**；全场浇水标记清空；日运势重摇（Log 可见） |
| 8 | 重复 5~7 直到成熟 | 作物到最终阶段，外观变化，可收获 |
| 9 | 对成熟作物按 `E` | 产出物品进背包，**数量经 `UMistLuckSubsystem` 判定**；可再生作物退回再生阶段，否则清格 |
| 10 | 走到出货箱按 `E` | 把手位物/选中物投入，进入"待结算"列表 |
| 11 | 再睡一觉 | 醒来弹出**昨日结算面板**：出货明细 + 收入 + 当前金币；金币真实增加 |
| 12 | 按 `Tab` | 弹出主面板 `MainUMG`，**七个页签**（地图/角色/背包/任务/人物/设置/宠物）可点击切换；**背包页显示真实物品与数量**，其余页可为占位 |
| 13 | 再按 `Tab` / `Esc` | 关闭面板，输入上下文回到徒步 |

**全部 13 条通过 = v0.1 完成。**

## 三、范围（明确的 In / Out）

### ✅ 本版做

1. **数据驱动的物品 / 作物 / 工具定义**（DataTable，可在编辑器加内容而不改代码）
2. **格子农田系统**：坐标换算、每格状态机、目标格瞄准与高亮
3. **三个工具动作**：锄地 / 浇水 / 播种（＋徒手收获）
4. **作物按天生长**（`StagedDaily`：昨日浇水 + 当季才推进）＋ 收获 ＋ 再生作物
5. **背包系统**（数据层 + UI）＋ 金币
6. **睡觉过夜**：床交互 → `SleepToNextMorning()` → 作物结算 / 出货结算 / 运势重摇
7. **出货箱** + **每日结算面板**
8. **主面板 MainUMG**：七页签框架（内容可空）
9. **HUD**：时间日期、金币、交互提示、快捷栏

### ❌ 本版不做（写在这里就是为了防止自己顺手做下去）

存档读档 · 天气 · 完整四季作物表 · [符咒](系统/00-核心-符咒系统.md) · NPC 与对话 · 战斗与矿洞 · 钓鱼 · 畜牧与岚兽 ·
料理加工 · 商店买卖（只卖不买，种子直接给初始库存）· 音效 · 正式美术 · 多关卡切换 · 手柄轮盘

> **刻意的降级**：[操作方案](11-操作与输入方案.md) 里的 `RT/LT 双轮盘`本版**不实现**，
> 用 **数字键 `1-9` 直选 + 键鼠为主**顶替。轮盘是"手感差异化"，放到有内容量之后再做才有意义。
> 手柄本版仅保证"能动 + 能用 + 能交互"，不保证平权。

## 四、模块拆解与目录

**目录一律按 [代码分区与目录结构](../../../MistRoost/程序设计准则.md#domains) 的领域分区落位**，命名与文件粒度遵循 [代码规范](../../../MistRoost/程序设计准则.md#coding)：
一个文件一个主类型、类型统一 `Mist` 前缀、`Public`/`Private` 镜像、**一切数值/路径/文本不写死**。

### 4.1 定义层（各域的 `Definition/`，一类型一文件）

| 类型 | 落位 | 关键字段 |
|---|---|---|
| `EMistItemType` / `EMistItemQuality` / `FMistItemStack` | `Item/Definition/` | 各自独立成文件 |
| `FMistItemDef : FTableRowBase` | `Item/Definition/` | 行名即 ItemId · `DisplayName(FText)` / `Icon` / `MaxStack` / `ItemType` / `BaseSellPrice` / `ToolId` |
| `EMistToolAction` / `FMistToolDef` | `Tool/Definition/` | `Action`(Till/Water/…) / `AreaSize` / `Tier` / `UseCooldown` |
| `FMistCropDef` | `Farming/Crop/` | `SeedItemId` / `HarvestItemId` / `StageDays[]` / `Seasons` / `bRegrow` / `MinYield`~`MaxYield` / `StageMeshes[]` |
| `EMistSeason` | `World/Season/` | 与时钟的 `int32 Season` 一一对应 |

**配置各归其域**（不设全局大设置类）：`UMistItemSettings`（物品表 + 兜底堆叠）、`UMistInventorySettings`（容量 / 快捷栏 / 初始物品）、
`UMistToolSettings`（工具表）、`UMistFarmingSettings`（作物表 + 格子边长）、`UMistEconomySettings`（初始金币 + 品质售价倍率）。
数据表资产 `DT_ItemDefs` / `DT_CropDefs` / `DT_ToolDefs` 在编辑器创建，由各自设置类**软引用**持有。

### 4.2 注册表与系统层

| 类 | 落位 | 职责 / 关键 API |
|---|---|---|
| `UMistGameClockSubsystem` ✅已有（待迁移改名） | `World/Clock/` | 权威时间 / `OnDayStarted` / `SleepToNextMorning` |
| `UMistLuckSubsystem` ✅已有（待迁移改名） | `Core/Luck/` | 概率闸口（收获数量 / 品质） |
| `UMistItemRegistry` **新** | `Item/Registry/` | 加载物品表 + 校验 + 查询：`FindItemDef / GetMaxStack / GetSellPrice` |
| `UMistToolRegistry` **新** | `Tool/Registry/` | 加载工具表 + 查询：`FindToolDef / FindToolDefForItem` |
| `UMistCropRegistry` **新** | `Farming/Crop/` | 加载作物表 + **种子→作物**反查（跨域索引放上层这一侧） |
| `UMistInventory` **新** | `Item/Inventory/` | 纯容器 UObject：堆叠 / 增删 / 交换 / 拆分 / 排序 / 转移；箱子日后复用同一个类 |
| `UMistInventorySubsystem` **新** | `Item/Inventory/` | 持有玩家背包 + 快捷栏选中 + 事件；`GetPlayerInventory / SetSelectedHotbarIndex` |
| `UMistWalletSubsystem` **新** | `Economy/Wallet/` | 金币：`GetGold / AddGold / TrySpendGold` ＋ `OnGoldChanged`（钱从背包里拆出来，商店/结算都只认它） |
| `UMistFarmGridSubsystem` **新** | `Farming/Grid/` | 世界↔格子换算、`TMap<FIntPoint, FMistTileState>`、订阅 `OnDayStarted` 推进全场作物 |
| `UMistShippingSubsystem` **新** | `Economy/Shipping/` | 待结算列表 → `OnDayStarted` 折算金币并生成明细 |

`FMistTileState`（`Farming/Grid/`）：`EMistTileState{未开垦, 已开垦}` ＋ `bWateredToday` ＋ `CropId` ＋ `Stage` ＋ `DaysGrown` ＋ `bHarvestable`。
**格子是纯逻辑数据，表现（翻土贴花 / 作物 Mesh）完全另起一层**（`Farming/Visual/`），用 ISM 或 Decal 订阅变更事件刷新。

### 4.3 交互层 `Action/`

- `UMistTileTargetingComponent`（`Action/Targeting/`）：键鼠＝光标射线命中格，手柄＝角色朝向前一格；输出目标格 + 是否有效
- 目标格高亮：Decal / 半透 Mesh，跟随目标格（表现层，`Farming/Visual/`）
- `IMistInteractable` + `UMistInteractionComponent`（`Action/Interaction/`）：范围内最近目标 → 提示文本 → `E` 触发
- `UMistToolUseComponent`（`Tool/Usage/`）：把「手位是什么工具」翻译成对目标格的动作，冷却与动画在此
- `AMistBed`（`Action/Interaction/`）→ 淡出 → `SleepToNextMorning()` → 弹结算面板
- `AMistShippingBin`（`Economy/Shipping/`）→ 投入手位物
- 新增输入（`Action/Input/`）：`IA_UseHand`(左键/X) · `IA_Interact`(E/A) · `IA_Menu`(Tab/☰) · `IA_HotbarSlot`(1-9)

### 4.4 UI 层 `UI/`（C++ 基类 + 编辑器 WBP 派生）

| Widget | 落位 | 内容 |
|---|---|---|
| `AMistHUD`（AHUD 子类）| `UI/HUD/` | **UI 层唯一入口**：建界面 · 接菜单键 · 订阅日结算 · 管输入模式（有面板就 UIOnly）|
| `UMistPanelWidget` | `UI/Common/` | 模态面板基类：进出视口 · 抢键盘焦点 · `CloseKeys` 按键关闭 · 开关事件 |
| `UMistMainMenuWidget` ＋ `UMistMainMenuTabButtonWidget` | `UI/MainMenu/` | **七页签**（`EMistMainMenuTab`，枚举序号＝WidgetSwitcher 页序号）；`Tab` 开关；页签按钮扫控件树自动归位 |
| `UMistInventoryWidget` + `UMistInventorySlotWidget` | `UI/Inventory/` | 网格布局，图标 + 数量；点击选中＝占手位 |
| `UMistHotbarWidget` | `UI/HUD/` | 底部快捷栏（背包前 N 格），`1-9` 高亮同步 |
| `UMistHUDWidget` | `UI/HUD/` | 时间日期（替换现有 Debug 文字）· 金币 · 交互提示 |
| `UMistDaySummaryWidget` ＋ `UMistDaySummaryEntryWidget` | `UI/HUD/` | 昨日出货明细 + 收入 + 当前金币，确认后关闭；由 `OnDailySettled` 自动弹出 |

> 七页签中**只有「背包」要求接真实数据**，其余六页 v0.1 只要"点得开、有个标题"即可，
> 目的是**把主面板的框架和输入切换先立住**，后续每个系统各自往里填。

### 脚本化接线（上面第 1~4、6、11、14 项就是这么做的）

数据表、输入资产这类**机械又容易填错**的东西可以让无头编辑器批量生成，不必手点：

```
UnrealEditor-Cmd.exe MistRoost.uproject -run=pythonscript -script="<脚本路径>" ^
  -EnablePlugins=PythonScriptPlugin -unattended -nosplash -nopause -NullRHI -stdout
```

- `-EnablePlugins=PythonScriptPlugin` 让 Python 插件**只在这一次运行时**启用，不动 `.uproject`。
- **跑之前先关编辑器**：两个编辑器进程会抢 DDC/ZenServer。
- 脚本里用 `AssetToolsHelpers.get_asset_tools().create_asset(...)` 建资产、
  `DataTableFunctionLibrary.fill_data_table_from_json_string(...)` 灌行；
  修饰符/触发器这类 Instanced 子对象必须 `unreal.new_object(cls, outer=资产)`，否则存不进去。
- 项目设置（`UDeveloperSettings`）**没有 Python 绑定**，要读就 `unreal.find_object(None, "/Script/MistRoost.Default__MistItemSettings")`
  再用**C++ 属性名**（`ItemTable` 而不是 `item_table`）；要写就直接改 `Config/DefaultGame.ini`。
- 生成完**务必另跑一遍只读脚本从磁盘回读**核对，别信"脚本没报错"。
