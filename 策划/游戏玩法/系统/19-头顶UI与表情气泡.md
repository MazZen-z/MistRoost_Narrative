## 1. 目标

- 【你已定】做一个**通用**的头顶 UI，NPC 能用，主角以后也能用。
- 【你已定】**可配置**，表里或 Setting 里都行：开心、惊讶、惊喜、无语、流汗……
- 【你已定】送礼的反应要体现在头顶 UI 和立绘上。
- 【建议】表情定义放**数据表**（加一种＝加一行，代码不动）；全局参数放**项目设置**。两者都用上，各管各的。

## 2. 组成

| 部件 | 放哪 | 做什么 |
|---|---|---|
| `DT_Emotes` | 数据表 | 每种表情一行：图标、气泡样式、动画、时长、优先级、音效 |
| 项目设置 `MistRoost - Emote` | `Action/Overhead` | 表在哪、默认时长、默认锚点、偏移、缩放、淡入淡出 |
| `UMistOverheadComponent` | `Action/Overhead`（第 3 层） | 挂在任何 Actor 上：播放／清除表情、锚点配置；**不认识界面** |
| `UMistOverheadSubsystem` | `Action/Overhead`（World 子系统） | 登记场上的头顶组件（弱引用），通知绘制层；只管表现，不存玩法数据 |
| 头顶绘制层 | `UI/Overhead`，放在 HUD 层 | 把正在显示的气泡画到对应 Actor 的屏幕位置 |
| `WBP_EmoteBubble` | UI | 气泡外观与动画，资产可换 |

主角（第 5 层）和 NPC（第 4 层）都能挂这个组件，分层方向合规（[程序设计准则 §3](../../../../MistRoost/程序设计准则.md#domains)）。

**为什么画在 HUD 层，而不是每个 Actor 挂一个 WidgetComponent**：

| 方案 | 好处 | 代价 |
|---|---|---|
| HUD 绘制层【建议】 | 组件不依赖界面；层级、统一隐藏一处管；控件对象池；和交互弹窗共用投影与夹边 | 要自己做"世界 → 屏幕"投影（只算正在显示的几个，开销很小） |
| 每个 Actor 挂 `UWidgetComponent`（屏幕空间） | 引擎现成、上手快 | 每个 Actor 各持一个控件；和 CommonUI 的层级、统一隐藏不好管 |

【实现，阶段 D0】按上表的建议做了 HUD 绘制层：

| 部件 | 实际位置 |
|---|---|
| 表情表、设置、登记处 | `Action/Overhead`：`FMistEmoteDef`、`UMistEmoteSettings`、`UMistEmoteRegistry`（启动体检：每行得有图标或占位字、有中文名） |
| 头顶组件 | `UMistOverheadComponent`（`Action/Overhead`）。NPC（`AMistNpcCharacter`）开场时把 `OverheadId` 填成 NpcId；主角（`AMistPlayerCharacter`）是 `Player`。别的 Actor 自己加这个组件就能用 |
| 子系统 | `UMistOverheadSubsystem`（World 子系统，只在游戏世界里有）：弱引用登记、按 `OverheadId` 找人、列出正在显示的 |
| 蓝图函数库 | `UMistOverheadLibrary::PlayEmoteOnActor` |
| 绘制层 | `UMistOverheadLayerWidget`（`UI/Overhead`）→ `WBP_OverheadLayer`；HUD（`WBP_CloudHUD`）的 `OverheadLayerClass` 指向它，建在 HUD 根面板里、垫在交互弹窗下面，对话时收起 HUD 信息也不收它 |
| 气泡 | `UMistEmoteBubbleWidget`（`UI/Overhead`）→ `WBP_EmoteBubble`，两份 WBP 都由 `MistRoost/Tools/common_ui_build.py` 首次生成 |

**WBP 合同**：

| WBP | 控件名 | 类型 | 必须 | 说明 |
|---|---|---|---|---|
| `WBP_OverheadLayer` | `BubbleCanvas` | CanvasPanel | ✔ | 铺满；气泡由代码按头顶投影摆上去 |
| | 属性 `BubbleClass` | 类 | ✔ | 指 `WBP_EmoteBubble` |
| `WBP_EmoteBubble` | `BubbleRoot` | 任意 | | 动画作用在它上面；不摆就作用在整个控件上 |
| | `RoundBubble`／`ThoughtBubble` | 任意 | | 按表情的样式显示其一，`None` 时都收起 |
| | `IconImage` | Image | | 表里配了图标时显示 |
| | `GlyphText` | TextBlock | | 没图标时显示占位字 |
| | 动画 `Anim_PopIn`／`Anim_Bounce`／`Anim_Shake`／`Anim_Float`／`Anim_Pulse` | UMG 动画 | | 有同名的就播它；没有就用 C++ 里的简单动法（数值在控件属性上，占位） |

哪些面板"盖住世界"由面板自己说：`UMistPanelWidget` 加了 `bCoversWorld`（默认是），对话框（`UMistDialogueWidget`）设成否；HUD 据此提供 `IsWorldCoveredByPanel()`，绘制层据此让位。以后的交易界面默认就会让气泡让位，不用改绘制层。

## 3. 表情表 `DT_Emotes`

| 字段 | 说明 |
|---|---|
| 行名 | EmoteId，如 `Happy` |
| DisplayName | 中文名（FText），调试与辅助功能读屏用 |
| Icon | 图标贴图（软引用）；要做帧动画可换成材质 |
| BubbleStyle | `Round`（圆气泡）／`Thought`（云朵）／`None`（只有图标） |
| Animation | `PopIn`／`Bounce`／`Shake`／`Float`／`Pulse`，对应 WBP 里的同名动画 |
| Duration | 秒；0＝一直显示直到被清掉；空＝用设置里的默认值 |
| Priority | 整数，高的能打断低的 |
| Sound | 音效（软引用），可空 |
| Scale | 可空，默认 1 |

**初始清单**【占位：图形与优先级都待定】：

| EmoteId | 中文 | 图形建议（美术定） | 优先级 | 默认用在 |
|---|---|---|---|---|
| `Happy` | 开心 | 音符或笑眼 | 10 | 喜欢的礼物、愉快的台词 |
| `Surprised` | 惊讶 | 感叹号 | 20 | 意外的消息 |
| `Delighted` | 惊喜 | 双感叹号＋星光 | 30 | 最爱的礼物 |
| `Speechless` | 无语 | 省略号 | 10 | 尴尬、接不上话 |
| `Sweat` | 流汗 | 汗滴 | 10 | 讨厌的礼物、为难 |
| `Heart` | 爱心 | 心形 | 30 | 生日礼物；好感升一颗心【建议】 |
| `Angry` | 生气 | 怒气符号 | 20 | |
| `Question` | 疑问 | 问号 | 10 | 主角用不了工具时【后续】 |
| `Idea` | 灵光 | 亮点 | 10 | 主角发现东西【后续】 |
| `Sleep` | 睡 | Zzz | 0 | NPC 休息【后续】 |

EmoteId 是开放集合（以后随时加），所以不用枚举；启动体检检查台词表、喜好表里引用的 EmoteId 都在这张表里。

【实现，阶段 D0】`DT_Emotes`（`/Game/MistRoost/Data`）由 `MistRoost/Tools/data_tables_build.py` 首次铺好上面 10 行，之后以编辑器为准。与上表的出入：

- 多了两列**占位**：`PlaceholderGlyph`（没图标时气泡里写的字）和 `PlaceholderColor`（那个字的颜色）。美术出图前先用字顶着：开心 ♪、惊讶 ！、惊喜 ！！、无语 …、流汗 汗、爱心 ♥、生气 怒、疑问 ？、灵光 ☆、睡 Zzz。给 `Icon` 配上贴图，就显示图标、不显示字。自动化测试逐个查这些字在气泡字体里都有（没有会画成方块）。
- `Duration` 写 −1＝用设置里的默认时长（数据表里没法留空）；0＝一直显示。
- 样式、动法先按直觉配了：疑问、睡用云朵；开心、灵光跳，惊喜、爱心胀缩，生气抖，无语、流汗、睡往上飘。
- 引用检查：台词行的 Emote 列、效果 Emote 在对话体检里查（§7）；喜好表等阶段 D 建表时一起接上。编辑器里这些列都是下拉，从表里选。

## 4. 项目设置 `MistRoost - Emote`【占位】

| 字段 | 默认 | 说明 |
|---|---|---|
| EmoteTable | `DT_Emotes` | 表指认 |
| DefaultDuration | 1.8 s | 表里没写时长时用 |
| DefaultAnchorSocket | `head` | 骨骼插槽名，以实际骨架为准；找不到就用胶囊顶 |
| WorldOffset | 30 cm | 在锚点上方再抬多少（世界 Z） |
| ScreenOffset | (0, −8) px | 投影到屏幕后再挪多少 |
| ScaleByCameraPreset | 1.0／0.9／0.8 | 镜头近／标准／远三档（主角角色蓝图里的 `CameraDistancePresetsCm`）各自的缩放；远档也要看得清 |
| FadeIn／FadeOut | 0.12 s／0.2 s | |

单个 Actor 可以在组件上覆盖锚点插槽与偏移（比如高个子、坐着的 NPC）。

## 5. 播放规则

| 接口 | 说明 |
|---|---|
| `PlayEmote(EmoteId, 时长覆盖＝可空)` | 新表情优先级 ≥ 当前 → 替换；否则忽略（**不排队**）；同一个表情再播 → 重新计时。返回是否播出 |
| `ClearEmote()` | 立即淡出 |
| `GetCurrentEmote()` | 当前在显示的 |
| 蓝图函数库 `PlayEmoteOnActor(Actor, EmoteId)` | 找到组件就播，没有组件什么也不做；给关卡、过场、其他系统用 |

- 同一个 Actor 同时只显示一个表情（标记另算，见 §8）。
- 时长到了淡出；时长为 0 的一直显示到 `ClearEmote`。
- 【建议】不排队：排队会让气泡在事情过去之后才冒出来，反而困惑。

【实现，阶段 D0】照上表。计时用世界时间（游戏暂停时一起停）；表里没有的 EmoteId 不播，每个 Id 只警告一次。

## 6. 锚点与显示

- 锚点：骨骼插槽（设置默认、组件可覆盖）＋世界上抬；没有插槽用胶囊顶。
- 投影到屏幕后加屏幕偏移，夹在安全区里；**Actor 在屏幕外就不显示**（不做屏幕边缘箭头）。
- 永远画在世界之上（屏幕空间），不会被屋顶挡住。
- 对话时：说话 NPC 的气泡照常显示——立绘换表情、头顶冒气泡同时发生，就是你说的"体现在头顶 UI 和立绘上"。
- 主菜单、交易界面打开时隐藏所有气泡；关掉后，还没到时的气泡继续显示。睡觉淡出、过场时隐藏。
- 交互弹窗（15 篇）用同一套投影与夹边：弹窗挂在脚下、表情气泡在头顶，不会互相叠住。

【实现，阶段 D0】气泡底边中点对准锚点；整个气泡夹在屏幕里（离边 16，界面单位）；锚点在屏幕外或镜头后面就不画；几个气泡叠在一起时近的画在上面；大小＝镜头档位的缩放 × 表里的 Scale。盖住世界的面板（主菜单、轮盘、确认框，以后的交易界面）打开时整层淡出，关掉后淡回来，对话框不算（§2 的 `bCoversWorld`）。**还没做**：睡觉淡出、过场隐藏——等睡觉的黑屏和过场系统有了再接。

## 7. 谁会调用

| 调用方 | 什么时候 | 播什么 |
|---|---|---|
| 对话（16 篇） | 每行开始显示时 | 台词行的 Emote 列；选项效果 `Emote(X)` |
| 送礼（17 篇） | 反应开始时 | 台词行写了就用台词行的，没写用档位默认：最爱 `Delighted`、喜欢 `Happy`、一般 无、讨厌 `Sweat` |
| 好感（17 篇） | 升一颗心时 | 【建议】`Heart` |
| 交易（18 篇） | 成交、钱不够、不收 | 由店主气泡台词行的 Emote 列决定 |
| 主角【后续】 | 体力低、发现东西、用不了工具 | `Sweat`、`Idea`、`Question` |
| 调试 | 随时 | 任意 |

【实现，阶段 D0】已接上：

- **台词行**：一行开始显示时，Emote 列冒在说话的人头上——NPC 说话冒在这位 NPC 头上，主角说话冒在主角头上，多人对话里别的 NPC 说话按 NpcId 找到他。说话的人不在场就不冒，不算错。选项行不用这一列；旁白没有头。这两种写了 Emote 列，体检会提醒。
- **效果 Emote**：字段是表情、冒在谁头上（对话的 NPC／主角／另一位 NPC）、时长覆盖。选项确认时提交。
- **升一颗心**：NPC 头上冒 `Heart`。表情在项目设置 `MistRoost - Relationship` 的 `HeartUpEmote` 里选，选 None 就不冒。
- 占位台词里挑了 12 行配上气泡（木匠的初见、寒暄、请你帮忙等；阿婆的初见、两颗心以后那句）。`dialogue_build.py` 只给 Emote 列还空着的行补，编辑器里改过的不碰。
- 送礼（阶段 D）、交易（阶段 E）做到时再接；主角那几种等对应玩法。

## 8. 头顶标记（【后续】，已留位置）

- 持续显示的小图标：今天有新话要说、生日、有任务可接／可交……
- `DT_OverheadMarkers`：MarkerId、图标、条件（[条件语言](14-条件与世界事实.md)）、优先级。
- 每个游戏时间步（10 分钟）对当前关卡里的 NPC 求值一次，只显示优先级最高的一个；播表情时标记让位。
- 组件预留"标记"槽位；本轮不做。

## 9. 性能

- 组件不 Tick；播放、清除时才通知绘制层。
- 绘制层每帧只为**正在显示**的气泡做投影与布局（通常个位数）。
- 气泡控件用对象池，不反复创建销毁。
- 子系统对组件只持弱引用，Actor 随关卡卸载时自动失效（[程序设计准则 §2](../../../../MistRoost/程序设计准则.md#architecture)：表现服务要有清晰生命周期与弱引用）。
