# 框架 · 运气系统（Luck）

> 状态：🌿 成形（架构方案待你评审） · 最后更新：2026-09-28
> 相关：[计时与产出系统](09-计时与产出系统.md) · [符咒系统](00-核心-符咒系统.md) · [供奉与技能](06-供奉与技能.md) · [矿洞与战斗](05-矿洞与战斗.md)

## 目标（你的定调）

> 游戏的**概率性**非常有意思、能吸引玩家。**所有概率相关内容都走运气系统**。

## 设计：单一「概率闸口」`ULuckSubsystem`

全游戏**任何一次掷骰都经过它**，好处：数值只在一处调、可埋点统计、便于做「每日运势」这类留存钩子。

覆盖对象（举例）：作物品质、掉落表、宝箱/晶洞、[岚兽进化概率](03-畜牧.md)、[妖魔化刷怪](01-岚气与岚兽.md)、钓鱼稀有度、小游戏结算、契约成功率……

### 三个组成

**1）每日运势 `DailyLuck`**
- 每次 `OnDayStarted` 重算一个隐藏值（如 `[-0.1, +0.1]`，对标星露谷「今日运势」）。
- 可通过**神龛 / 算命 / 岚气占卜**软性透露 → 给玩家「今天适合下矿吗」的决策与**每日登录动机**。

**2）持续/情境修正 `LuckModifiers`**
- 叠加来源：[供奉技能](06-供奉与技能.md)、[料理 Buff](02-种田.md)、装备、**幸运符（[符咒](00-核心-符咒系统.md)）**、神龛加持。
- 表示为带**情境标签**的加/乘修正，有时限或永久。

**3）情境标签 `FLuckContext`**
- 用 `GameplayTag` 标注这次掷骰属于哪个系统（Mining/Fishing/Foraging/Farming/Combat/Beast…），
  让运气可以**按系统分别加权**（幸运符也能只加「采矿运」）。

### 接口（示意）
```cpp
class ULuckSubsystem : public UGameInstanceSubsystem {
    float DailyLuck;                         // OnDayStarted 重算
    TArray<FLuckModifier> ActiveModifiers;   // 技能/料理/符咒/神龛

    // 统一 API —— 全游戏概率都调这里
    bool  RollChance(float BaseProb, const FLuckContext& Ctx);          // 是/否
    int32 RollWeightedTable(const FLootTable& Table, const FLuckContext& Ctx); // 权重表
    int32 RollQuantity(FIntPoint Range, const FLuckContext& Ctx);       // 数量/品质
    float GetEffectiveLuck(const FLuckContext& Ctx) const;             // 汇总当前运气
};
```

### 确定性：种子化随机（重要）
- **每日/固定型掷骰**（每日运势、晶洞内容）用**种子化** `FRandomStream`，
  键 = `(存档种子, AbsoluteDay, 用途Hash)` → **同一天可复现**（公平、可测试、抗读档刷）。对标星露谷的 seeded RNG。
- **即时型掷骰**（战斗暴击）用会话级流即可，无需可复现。
- 【已实现，2026-09-28】有效运气＝日运＋**角色运气**：角色运气是主角的属性 `Luck`（[22 主角属性](22-主角属性.md) §5.3，属性表夹在 −0.1～+0.1），饰品、料理、符咒、神龛以后都挂效果改这个属性，运气系统只读结果（`GetCharacterLuck`、`GetEffectiveLuck`）。上面示意里的 `ActiveModifiers` 因此不单独做；按情境加权（只加采矿运）还没做。
- 【已实现，2026-09-25】公开的"按天固定、**不受运气影响**"掷骰 `UMistLuckSubsystem::GetDailyFixedRoll(天, 用途, 键A, 键B)`，返回 [0, 1)：对话的"概率"列与台词抽签用它（[16 NPC 对话](16-NPC对话.md) §7）。用途与键按名字（不分大小写）算稳定哈希，不用 FName 的内部编号——那个编号随进程变，重启游戏就会刷出不同结果。

## 与其他系统的联动
- **[符咒](00-核心-符咒系统.md)**：可设「幸运符」临时抬高某情境运气 → 概率玩法与符咒便利层自然咬合。
- **[计时产出](09-计时与产出系统.md)**：产出「数量/品质」区间由本系统摇（`RollQuantity`）。
- **[供奉](06-供奉与技能.md)**：技能树可含「提升每日运势下限 / 某系统运气」分支。
