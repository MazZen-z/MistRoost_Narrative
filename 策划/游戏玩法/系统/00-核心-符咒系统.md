## 一句话定义（已定稿）

**符咒是「便利玩法层」，只是用手绘符咒的形式表现出来。** 它让玩家一定程度上摆脱繁琐操作
（浇水、矿洞敲石头等），本质对标**星露谷物语的「炸弹 / 梯子」**——是提供便捷的**消耗性道具**，
而非需要囤积的稀缺资源。差异点在于：**由玩家在小游戏里亲手画出来**，并消耗**岚气 + 一定资源**。

> **世界观定位（D-035）**：符＝**公文**。你不是在施法，是在**借神的职分办事**——权限来自职分，不来自主角本身。这解释了为什么符咒是「便利」而不是「力量」，也解释了为什么它能被限制。

## 玩家定调（原话，2026-09-09）

> 符咒是一种**便利玩家的方式**，只是用符咒的形式表现出来。例如符咒需要一个**小游戏由玩家自己画出来**，
> 需要**消耗岚气和一定资源**。可以帮助玩家一定程度**摆脱繁琐的浇水、矿洞敲石头**这种操作，
> **类似星露谷物语的炸弹、梯子**。暂时定义为能为玩家提供便捷的道具，如：**传送、生活帮助、战斗帮助、资源采集帮助**。

## 四大用途分类（暂定框架）

| 分类 | 作用（摆脱哪种繁琐） | 星露谷类比 | 关联系统 |
|---|---|---|---|
| **传送** | 免去往返奔波 | 回城卷轴 / 传送图腾 | 全地图 / 家园 |
| **生活帮助** | 免去浇水、施肥等重复劳作 | —（降雨/自动浇水向）| [种田](02-种田.md)、[畜牧](03-畜牧.md) |
| **战斗帮助** | 增强/群清/自保 | 炸弹（战斗向）| [矿洞与战斗](05-矿洞与战斗.md) |
| **资源采集帮助** | 免去敲石头、砍伐等 | 炸弹 / 梯子 | [矿洞](05-矿洞与战斗.md)、采集 |

> 示例符：**降雨符**（生活帮助，替代浇水）、**爆破符**（资源采集，替代敲矿）、
> **传送符**（传送）、**净秽符**（战斗帮助，净化煞与 Boss 战解封）。
> **原「契约符」（收服妖魔化岚兽）随岚兽归档**；若需保留同类功能，由净秽符承接，需主策确认。

### 职权表（D-035 定稿，暂定）

每张符都要能回答「**这是借谁的职分**」。没有职分的符不成立。

| 授权方 | 职司 | 符 | 用途分类 |
|---|---|---|---|
| **山神**（老人形象） | 山、路、石、地 | **缩地符** | 传送 |
| | | **点石符** | 资源采集帮助 |
| | | **开路符** | 资源采集帮助（清障／开山道） |
| **海神**（和善的婆婆形象） | 水、雨、潮、净 | **降雨符** | 生活帮助 |
| | | **潮信符** | 生活帮助（钓鱼／出海时机） |
| | | **净秽符** | 战斗帮助（净化煞、Boss 解封） |
| | | **安澜符** | 生活帮助（止风浪／护岸） |
| **神兽**（十只，净化后授予） | 各自的元素职司 | **战斗符**（逐只对应） | 战斗帮助 |
| **她的印** | 格式与章法 | 不是某一张符，而是**画符的程序格式** | — |

> 说明：**爆破符**是既有示例，需在职权表中补一个授权方（候选：山神「点石／开路」的延伸），待定。
> 神明形象与出场时机暂定；是否新增财神（管交易／价钱）待定。

## 获取机制：亲手画（核心手感）

- **绘制小游戏**：玩家在一个小游戏里**亲手画出符咒**（这是「符咒表现形式」的关键仪式感）。
- **成本**：消耗 **岚气／岚息**（见 [岚气与神兽](01-岚气与岚兽.md)）+ **画符原材料**（**仅 [岚日](10-季节与天气.md) 显出的 [秘境](01-岚气与岚兽.md) 可得**；具体材料名如符纸/朱砂待定）。
- **平衡杠杆（核心张力，D-035 修订）**：符咒是便利层，但**有意受限、不能天天随用**。核心约束＝**画符原材料只在岚日显出的秘境中（约 3–5 天/季、每岚日只显一处秘境、限量）**，叠加 **岚息成本 + 画符操作/时间 + 职分门槛**。
  → 目标手感：玩家在**有限原料下统筹抉择**——这批符该留给 **种田**（如降雨符大面积浇水）、**矿洞**（爆破符/战斗）还是 **钓鱼**，而非每天无脑刷；这份"抉择"就是符咒玩法的核心乐趣。

### 绘制小游戏的方向 ❓（待细化）
- 描线临摹 vs 自由绘制+图形识别 vs 连线/节奏？
- 判定：相似度评分（影响品质/成功率）还是「画对即成」？

## 与岚气、职分的关系（D-035 修订）

- **岚气 = 灵墨，符咒 = 用气写成的一次性公文。** 画符**消耗岚息**（玩家可携带的气）+ 材料。
- **印决定职分**：印上的纹路＝每日可调用的气量。**修行即升职**——职分越高，能画的符越多、能调的气越多。
- **职权来自净化进度**：净化神兽 → 神力恢复 → 神的职分可借的范围变大 → 解锁更高阶符。这是**唯一的成长脊柱**，不另设第二条线。
- 气的环境浓度由生活经营与净化共同驱动（见 [岚气与神兽](01-岚气与岚兽.md)）→ 形成「**经营与净化越好 → 气越足 → 越能用符咒省事**」的正循环。
- **红线**：符咒不得写成力量本体或剧情万能钥匙；它是**借来的权限**，用完就还。
