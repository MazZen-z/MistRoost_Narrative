- **页面**：左边分类（全部＋5 类占位），中间是已经学会的配方（图标格子），右边是选中配方的详情——做出什么、要哪些材料（有几个／要几个）、做几份、"制作"按钮。
- **怎么做**：材料从主角背包里扣，一下做完（不花游戏时间、不耗精力），东西直接进背包；背包放不下就不做。
- **配方怎么来**：开局会几个；以后靠技艺升级、NPC、商店、五神供奉学会。学会了一直会，存档记下来。

## 2. 规则

### 2.1 做东西

- 一份配方＝**一组材料 → 一样东西（可以一次出好几个）**。做 N 份就扣 N 倍材料、得 N 倍东西。
- 材料只看背包里的总数（跨格子、跨等级都算）；扣的时候先扣低等级。
- 做出来的东西按物品表的默认等级放进背包。
- **整批要么全成、要么不做**：先算"扣完材料以后放不放得下"，放不下就一件都不做，背包不变。扣完材料正好腾出格子的也算放得下。
- 材料不够、配方不会、背包放不下时，"制作"按钮灰掉，旁边写原因。

### 2.2 学会配方

- 开局会的：配方表里勾了"开局就会"的那几个（星露谷开局会 10 个、珊瑚岛 7 个；我们现在占位 2 个）。
- 以后学会：技艺升级（[24 篇](24-技艺与经验.md)）、NPC 事件、商店买、五神供奉（[06 篇](06-供奉与技能.md)）。这些来源各自调同一个"学会配方"的口子，制作系统不认识它们。
- 学会就一直会，不会忘。
- 存档只记**开局以后学会的**；开局就会的每次按表算——以后往表里加开局配方，老存档也会有。

### 2.3 做出东西以后

- 发一条消息 `ItemCrafted`（做了什么、几件、哪个配方）。技艺（K1）听它记"制作"经验；以后 NPC 听说、成就也可以听它。
- 界面上数量回到 1（材料不够时是 0），材料的"有几个"跟着刷新。

## 3. 界面

### 3.1 布局

和背包页同一块区域（1532×730），三栏：

| 区 | 内容 |
|---|---|
| 左：分类 | 竖排按钮：全部、加工、田间、收纳、摆设、杂项；选中的高亮 |
| 中：配方 | 标题"配方"和"已学会 N 个"；下面是图标格子（和背包格子一样），材料不够做一份的变淡；空的时候写"这一类还没有学会的配方。" |
| 右：详情 | 大图标、名字（一次出多个时写"×2"）、说明；材料列表（图标、名字、有／要，不够的标红）；数量行：−、数字、＋、最多；"制作"按钮；原因（材料不够、背包放不下） |

位置和大小都是【占位】，在 WBP 里调；以后有参考图就照图改。

### 3.2 分类【占位】

| 分类 | 放什么（例） |
|---|---|
| 全部 | 界面自带，不是表里的一行 |
| 加工 | 腌菜坛、酿酒桶、熔炉、肥料机、炭窑 |
| 田间 | 稻草人、肥料、树苗箱 |
| 收纳 | 储物箱 |
| 摆设 | 篱笆、小路、灯、家具 |
| 杂项 | 鱼饵、木板这类中间材料 |

参照：珊瑚岛攻略里把能做的东西分成储物箱、农业必需品、手工设备、资源设备、物品产出、装饰、消耗品、鱼饵、陷阱、炸弹、杂项（攻略的分法，不一定是游戏里页签的原名，未核对）；我们先合成 5 类，东西多了再拆。

### 3.3 操作

- 打开制作页：选"全部"，选中第一个配方，数量 1（做不了一份就是 0）。
- 点分类：列表换成这一类，选中第一个。
- 点配方：详情换成它，数量回到 1。
- −／＋：在 1 到"最多"之间；"最多"＝材料够做几份和背包放得下几份里小的那个，再不超过上限。
- 点"制作"：做数量那么多份。
- 在别处（背包页、箱子）动了背包，回到制作页时"有几个"和能不能做会重算。
- 手柄：分类、格子、数量、"制作"都是能用方向键走到的按钮；LB／RB 照旧切主面板页。

## 4. 数据

### 4.1 配方表 `DT_RecipeDefs`（行名＝配方 ID）

| 列 | 说明 |
|---|---|
| 产物 `Output` | 物品 ID＋一次出几个 |
| 材料 `Ingredients` | 一组"物品 ID＋数量"，1～6 种，不能重复，不能有产物自己 |
| 分类 `Category` | 分类表的行名（下拉选） |
| 排序 `SortOrder` | 同一分类里小的在前 |
| 开局就会 `bKnownAtStart` | 勾上＝新游戏就会 |

显示名、图标、说明都用**产物**在物品表里的，配方表不另存（不造第二套真相）。

另有 `SkillXp`：做一份给制作技艺多少经验（09-28 随技艺 K1 加，[24 篇](24-技艺与经验.md) §6.1）。

### 4.2 分类表 `DT_RecipeCategories`（行名＝分类 ID）

| 列 | 说明 |
|---|---|
| 显示名 `DisplayName` | 如"加工" |
| 图标 `Icon` | 可空（现在用文字按钮） |
| 排序 `SortOrder` | 左边从上到下 |

### 4.3 占位配方（只用现有物品）

| 配方 | 做出 | 材料 | 分类 | 开局就会 |
|---|---|---|---|---|
| `Recipe_ChestSmall` | 小储物箱 ×1 | 木料 ×50（星露谷箱子也是 50 木头） | 收纳 | 会 |
| `Recipe_Plank` | 木板 ×1 | 木料 ×2 | 杂项 | 会 |
| `Recipe_ChestBig` | 大储物箱 ×1 | 木板 ×20 | 收纳 | 不会；制作技艺 1 级时学会（09-28 技艺 K2），也能用调试命令学 |

加工、田间、摆设暂时没有配方，用来看空分类的样子。

### 4.4 启动体检

配方表：产物或材料不是已知物品、数量 ≤ 0、材料重复、材料里有产物自己、没有材料、分类不在分类表里。分类表：没有显示名。都会在日志里点名（"validated N rows, M issue(s)"）。

### 4.5 设置（项目设置 → MistRoost - Crafting）

两张表的位置、一次最多做几份（【占位】99）、界面上的几句话（材料不够、背包放不下、空分类）。

## 6. 程序（给程序看的摘要）

| 放哪 | 是什么 |
|---|---|
| `Economy/Crafting/` | 配方与分类的行结构、两个查询入口（继承 `UMistDataRegistry`）、设置、`UMistCraftingSubsystem`（会不会、最多能做几份、做、学会、存档块、调试命令、发 `ItemCrafted`） |
| `UI/Crafting/` | 制作页控件、材料行控件 |
| `UI/MainMenu/` | 页签枚举末尾加 `Crafting`（不改已有值）；显示顺序里放在背包后面 |

- 放 Economy 域：制作就是"扣材料、发产物"的物品事务，和出货、交易同一层（[程序设计准则](../../../../MistRoost/程序设计准则.md) §3 第 3 层、§8 经济事务），不用新开域。
- "放不放得下"用一个临时的背包副本先试一遍，真背包只在确定能成之后才动。

调试命令：`Mist.Craft.List`（列出配方和会不会）、`Mist.Craft.Learn <配方|All>`、`Mist.Craft.Make <配方> [份数]`。

### 8.1 实机怎么看（L3，你来）

1. 打开编辑器，进游戏（PIE），按 Tab 打开主面板，点"制作"（首页多了一张锤子卡片）。
2. 开局会两个：小储物箱（木料 ×50）、木板（木料 ×2）。控制台 `Mist.AddItem Material_Wood 60` 给木料，就能做。
3. `Mist.Craft.Learn Recipe_ChestBig` 学会大储物箱，页面会自己刷出来；`Mist.Craft.List` 列出全部配方、会不会、现在能做几份。
4. 木料、木板还没有图标（背包里也一样是空格），格子看起来是空的。【09-28 已配】木料用 `美术资产/UI/Items/Materials/Wood.png`（`T_UI_Wood`）；木板还没有图，先用木料的（你定），`Tools/data_tables_build.py` 的 `ITEM_ICONS` 里改一行就换。已有的行图标空着时脚本会补上（`fill_item_icons`）。有了图标：放进 `美术资产/UI/Items/`，跑一次 `Tools/common_ui_build.py` 导入贴图，再在 `DT_ItemDefs` 里给这两行填 Icon（`Tools/data_tables_build.py` 只在建行时写图标，已有的行不会自己补上）。

已知：界面位置都是占位；没选配方时"所需材料"几个字还在；手柄能走到分类、格子和按钮，但没专门调过焦点顺序。
