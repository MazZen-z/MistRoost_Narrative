## 1. 目标

- 以后加一种交互物（门、井、信箱、告示牌、各种箱子），只需继承基类、写"交互后做什么"、配模型，不再各写一遍交互范围、模型、提示文字。
- 储物箱和出货箱共用一个"转移面板"：上面是箱子，下面是背包，右边是物品详情；按箱子类型换规则。
- 玩家造、摆、扩容的箱子都能存档，读档后按数据重建。

## 2. 三层结构

```
IMistInteractable（接口）                 交互组件只认它；NPC、作物、所有摆放物都实现
└─ AMistInteractableProp（摆放交互物基类） 交互范围、模型、提示文字、开关、对准／交互事件
   ├─ AMistBedActor（床）
   ├─ AMistContainerProp（容器基类，第 2 步）  打开转移面板；只是"钥匙"，数据在背包子系统
   │   ├─ 储物箱
   │   └─ AMistShippingBin（出货箱，第 3 步起继承它）
   └─ 以后：门、井、信箱、告示牌……
```

**基类 `AMistInteractableProp`（Action/Interaction，第 1 步已做）**

| 它负责 | 说明 |
|---|---|
| 交互范围 | 根上的 `InteractionBox`：只做查询、对谁都重叠、不挡东西；玩家的交互组件按它找到物件 |
| 模型 | `MeshComponent`（碰撞照常挡人） |
| 提示文字 | `InteractionPrompt`，HUD 直接显示 |
| 能不能用 | `bInteractionEnabled`；关掉后对不准、不亮提示 |
| 事件 | `OnInteracted`（交互成功一次）、`OnFocusChanged`（玩家对准／移开，给高亮用） |
| 子类只写 | `CanInteractWith`（此刻让不让交互，默认让）、`HandleInteract`（交互后做什么）；两个都能在蓝图里覆盖 |

- 交互接口加了一个"对准／移开"通知 `OnInteractionFocusChanged`，交互组件换目标时调用；默认什么都不做，NPC、作物不受影响。
- 高亮描边的材质还没有：`OnFocusChanged` 先留给蓝图接，描边做好后放进基类。
- 子类的模型组件名沿用原名（床 `BedMesh`、出货箱 `BinMesh`），已有蓝图和关卡里配的模型不受影响。

## 3. 转移面板（第 2 步）

一个面板，箱子和出货箱共用（UI 层，只显示两个容器、发转移请求；规则在数据那边）：

| 区域 | 内容 |
|---|---|
| 顶部 | 图标＋标题（箱子名／"出货箱"）；出货箱多一行说明"将想要卖掉的物品放入出货箱，当晚运出" |
| 上方 | 容器格子（储物箱 40 或 80 格，可滚动） |
| 下方 | 背包格子 |
| 右侧 | 选中物品的详情卡（名字、类别、说明）；没选时"没有选择项目" |
| 左侧 | 一列图标快捷操作（参考图 `概念设计/UI/珊瑚岛/箱子.png`）：箱子格子旁"整理"；背包格子旁四个——↑全部放入、↑放入同类（背包 → 箱子），↓全部取出、↓取出同类（箱子 → 背包）。参考图里的"自动整理"没做 |
| 左下 | 出货箱："N 件物品将被运输 · 预计收入 X 金"（一行） |
| 右下 | 按键提示，随鼠标／手柄切换。现在是鼠标"Space 分割 · 左键 拿起／拖动 · 右键 转移 1 · Shift+左键 整堆送过去"，手柄"Y 分割 · A 拿起／放下 · X 转移 1 · LB/RB 换区"（返回键在旁边的按键条里）。参考图里出货箱专用的"放置所有 / 放置（长按放置更多）"没做 |

- 放不进去（出货箱不收的东西）：格子变灰，按了提示原因，不动任何东西。
- 【本步实现】焦点在哪格右边就显示哪格的详情；整理＝箱子里按物品排好。怎么拿、怎么放见 §3.1。面板样子是占位（`WBP_Container`，在 Designer 里调）。
- 面板开着时主角不能走（与其他面板一致）。
- 画面风格用本项目的界面样式（暖纸色面板、青绿选中），布局照参考图。

### 3.1 物品操作（拿起、放下、转移）

【你已定，09-26】照珊瑚岛的做法。箱子面板（以后出货箱面板共用）全都有；Tab 菜单的背包页能在背包里挪、能挪进快捷栏；交易界面不变（点一格 → 选数量）。

| 操作 | 鼠标 | 手柄 |
|---|---|---|
| 拿起整堆／放下 | 左键点一格拿起，再点另一格放下；也可以按住直接拖过去松开（刚点过马上再按住拖也一样） | A |
| 转移 1 个到另一边 | 右键（连按连着转）；背包页没有另一边，右键＝拿 1 个，再按多拿 1 个 | X |
| 拿一半（分割） | Space（对着鼠标下的那格） | Y |
| 整堆送到另一边 | Shift＋左键；背包页里是快捷栏 ⇄ 背包 | — |
| 放回拿着的东西 | Esc；拿着东西时 Esc 先放回，不关面板 | B（同上） |
| 在箱子区和背包区之间跳 | — | LB／RB |

- 放下的规则：空格＝放下；同种＝叠上去（叠满为止，剩下的继续拿在手上）；不同种＝两边对调（只有拿着整堆时才对调，拿着一部分时不让放并提示）。
- 拿起来的东西在放下之前**一直留在原来的格子里**，原格变淡、数字显示剩下的；手上的图跟着鼠标（手柄时贴在聚焦的格子旁边）。关面板、存档、崩溃都不会丢东西；原格被别处改了（整理、读档）就自动放手。
- 整理、放入手位、翻页、关面板之前先放回。
- 按住拖的规则：按下就拿起整堆；松手在别的格子上就放到那格（规则同下）；松手在格子外面就放回；按下又在原格松手＝点了一下，继续拿着，再点别处放下。已经拿着东西时，按下再在别的格子上松手也算放到那格。
- 箱子面板背包格子左边四个图标按钮（悬停有说明）：**全部放入**（背包里除快捷栏外的都放进箱子）、**放入同类**（只放箱子里已经有的那几种）、**全部取出**（取到背包满为止）、**取出同类**（只取背包里已经有的那几种，快捷栏里有的也算）。放不下的留在原处并提示。
- 【占位】图标先用文字代替：↑全、↑同、↓全、↓同、整理。你找到图标后换。
- 右下一行操作提示，随鼠标／手柄切换；刚才的操作没成功时右栏显示原因。
- 以前"点一格整堆挪过去"改成 Shift＋左键。

## 4. 储物箱

### 4.1 数据

- 箱子里的东西是背包子系统里的一个持久容器，名字 `Chest.<箱子编号>`，默认 40 格。箱子本身只记编号（"钥匙"），和 NPC 的背包组件同一个思路。
- 存档：背包块本来就存所有持久容器，箱子里的东西不用新加块。

- 地图上预先摆的箱子：直接把 `AMistStorageChest` 拖进关卡、填 `ContainerName`（不进摆放物存档）。本步没有测，关卡里也还没摆。

### 4.2 扩容

- 大箱子（以后由制造系统产出）拿在手上，对准一个小箱子交互 → 小箱子变成大箱子：**编号不变**，容器从 40 格扩到 80 格，里面的东西原样保留，换模型；大箱子这个物品消耗掉。
- 已经是大箱子的再套不上。能不能再拆回小箱子：【待定】现在不能。

### 4.3 名字、颜色、收起

- 转移面板右边：名字框（空＝显示物品名"小储物箱"／"大储物箱"）、颜色块＋"换颜色"（8 种循环，颜色表在 `MistRoost - Placement` 设置里，占位色）、"整理"、"收起箱子"。
- 收起：只有空箱子能收；箱子里有东西、或背包满了放不下箱子，按钮变淡，按了在面板里说原因，不动任何东西。收起后箱子这个物品回到背包，格子空出来，箱子的容器删掉。

## 5. 出货箱（第 3 步）

- "今天投了什么"改成背包子系统里的一个容器 `Shipping.Pending`，只收能卖的东西；睡觉前可以随时从面板里取回。
- 晚上出货子系统照常从这个容器结算，结算完清空。结算规则、结算面板、存档时机都不变。
- 交互弹窗两项：**打开**（转移面板）、**投入手上的**（手上一整堆直接投进去，就是现在的做法）。手上没有能卖的东西时第二项灰掉。
- 老存档：存档里原来的出货块，读档时搬进这个容器，不丢东西。

**【本步实现，L2】**

| 加在哪 | 做什么 |
|---|---|
| `UMistInventory`（Item） | 容器"收什么"：`EMistInventoryAccept`（什么都收／只收能卖的，看物品表的能不能卖／只取不放，09-28 随[回收箱](26-掉落物与拾取.md)加：玩家什么都放不进来，面板藏起"全部放入""放入同类"）。放进来的路——加物品、挪格、对调、批量转移——都照它挡；`SetSlot`（读档、调试）不挡。规则不存档，由容器的主人每次取容器时设上 |
| `UMistShippingSubsystem`（Economy） | 建容器 `Shipping.Pending` 并设"只收能卖的"；投入手上的（`SubmitStack`）、箱里的东西、件数、预计收入。空格少于 10 格就加一整行，所以出货箱不会满；过夜结算完清空、缩回 40 格（`MistRoost - Economy` 设置的 `ShippingBinCapacity`、`ShippingBinSpareSlots`） |
| `AMistShippingBin`（Economy） | 改为继承容器基类，所有出货箱共用这一个容器；弹窗两项 `ShipOpen`「打开」、`ShipHeld`「投入手上的」（`DT_InteractionOptions` 新加两行）。交互键执行第一项＝打开 |
| `WBP_Container` | 出货箱模式：标题"出货箱"、标题旁一行说明、"N 件物品将被运输／预计收入 X 金"；不显示格数；背包里不能卖的格子变淡，点了或拖过去提示"这个不能卖，放不进出货箱"、不动东西；改名、换色、收起不显示 |
| 存档 | 箱里的东西跟着背包块走（容器 `Shipping.Pending`）；出货块升到 v2、不再写东西，只为读 v1 老存档留着（20 篇 §4） |

- "投入手上的"画淡的原因：手上空着"手上没有能卖的东西"（选项表默认原因），拿着不能卖的东西"手上的东西不能卖"。
- 预计收入和晚上结算同一个算法：物品表售价 × 数量。
- 全部放入时不能卖的留在背包里，提示"不能卖的东西留在背包里"；背包里一件能卖的都没有时提示"背包里（快捷栏以外）没有能卖的东西"。
- 老存档里已删掉或已改成不能卖的物品：丢掉并记警告（和背包块处理删掉的物品一样）。
- "N 件物品将被运输"在左下（原来和储物箱的"名字""颜色"小标题叠在一起，已修好：出货箱时这两个小标题收起）。【占位】按键提示暂时和储物箱一样，§3 表里出货箱专用的提示没做。你重做界面时一起改。
- 手柄：弹窗第二项现在用手柄选不到（15 篇 §7 待定）；手柄玩家可以打开面板再放。

## 6. 玩家摆放的物件与存档（第 2 步）

**格子：查下来原来的"预留"只有这些**——物品类型里有 `Placeable`、瞄格子组件（`TileTargeting`）能瞄任意格、11 篇里写了摆放用的输入 `IMC_Placement`（没建）、田的设置里有静态的 `ExcludedTiles`。**没有"这一格被谁占了"的记录**，所以这一步在田的格子系统里加了一个：

| 加在哪 | 做什么 |
|---|---|
| `UMistFarmGridSubsystem`（Farming/Grid） | 占格表：`SetTileBlocked` / `ClearTileBlocked` / `IsTileBlocked` / `GetTileBlocker`，变了发 `OnTileChanged`；被占的格子不能开垦。占格表不存档，由摆放物读档时重新占上 |
| `UMistPlacementSubsystem`（Action/Placement，新） | 记玩家摆的每个物件：编号（生成后不变）、物品 ID、地图、格子、朝向、名字、颜色；生成／拿掉 Actor；占格；存档块 `Placement`（顺序 320，在出货箱之后）。以后的加工机器也走它 |
| `DT_PlaceableDefs`（新表，行名＝物品 ID） | Actor 类、占几格（本版只支持 1×1）、容器格数、由谁升级、只能升级、模型、缩放 |
| `UMistToolUseComponent` | 手上拿着 `Placeable` 类物品，对准一格按使用键＝摆下（成功才扣物品）；对准同种小箱子＝升级 |
| `UMistTileHighlightComponent` | 手上拿着可摆放物时也显示格子高亮，颜色表示能不能摆（新开关 `bShowForPlaceables`） |

- 能摆的条件：地面找得到、坡不超过 10°、格子没被占、没开垦、没作物、上面没别的东西挡着（坡度、探测高度在 `MistRoost - Placement` 设置里）。
- 角色（主角、NPC）只有站在那一格上才算挡路；身子擦到格子边不算（不然脚边那格永远摆不下）。
- 朝向：面向主角（四个方向取最接近的）。
- 读档：先回默认（拿掉所有摆放物），再按记录重建、重新占格；箱子里的东西在背包块里，背包块先读，箱子容器按编号对上。
- 储物箱是占位方块（小 0.8×0.6×0.6、大 0.95×0.7×0.7 米），颜色用材质参数 `Color`；图标是 AI 生成的占位图（`美术资产/UI/Items/Placeables/`）。
- 调试：`Mist.AddItem Chest_Small`（拿物品）、`Mist.Place <物品ID> [X Y]`（不扣物品直接摆在面前）、`Mist.Placement.Dump`。
- 制造系统还没有：箱子物品现在只能用调试命令拿。
