# 玩法 · 矿洞与战斗

> 状态：🌱 草稿 · 最后更新：2026-09-27
> 相关：[符咒系统](00-核心-符咒系统.md) · [岚气与岚兽](01-岚气与岚兽.md) · [主线剧情](../../../剧情/主线剧情/00-主线剧情.md)

## 原始设想（来自笔记）

- **矿洞玩法**：类似星露谷物语。
- **普通战斗**：主角通过**武器**战斗，武器带**词条**；类星露谷但**词条更多**。*(原「部分岚兽可协助战斗／挖矿」已随岚兽归档，改由**战斗符**承担，见下。)*
- **神兽事件**（2026-09-27 作者续订）：神兽不吃供奉，各有地界，受煞影响后在岚日现身，承担主角阶段性能力成长。**战胜后提高净化能力是候选实现**；数量与上限本轮不设。旧自封解封解释作废。

## 结构化拆解

### 探索与采集
- 逐层深入的矿洞；采矿产出矿石／宝石／材料。作者当前按 **120 层矿洞、第 60 层与火神相识、开放火神供奉**规划，若总层数变化另议，不自行改比例。
- 基础采矿、普通冶炼与前 60 层工具升级应先可用；天然矿脉的采集收益归技艺·采矿（[24 篇](24-技艺与经验.md)）；火神供奉给神授熔炉、精炼工艺、爆破符等（[06 篇](06-供奉与技能.md)）。
- **爆破符**（[符咒](00-核心-符咒系统.md)）可炸开矿石 / 矿墙 / 通路，作为镐子之外的稀有手段。

### 普通战斗
- 武器为主，**武器词条**系统（比星露谷更丰富）。
- 常规敌人＝**妖**（中煞的动物，黑化、更强力），详见 [岚气与神兽](01-岚气与岚兽.md)。
- **战斗协助**：战斗符的绘法统一来自五神供奉；神兽事件承担阶段性能力成长，也可提供附加线索与素材，见[符咒系统](00-核心-符咒系统.md)。
- **装备槽**：护甲、武器、饰品分开；饰品出生有 1 槽、有总上限（上限未定）。金神中期相识后，供奉可换饰品槽扩展、武器／工具附魔、加攻防的护身符与金钟罩符。槽位及数值唯一入口为[五神供奉](06-供奉与技能.md)。

### 神兽：阶段性能力事件，Boss 战为候选

神兽生存在自己的地界，后来受到煞影响，在岚日现身。五神告知玩家疏通办法，具体能力阶段见[岚气与神兽](01-岚气与岚兽.md)。

| 要素 | 当前方向 |
|---|---|
| 事件目的 | 处理神兽所受之煞，推动主角进入下一能力阶段 |
| 战斗定位 | 候选：压住失控、创造梳理机会；不默认击杀与夺取力量 |
| 净化手段 | 神明指导的疏通行动；通用净化能力与水系净秽符的分工待定 |
| 核心回报 | 阶段性能力提升；战胜后提高净化能力为作者提出的候选 |
| 附加反馈 | 目标与栖地恢复，可有材料、线索或猫狗氛围反馈，具体待定 |
| 进入 | 岚日现身；建议预告、目标保底、失败重试与错过重遇 |
| 数量 | 本轮不设数量与上限，不保留旧十只候选 |

建议先确定「本次学会处理哪种煞」，再反推事件与战斗设计。不能用尚未获得的阶段能力作为取得该能力事件的入场条件；同一阶段奖励不能靠重复战斗无限刷取。

神兽恢复后仍属于自己的栖地，不加入畜牧或协战。截气者的最终行动同样以救助为目标；是否设置战斗、如何稳定其爆发与处理积煞，另按剧情设计，不能默认最后一场必须杀死它。
