# 剧情事件与对话模板

> 类型：可复制模板 · 更新：2026-09-18 · 所有示例ID为占位，不是已定剧情或当前工程字段实现。

## A. 剧情规格

| 字段 | 填写要求 |
|---|---|
| QuestID / EventID / 版本 | 稳定ASCII ID；主线 `MQ-*`、支线 `SQ-*`；不复用已移除ID |
| 标题 / Owner / 评审人 / 状态 / 目标版本 | 草稿、已批准、实现和验证状态分别记录 |
| 玩家价值 / 情绪主题 / 正史依据 | 关联主线、世界观、系统和ADR |
| 范围／非目标 | 演出、配音、表情、地图、NPC新增项逐一列出 |
| 前置／触发／优先级／互斥 | 可计算条件、时间／地点／NPC占用与事件排队 |
| 状态与节点 | 每节点输入、条件、副作用、下一节点和错误回退 |
| 奖励与补偿 | 物品／货币／能力、满包处理、稳定领奖事务ID与幂等 |
| 保存／中断／重复 | 连续／累计、重置条件、切图／退出／跳过／读档 |
| 3D演出 | 站位、朝向、相机、动作／道具、遮挡、导航与归还控制 |
| 本地化／音频 | 文本键、上下文、发音、字形、配音是否在范围内 |
| QA／证据／批准 | 分支矩阵、BuildID、文档／代码／资产版本和结论 |
