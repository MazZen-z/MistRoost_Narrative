# 世界观术语与连续性规则

> 类型：叙事一致性基线 · 版本：1.5 · 更新：2026-09-27
> 上游：[世界观](../主线剧情/00-世界观.md)；神授之物归属以[五神供奉](../../策划/游戏玩法/系统/06-供奉与技能.md)为准，人自己的成长以[技艺与经验](../../策划/游戏玩法/系统/24-技艺与经验.md)为准。
> 本轮依作者要求同步世界观，不改变事件制作、保存、验收与本地化流程。上游标为建议的内容在本表仍是建议。

| 术语／事实 | 当前含义 | 边界与待决 |
|---|---|---|
| 岚栖 / MistRoost | 栖于岚之中，人、村庄与气的循环 | 不解释为岚兽栖息地；不是正式村名 |
| 气／岚／岚气 | 滋养这片土地、在山海间流转的气 | 五行是其不同作用，不是五种新能量 |
| 煞 | 气被长期截留、失去出路后变质 | 不把正常取用、短时蓄气、所有雾或所有秘境都叫煞 |
| 妖魔气息 | 煞的旧文档称谓 | 新剧情优先用煞，不再开一套邪气分类 |
| 五神 | 土、水、木、火、金五位本地气孕育的神，非受封正神，只能在本地界活动 | 不写成全知全能；不默认引入天庭官制 |
| 山神／土神 | 同一位，土树来源；前期相识，长期承担主线 | 土地与作物；形象未定 |
| 海神／水神 | 同一位，水树来源；与山神同在早期引入 | 钓鱼、水田、灌溉；不额外加一位水神 |
| 木神 | 木树来源，避世修行，待玩家寻访 | 木材、纤维、牧草、回复、基础精力；精确阶段未定 |
| 火神 | 火树来源，避世修行 | 120 层矿洞方案下第 60 层解锁；普通冶炼不能因此拖到 60 层 |
| 金神 | 金树来源，避世修行，中期解锁 | 饰品槽、附魔、攻防、增益符；不是财神 |
| 地气与香火 | 建议：地气维持存在与缓慢修行，供奉补充施力；山海持续助人而消耗更大 | 三神避世不等于不受本地衰败影响 |
| 供奉／祭祀 | 每隔两季的村落旧俗，献灵性作物、灵物与珍宝；后因港口挣钱方式增多、年轻人转向经商而逐渐少人参与 | 取消送饭；祭典频率不是供奉的等待周期 |
| 五神供奉 | 每神一份分阶供奉清单；交齐一份换一件神授之物（符咒绘法、强力设施、神授技法、土地改良、饰品槽、护身之物） | 2026-09-27 替代「五行科技树」：没有技能点和节点前置；不用全部净化进度代替供奉；叫「供奉」不叫「献祭」；清单与数值待定 |
| 技艺 | 人自己的本事：农事、畜牧、采集、采矿、钓鱼、制作六门，做什么涨什么 | 不是神授；普通配方、装饰物与少量精力／生命上限从这里来 |
| 饰品槽 | 出生 1 个，金树后续解锁更多，有上限 | 总上限未定；不据此推断武器、护甲槽数量 |
| 布雨符／降雨符 | 同一水系符的当前称呼与旧称；正文优先布雨符 | 早于自动浇水器；暂不新增两个效果相同的条目 |
| 金钟罩 | 金树增益／防护符的作者示例 | 时长、强度、正式条目名待定 |
| 净化 | 梳理已成之煞、帮助受影响的灵与气路恢复 | 五神指导、神兽事件带来阶段成长；战斗后提升为候选，水系符与通用净化能力的分工待定 |
| 符咒 | 玩家亲手绘制、依对应神授力借用五行权柄的消耗道具 | 公文可作银雀的比喻，不是神籍官制事实；不是万能解题工具 |
| 印 | 建议：承接并记录授力的媒介，银雀寄身处 | 不凭一个印跳过结识五神；不是血统证明 |
| 引岚／岚息 | 引岚为取用气的行为；岚息为玩家可用的气相关资源 | 旧每日量槽与作者「一颗岚息」用法尚需统一；半格／每日恢复量均未定 |
| 银雀 | 原「她／印里的老住户」的暂名；鸟形常驻伙伴 | 不是截气者；不是第六位受供奉的神；真实身份建议沿用山神信使关系 |
| 山雀形态 | 沿用的鸟形美术参考 | 不用现实鸟类冬季生存问题设主线期限；具体美术待定 |
| 截气者 | 低于五神层次的天然灵物，缺气后截留求生，被积煞折磨并不定期爆发 | 身份方向与救助目标已定；名称、形态、交流方式待定。镇物方案作废，不改回逐利囤积的对手 |
| 取与还 | 在生活、供奉、授力与气流通中体现的主题 | 表现生计转变与土地联系变淡，不将经商等同于应受惩罚；不用现代说教式对白 |
| 神兽 | 不吃供奉、各有地界的灵，受煞影响后在岚日现身；事件承担主角阶段性能力提升 | 数量与上限本轮不设；战胜后提升净化能力为候选；不沿用自封解封，不收作战斗宠物 |
| 秘境 | 隐藏或异常聚气的地点，可包含修行处与受煞气路 | 不一概由煞创造；神兽保留岚日现身，建议预告与保底避免无期限随机等待 |
| 岚日 | 异常气息外溢、受影响神兽现身的窗口 | 与截气者不定期爆发的具体对应待定；不据频率倒推通关季节 |
| 灵性作物／灵植 | 带灵性的作物，可用于供奉 | 不等于巨大作物；具体系统名与品类待定 |
| 巨大作物 | 气与土地恢复后的一种特殊生长表现 | 不作为前期供奉唯一来源；条件与数值待定 |
| 岚兽、技能石、契约符 | D-035 待定归档内容 | 不以灵兽等别名自动恢复旧养成系统；历史记录保留 |
| 主角 | 海外漂流上岸、村长安置半山老屋；性别与来处可自定义 | 暂留开局；未被煞感染，不写成隔离对象；来处命名待定 |
| 闹鬼 | 老屋异象，源于银雀的无损恶作剧 | 不毁作物、不夺关键物、不伤动物，不影响存档进度 |
| 猎户／猎人、大黄 | 既有支线角色职能与狗名 | 猎户正式人名、快速回家实现待定；不因本轮世界观改动重写其事件 |
| 半山庄园／村落／森林／海岸 | 沿用现有地理与布局方向 | 本次不改相机、地图合同或资产 |
| 海外来客 | 近海贸易与交流的世界空间 | 国别、命名、文化与商品待设计；不当作截气病因 |
| 季节与主线 | 四季均可推进、揭示真相与进入结局后生活 | 冬季不特殊削弱银雀，无结局期限；节点不因拖延永久失效 |

## 连续性审校

每章检查角色知识、既往事件、当前日程、已有能力、世界状态、选择后果与完成后对白。

本轮重点：

- 五神供奉的神授之物与神兽事件的阶段成长是否分清？不能把神兽降回只给素材，也不让它替神发放神授之物。
- 山海的衰弱是否同时体现补充不足与持续付出？三神是否被误写成完全不依赖本地？
- 供奉是否仍变相写成每日送饭、硬等两季或给全村定罪？
- 截气是否始于来气不足？爆发后是否仍缺稳定气源？救助是否同时解决积煞与生存需求？
- 是否残留器物出身、镇物机关或神兽自封的旧解释？神兽不吃供奉、各有地界、岚日现身是否保持一致？
- 第 60 层前是否可正常采矿冶炼？中期金树是否依赖自身附魔才能解锁？
- 是否还存在冬季结局、银雀冬季病危、固定神兽数决定通关季节的隐藏限制？
- 灵性供物是否能在世界完全恢复前获得？普通用气与截断循环有无明确区别？

## 翻译与演出交接

主线、支线、日常共用角色与地点 ID；玩家自定义性别、来处不写死。候选名与译名标 provisional；银雀是暂名，不自动锁定英文名称。文本键、配音、字幕、立绘与 3D 演出引用同一角色 ID。

术语可扩展中文、外文、词性、专名规则、发音、上下文、例句、批准人、变更日期；机器译文不自动定稿。
