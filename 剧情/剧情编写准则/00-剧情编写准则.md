## 1. 叙事支柱与边界

生活模拟是主体。主线保持**轻量、线性、碎片化、随玩家心情推进**；温馨惬意为主，失控岚气提供适度暗涌。主角是从海外漂流上岸、由村长安置到半山老屋的外来者，闹鬼传闻、印与银雀、五位地方神与村庄气路危机是当前主轴（2026-09-27 修订；原感染隔离开局仍作废）。世界观一律以 [世界观](../主线剧情/00-世界观.md) 为上游，本文与其冲突时以上游为准

“妖魔气息”即被长期截留、失去出路的气变成的**煞**。五位神生于本土地气、非受封正神；具体五行能力由对应神授予，银雀与印负责引导和承接。成长分两条：五神供奉给符咒绘法、强力设施与神授技法，人自己的手艺与体魄靠技艺（2026-09-27 作者续订，替代五棵科技树），不能仍写成只有净化进度一条成长线。**岚兽继续待定归档**。银雀暂名、双季祭祀与自由季节推进已确定。同日作者续订明确：港口开设后年轻人转向经商，农耕祭祀渐衰；截气者为缺气求生、受煞折磨的天然灵物，主线要救助它，镇物方案作废。神兽不吃供奉、各有地界，受煞影响后在岚日现身，承担阶段性能力成长；战胜后提高净化能力为候选实现，数量本轮不设。正式地名、形态、具体事件与救助演出仍待定。

- 村长与村民保持**友善、和蔼**；主角不得被写成村民忌讳、恐惧或隔离的对象。安置是一次性善意安排加自力更生，不是隔离、监视或债务奴役。
- 银雀的恶作剧**不得造成实际损失**（作物、关键道具、动物、存档进度）；屋内异象写成滑稽与温柔，不写成真实灵异或恐怖线。
- 主角的性别与来处是玩家自定义项，对白不得写死具体国名、地名或性别表述。
- 不靠强制赶日历、永久错过关键主线或长时间剥夺经营自由制造戏剧张力。取消冬季结局、银雀冬季特殊虚弱等旧限制；双季祭祀不得成为供奉唯一推进窗口。
- 重要信息可通过多次可发现的提醒／回顾获取；连续长对白、镜头锁定和自动推进必须有交互理由与跳过策略。
- 参考作品提供节奏或表现启发，不照搬角色、台词、事件链和世界设定。

## 2. 内容层级、正史与权限

| 层 | 唯一内容 | 审批责任 |
|---|---|---|
| 世界观／术语／时间线 | 岚气与煞、神明职权、神兽、地理、文化与事实边界 | 叙事负责人＋主策 |
| 主线 | 关键节点、因果、角色弧、能力与世界变化 | 项目／叙事负责人 |
| 支线／关系线 | 局部人物故事、前置与后果，不能覆盖主线事实 | 叙事负责人；涉机制需主策 |
| 环境／日常对白 | 生活细节、情绪与反馈，受已知事实和状态约束 | 对应作者＋叙事审校 |
| 运行时数据 | Quest/Event/Line ID、条件、状态、奖励、文本键 | 任务程序＋叙事设计＋QA |

概念图人物、摊位和装饰不自动成为已定NPC、商店或任务。草稿中的名字、国别、文化、职业必须标候选；正式正史变更进 ADR 与术语表，不在对白里静默修改。

## 3. 每条剧情的最低规格

`QuestID / EventID / 类型 / Owner / 目标版本 / 正史状态 / 玩家目标 / 主题与情绪曲线 / 关联主线与系统 / 场景与角色 / 前置条件 / 触发与排队 / 节点与分支 / 完成条件 / 奖励 / 中断恢复 / 重复策略 / 文本键与资产 / QA / 批准`。

- 主线先列节点与玩法锚点，再写场景节拍与对白；支线先列前置—冲突—行动—结果—奖励，避免只有段子没有可实现事件。
- 每个节点区分玩家可控制与系统接管，注明是否暂停时钟、是否允许移动、返回点与取消语义。
- 每个选择写清“表达性选项”或“状态性选项”；后者的变量、后续对话与回归范围必须可追踪。
- 关键分支写互斥与优先级，不能出现同时进入两段冲突剧情、NPC在两个场景或锁死下一节点。

## 4. 触发、状态、保存与奖励合同

推荐概念状态：`Locked → Available → Active → ReadyToComplete → Completed`；`Suspended/Failed/Cancelled` 是否需要由具体任务定义。这是接口设计合同，**不是宣称当前工程已经有该系统**。

| 合同 | 必须说明 |
|---|---|
| 触发 | 前置Quest/Flag、地点、时间／天气、好感／物品、NPC可用性与优先级 |
| 排队与互斥 | 同日多个事件、节日／主线冲突、玩家战斗／菜单／睡眠时的处理 |
| 重复 | 一次性、每日、可重试；冷却与连续／累计计数；重载不重抽关键结果的策略 |
| 副作用 | 扣物、发物、货币、能力、NPC关系、世界变化；失败补偿与事务边界 |
| 保存 | QuestID、节点ID、Flag、计数、已提交奖励ID、随机结果等最小持久状态 |
| 恢复 | 退出／崩溃／切图／读档／剧情跳过后恢复位置与下一合法节点 |
| 失效 | NPC不可达、资产缺失、满包、任务条件变更、旧存档引用已移除ID |

奖励采用稳定 `RewardTransactionID` 并保证逻辑幂等；不可仅依赖某句台词或某个动画 Notify 防重。需求指定“发一次”后由程序明确原子提交／补偿设计，QA覆盖领奖前后中断、重载和重复交互。

**大黄支线特别约束**：“连续三次”保留原文语义，不能擅自改为累计三次。何事重置连续计数、概率、剩肉数量、邮件到达和快速回家形式均待共同定案，未关闭前不能当成完整生产规格。

## 5. 对白与文本生产

- 角色卡包含动机、知识边界、说话节奏、称呼、禁用语和关系变化；同一角色不能因不同作者换人格。
- 先写对白目的和场景节拍，再写台词。避免NPC替游戏设计说明书说话；必要教程用可跳过且可回看的短反馈。
- 每行有 `LineID / StringKey / SpeakerID / SourceText / Context / Emotion / Gesture / VoiceCue / BranchCondition`；无配音的字段明确 `None`，不凭空扩大配音范围。
- 正文、选择、旁白、玩家指令、舞台说明分栏。舞台说明不混进玩家文本；程序不能把说明直接显示成对白。
- 用户可见文本使用可本地化数据与 `FText`，不把汉字显示文案硬编码进逻辑。文本键不随措辞变化，改剧情结构才评估是否换键并保留迁移。
- 文本长度按实机文本框、字号和目标语言测试，不拿中文字数直接推断英语显示长度。长文本、字体缺字、参数、换行和伪本地化是LQA门禁。

## 6. 3D 演出与跨专业协作

3D场景对白要给**站位／朝向／镜头合同／角色高度与眼神／动作与道具接触点／导航与碰撞／遮挡／时间和天气状态**。不能只交一段剧本便让地编猜走位。

- 默认遵循固定斜俯视镜头；特写或过场机位必须作为额外内容评审，不自动启用自由镜头。
- 场景须在最近／最远允许镜头都可读；说话对象、选项和任务目标不被树冠／屋顶吞掉。
- 使用已批准的动画、表情与道具列表；缺少动作就明确占位方案和补制任务，不把“情绪”字段等同于已做面部动画。
- 对话立绘、UI图标仍可为2D，美术全面3D指世界与实体资产管线，不取消合法的二维界面生产。
- 跳过演出必须执行必要的逻辑结算并归还输入／镜头／时间控制，不能跳过后困在隐藏UI或锁定角色状态。
- 音频按场景信息量和情绪需求登记触发与淡入淡出；有配音才建立录制版本、发音表、替换与回收预算。

## 7. 写作流程与评审门禁

| 阶段 | 产物 | 通过条件 |
|---|---|---|
| N0 梗概 | 主题、玩家价值、正史与机制关系 | 叙事负责人认可；非目标与未决可见 |
| N1 事件设计 | 节点图、状态／条件／奖励、3D演出规格 | 策划、任务程序、QA会签，可实现可测试 |
| N2 剧本与对白 | 台词表、文本键、角色一致性、资产清单 | 编辑审校、正史检查、范围预算通过 |
| N3 集成 | 数据导入、摆位、动画／UI／音频装配 | 无孤立节点、缺失ID或阻断；占位有标签 |
| N4 QA/LQA | 分支、重载、跳过、时间／天气／NPC互斥、本地化 | 所有必须路径有证据；关键缺陷关闭 |
| N5 锁定 | 对白／文本版本、资产／构建号、审批与变更记录 | 进入内容锁定；后改动明确回归和翻译影响 |

## 8. 叙事测试矩阵与 DoD

至少测：前置未满足／刚满足／已完成；重复交互；白天／夜晚／岚日；NPC被占用；背包满；对话中开菜单、退出、切设备；选项每条路径；跳过前后；领奖中断；读旧档；字体缺字与长文本；完成后世界状态、输入、时钟、镜头均正确恢复。

叙事DoD不是“文字写完”：正史审校、可实现数据、资产与许可、集成、分支／保存／本地化回归、证据与批准均完成，或有被明确接受且限制用途的原型例外。
