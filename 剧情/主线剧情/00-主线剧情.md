## 主轴（2026-09-19 按 D-034／D-035 修订）

> 开局反转见D-034；世界观定稿见D-035与[世界观](00-世界观.md)。原始笔记字节保留在迁移备份中，不因修订丢失。

**世界（一句话）**：山和海之间有一股气在来回走，走过哪儿哪儿就肥；村子富了以后不上香了，神弱了，一个没有名分的东西占了位子，把气截住只取不还——气就成了煞。

- 主角**从海外漂流上岸**；来处与**性别由玩家自定义**（来处用真实国名还是架空地名待决）。
- 村长在山滩发现主角，把他带到半山一间**没人要的老屋子**：「正好空着，别想太多，先住下。」
- 那屋子没人肯住，因为村里都说它**闹鬼**——其实是**印**里那位老住户的**恶作剧**。
- 村子给**一次性**启动帮助（口粮、旧农具、种子、指明山溪取水点与两块荒田），此后**自力更生**。
- 主角整理屋子时发现**一枚印**（他以为是戒指，太大戴不上，只能穿绳或套拇指），激活了寄寓其中的**她**——她**显形为一只银喉长尾山雀**。
- 她存在了很久，懂得很多，但**不白教**：主角帮她做事，她才教。她的真实身份是**山神座下信使、解印绶**，序章内不透露。
- 她教：**引岚**（收集气）、**符咒炼制**（借神的职分办事）、**净化**（把被煞困住的神兽放出来）；世界主线也有她参与。
- 庭院里藏着**净化的秘密**——秘密就是她。
- 之后：在**日常生活中**逐步解开**村子的秘密**、以及**气为什么变成了煞**。
- 结局：**把「只取不还」改回「有取有还」**，气重新流通，享受田园生活。
- 村长与村民一律**友善、和蔼**；主角不是被忌讳、被隔离或被监视的对象。

> **剧情节奏参考「静谧田园」。**

## 主线推进与年历（D-035 暂定）

| 季 | 主线 | 世界状态 |
|---|---|---|
| 春 | 落岸、安置、闹鬼、得印、学引岚与画符、第一个岚日 | 岚日「来得太勤」，村民说不清原因 |
| 夏 | 委托换教学；随岚日进秘境；遇见并净化前几只神兽 | 局部区域气开始回流，山神海神略微回力 |
| 秋 | **十只神兽最早在此季净化完毕**；神明职权恢复到可授高阶符 | 巨大作物回归，雾退，岚日风险下降 |
| 冬 | **真相与结局**：化外之物是谁、村子（和玩家）也是只取不还的一方 | 主线收束；岚日转为正常时令日 |
| 次年春 | **尾声**：时令日、村子的新规矩、小猫小狗满村跑 | 有取有还的日常 |

- **进度只有一条脊柱**：净化神兽 → 神力恢复 → 职分上升 → 气回地里 → 灵植／巨大作物。
- **岚日约 12–20 天／年**（3–5 次/季），每个岚日随机显出**一处**秘境，十只神兽据此推进；**保底方案未定**。
- **不锁日历**：以上为作者基线，按玩家完成节点的时间推进，不逼玩家赶季。

## 威胁定义（D-035 修订）

- 主线概括为「**探寻煞的来处**」。**煞＝被截住、只取不还的气**（旧称「妖魔气息」「失控岚气」，同指一物）。
- **病因三步**（详见[世界观](00-世界观.md)）：① 港口商业化，村子富了；② 上山下海烧香的人少了，山神海神神力稀薄；③ 一个**没有名分的化外之物**趁虚占了位子，把循环的气截住只取不还，气遂成煞。
- **表征**：动物中煞成**妖**（常规敌人）；地脉滞塞成**秘境**；**岚日**变勤；神明可见地衰弱；巨大作物绝迹。
- **不是天灾，也不是挖山填海**：「填海造港」只解释村子为什么富了，不解释气为什么坏。**不采用**「山的呼吸」「雾从谷底涨起」一类把岚日写成古老自然节律的说法。
- 主角在庭院里发现**净化**之法（印与她），正是化解这一威胁的钥匙。
- **主角没有被失控岚气感染**（D-034 删除）。他能住进那间没人肯住的屋子，是因为**没有别处可去**，不是因为体质特殊；恶作剧吓跑了所有有选择的人，吓不跑一个没有选择的人。
- **主题＝取与还**：化外之物是村子的镜子。主题只能落在民俗礼数与人物选择上，**不得出现现代环保话语**，**不得把化外之物写成外族／外国人／入侵者**。
- 主线**比重较少、线性、碎片化**；核心仍是生活模拟，推进「随玩家心情来」。

## 结构化梳理（叙事节点）

| 阶段 | 事件 | 玩法解锁/锚点 |
|---|---|---|
| 序 | 海上船难漂流上岸 → 村长发现 → 安置半山老屋 | 家园/农场起点；一次性启动物资 |
| 起 | 自力更生：开垦两田、修屋、取水、下山以工换物 | 种田、工具、采集；社交循环开端，并经捕兽夹引出 [猎户与大黄](../支线剧情/01-剧情碎片.md) |
| 承 | 屋内「闹鬼」→ 发现印 → 她显形 → **委托换教学** | 引岚、岚息读数、[符咒炼制](../../策划/游戏玩法/系统/00-核心-符咒系统.md) |
| 转 | 她的异常躁动＝岚日预报 → 第一个 [岚日](../../策划/游戏玩法/系统/10-季节与天气.md) → 她说「这雾，来得太勤了」 | 岚日认知与风险；秘境显形 |
| 合（日常中）| 随岚日进秘境、净化**神兽**（≤10），碎片化揭开**村子秘密 + 煞的来处** | [神兽 Boss 与净化](../../策划/游戏玩法/系统/05-矿洞与战斗.md)；神力恢复→职分上升 |
| 终 | **化外之物现身，真相与结局**：把「只取不还」改回「有取有还」 | 气重新流通；岚日转为时令日；巨大作物回归 |
| 尾 | 次年春：村子的新规矩、小猫小狗满村跑 | 结局后 sandbox 生活 |

序章（序→转）按**玩家完成前置节点的时间**推进，不锁日历；作者基线为住下到发现印 2 个事件、再到拥有岚息 2–3 个事件，一般 7–10 天完成，随后触发岚日并用 2–3 天收束。
