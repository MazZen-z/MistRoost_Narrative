## 三分钟看懂这里怎么组织

美术文档分三层，**一层只回答一个问题**。找东西先问自己是哪类问题：

| 我想知道… | 去哪 |
|---|---|
| **长什么样** — 风格、色彩、地图、角色气质、概念图 | [设计方向/](设计方向/README.md) |
| **怎么做** — 流程、规范、命名、预算、验收 | [美术准则/](美术准则/00-美术准则总纲.md) |
| **做到哪了** — 批次状态、未决问题、冻结项 | [生产台账/](生产台账/README.md) |
| **有哪些参考图** | [资产/](资产/README.md) |

**规则只写在准则里，数值只写在方向与合同里，进度只写在台账里。**

## 主流程

```text
                    ┌─ 设计方向（Art Bible）── 风格支柱、色板、参考
                    │
  ①需求/AssetID ──→ ②概念与规格 ──→ ③首件模板 ──→ ④首件验收 ──┬─ 不过 → 返工
                                    (A/B/C三画面        (硬门禁+评分)  │
                                     ＋拆解页)                        │ 通过
                                                                      ↓
                                                          ⑤冻结项锁定
                                                                      ↓
  ⑥批次立项(DoR) → ⑦生产 → ⑧切片导出 → ⑨UE导入装配 → ⑩同框验收(DoD) → ⑪归档＋资产卡
        ↑                                                                    │
        └──────────── 返工：改变量走五步法，不改成品资产 ←─────────────────────┘
```

详见 [美术准则总纲](美术准则/00-美术准则总纲.md)。
