# 美术

> 更新：2026-09-24 · 当前路线：**全面 3D**（负责人最终决定）× 珊瑚岛式固定鸟瞰镜头（透视 FOV 35°、Pitch −37.5°）
> 风格一句话：**现代中式淡彩青绿山水插画，以水彩晕染和纸本颗粒表现山岚，用暖白流云、灰青群山与低饱和海色营造田园生活感。**
> 本阶段目标：做一个有自己美术特色的 **Demo 拿去众筹**，第一个正式关卡是 [半山庄园](设计方向/04-首关-半山庄园.md)。
> 2D 分层场景路线（2026-09-20 至 09-24）已放弃，其文档已删除，见 Git 历史。

## 三分钟看懂这里怎么组织

美术文档分三层，**一层只回答一个问题**。找东西先问自己是哪类问题：

| 我想知道… | 去哪 |
|---|---|
| **长什么样** — 风格、色彩、地图、首关、角色气质、概念图 | [设计方向/](设计方向/README.md) |
| **怎么做** — 流程、相机与尺度、管线、命名、预算、验收 | [美术准则/](美术准则/00-美术准则总纲.md) |
| **做到哪了** — 批次状态、未决问题、冻结项 | [生产台账/](生产台账/README.md) |
| **有哪些参考图、原画简报** | [资产/](资产/README.md) |

**规则只写在准则里，数值只写在方向与合同里，进度只写在台账里。**

## 主流程

```text
                    ┌─ 设计方向（Art Bible）── 风格支柱、色板、参考
                    │
  ①需求/AssetID ──→ ②原画与规格 ──→ ③首件模板 ──→ ④首件验收 ──┬─ 不过 → 返工
                                    (A/B/C三画面        (硬门禁+评分)  │
                                     ＋拆解页)                        │ 通过
                                                                      ↓
                                                          ⑤冻结项锁定
                                                                      ↓
  ⑥批次立项(DoR) → ⑦生产(原画→建模→贴图) → ⑧导出 → ⑨UE导入装配 → ⑩同框验收(DoD) → ⑪归档＋资产卡
        ↑                                                                    │
        └──────────── 返工：改变量走五步法，不改成品资产 ←─────────────────────┘
```

详见 [美术准则总纲](美术准则/00-美术准则总纲.md)。

## 新人入门顺序

1. [美术准则总纲](美术准则/00-美术准则总纲.md) — 整条线怎么跑（10 分钟）

4. 按你的工种读对应管线：[3D场景](美术准则/02-3D场景资产管线.md) / [3D角色](美术准则/03-3D角色与动画管线.md) / [立绘UI](美术准则/04-立绘与UI资产管线.md)
5. [验收门禁与评分表](美术准则/07-验收门禁与评分表.md) — 什么才算做完
