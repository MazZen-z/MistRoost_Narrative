## 一、一句话目标

> **固定鸟瞰镜头下，成人比例的风格化 3D 角色，生活在一个"像被画出来的"3D 中式山海田园里。**

风格一句话（负责人原话）：**现代中式淡彩青绿山水插画，以水彩晕染和纸本颗粒表现山岚，用暖白流云、灰青群山与低饱和海色营造田园生活感。**

## 二、技术路线（已定）

| 内容 | 实现 |
|---|---|
| 世界 | **全 3D**：Landscape 地形 + 3D 建筑、植被、道具、作物、水 |
| 画意 | **手绘贴图承载水彩设色**（参照主角四件道具：原画 → AI 生模 → 贴图即画），实时灯光给时段，后期只做统一 |
| 主角与 NPC | 3D 骨骼角色，统一人体骨架 + Mutable 部件（[3D角色管线](../美术准则/03-3D角色与动画管线.md)） |
| 动物、神兽、猫狗 | 纯 3D，与角色同管线 |
| 镜头 | 珊瑚岛式固定鸟瞰：透视 FOV 35°、Pitch −37.5°、不可旋转，远近只在设置里选（[相机合同](../美术准则/01-相机与空间合同.md)） |
| 遮挡 | 挡住角色的树冠、屋顶自动淡出 |
| 仍是 2D 的 | 对白立绘、UI、图标、概念图 |

> **路线变更说明**：2026-09-20 曾改为"3D 角色 × 2D 分层手绘场景"，09-23 的卡片拼贴试片被判"无法投入生产"，09-24 的 3D 风格试片证明了"下载的现成 3D 包 + 后期"做不出目标画风。负责人最终决定全面 3D：团队熟悉 3D、人脉与素材都在 3D、UE 的优势在 3D；**画风靠自己的原画与贴图建立，不靠现成包的原画风**。2D 路线文档已删除，见 Git 历史。

## 三、不可随技术路线改变的风格支柱

这五条是**方向本身**。任何一条被违反，不管单看多好，都算不通过。

| 支柱 | 要看到 | 避免 |
|---|---|---|
| **中式日常生活** | 青瓦、夯土与木构、石坎、竹编粗陶、劳动服饰与工具 | 为"国风"堆宫殿飞檐；日式町屋障子；西式奇幻小屋 |
| **淡彩静谧** | 大色块、低饱和、柔和明暗、局部笔触与生活细节 | 强黑描边、塑料高光、写实扫描材质、高饱和热带色 |
| **山地与近海** | 半山错层庄园、连续山林、平整村落、森林与海岸贸易 | 把所有区域都做成陡坡，或把整座庄园铺平 |
| **招牌雾岚** | 衬托深度与冷暖的薄雾、暖白流云、灰青远山 | 用浓雾掩盖坏接缝，或遮住目标格与交互物 |
| **温馨与暗涌** | 日常暖色，与少量失控岚气（煞）的紧张对比 | 整体转成恐怖游戏或高饱和度假风 |

## 四、"像画出来的 3D"靠什么（执行层）

| 层 | 负责 | 规则 |
|---|---|---|
| 造型 | 剪影与体块 | 概括、质朴、略带手工不规则；小于约 5 cm 的细节画进贴图不建模 |
| 贴图 | **画意（主要来源）** | 水彩透明叠色、局部露底、颜料沉淀、有色勾线画在 BaseColor 里；不烘方向光 |
| 灯光 | 时间与体积 | 暖白日光、灰青阴影；不用高对比硬光 |
| 雾岚 | 深度与气氛 | 高度雾 + 局部雾体，远景灰青淡出 |
| 后期 | 统一 | 曝光与轻微调色；**关掉后期仍是同一风格** |

**画面成分预期：手绘贴图约 60% ＋ 风格化光照与雾岚约 30% ＋ 后期统一约 10%。** 任何一层越权都算违规——尤其是"用后期滤镜救贴图"。

> 2026-09-24 试过的"现成吉卜力风包 + 墨线后期 + 调色"一路，负责人判定与目标完全不沾边：
> 问题不在后期，而在**原包自带的造型语言、饱和色板与写实光影**。所以风格必须从原画与贴图建立。

## 六、审美批准标准

1. **游戏机位下同框**看到角色、农舍、植被、田与作物；单独渲染好看不算。
2. 标准档下**先读到**角色、道路与可交互物，**再读到**装饰细节。
3. **关掉后期和雾**，底层资产仍有淡彩手绘特征。
4. 日夜、行走、工具动作、屋顶与树冠淡出都成立。
5. 原画与确定资产**保留原始笔触**，不自动去噪、磨皮或增强。
6. **美术质量优先**：资源冲突时提方案，不自行降成廉价风格。

审美、技术、性能、复用**分别签核**。
