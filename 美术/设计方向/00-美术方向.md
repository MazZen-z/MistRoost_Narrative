## 一、一句话目标

> **固定鸟瞰镜头下，约六头身的卡通渲染 3D 角色，生活在一个明快、温润、有中式生活气的 3D 山海田园里。**

风格一句话（2026-10-01 负责人定方向，本轮授权按参考截图校正文案）：**以《风之繁华集市》的卡通角色、风格化手绘环境与饱满明快的设色为底，换上中式山居田园的建筑、器物与服饰；保留少量透明叠色与柔和色斑，去掉厚涂油画肌理。**

> 3.0 版的风格一句话（"现代中式淡彩青绿山水插画，以水彩晕染和纸本颗粒表现山岚……"）作废。负责人 2026-10-01 的判断：原方向过于理想化，做不出来；项目做到现在本来就更接近《风之繁华集市》，差的主要是插画式的描边。

## 二、技术路线（已定）

| 内容 | 实现 |
|---|---|
| 世界 | **全 3D**：Landscape 地形 + 3D 建筑、植被、道具、作物、水 |
| 画意 | **卡通渲染 + 手绘风贴图**：角色用简化卡通明暗；矿石、采集物等小中型交互目标保留概括的体积与材质色面，用细描边突出；场景用风格化造型与手绘风贴图，不统一描边。范围见 §四；实时灯光给时段，后期只做统一 |
| 资产来源 | 风格化植被、地编、通用小道具**优先购买**与主参考同类的商用包（核授权、校色、换母材质，见 [3D场景管线 §3.2](../美术准则/02-3D场景资产管线.md)）；中式建筑、器物、服饰和角色自己做 |
| 主角与 NPC | 3D 骨骼角色，**约六头身**，卡通着色 + 描边；统一人体骨架 + Mutable 部件（[3D角色管线](../美术准则/03-3D角色与动画管线.md)） |
| 动物、神兽、猫狗 | 纯 3D，与角色同管线 |
| 镜头 | 珊瑚岛式固定鸟瞰：透视 FOV 35°、Pitch −37.5°、不可旋转，远近只在设置里选（[相机合同](../美术准则/01-相机与空间合同.md)） |
| 遮挡 | 挡住角色的树冠、屋顶自动淡出 |
| 仍是 2D 的 | 对白立绘、UI、图标、概念图 |

> **2026-10-01 补充**：09-24 的结论"现成包做不出目标画风"，针对的是当时的吉卜力风包和淡彩水彩目标。目标改为《风之繁华集市》式卡通渲染后，市面上的风格化包与目标属于同一类，可以买来校色使用。造型仍要符合中式日常（剪影判断见 3D场景管线 §3.2），这一条不变。

## 三、不可随技术路线改变的风格支柱

这五条是**方向本身**。任何一条被违反，不管单看多好，都算不通过。

| 支柱 | 要看到 | 避免 |
|---|---|---|
| **中式日常生活** | 青瓦、夯土与木构、石坎、竹编粗陶、劳动服饰与工具 | 为"国风"堆宫殿飞檐；日式町屋障子；西式奇幻小屋 |
| **明快温润** | 饱满明快的大色块、清楚而柔和的明暗、暖阳、局部笔触与生活细节；保留一部分水彩感 | 灰白发闷的低饱和、油画厚涂笔触、纯黑粗描边、塑料高光、写实扫描材质、荧光色 |
| **山地与近海** | 半山错层庄园、连续山林、平整村落、森林与海岸贸易 | 把所有区域都做成陡坡，或把整座庄园铺平 |
| **招牌雾岚** | 衬托深度与冷暖的薄雾、暖白流云、灰青远山 | 用浓雾掩盖坏接缝，或遮住目标格与交互物 |
| **温馨与暗涌** | 日常暖色，与少量失控岚气（煞）的紧张对比 | 整体转成恐怖游戏或高饱和度假风 |

## 四、"像画出来的 3D"靠什么（执行层）

| 层 | 负责 | 规则 |
|---|---|---|
| 造型 | 剪影与体块 | 轮廓概括、体块清楚、边缘适度柔化，略带手工不规则；石头保留大切面，建筑保留结构直线，不把所有物体做成圆球。植被先有树冠层次，再有概括叶簇；针叶树保留分层枝片。角色约六头身；微细节处理见 [3D场景管线 §1](../美术准则/02-3D场景资产管线.md) |
| 贴图 | 固有色与笔触 | 饱满的大色块，加少量随材质变化的笔触、色斑和透明叠色；木纹、石面、叶片等结构仍可读。水彩感是本项目少量保留的选择，不要求湿画晕染、纸纹或大面积留白。不烘方向光、投影和屏幕描边；允许木板缝、叶脉等材质结构线，不画厚涂油画肌理 |
| 着色 | 明暗 | 角色以亮、暗两组概括明暗、过渡受控，保留面部与服装体积；矿石、作物与小道具允许柔和渐变和局部切面，不强制每件严格两档。场景常规受光，投影清楚而边缘柔和。暗部保留固有色色相，冷暖随环境光与时段变化，不统一染暖或染冷，不整体泛灰 |
| 描边 | 强化焦点轮廓 | **仅角色与小中型交互目标**（矿石、可破坏石块、树桩、小道具、采集花草、需突出识别的作物）使用克制的细描边；以固有色同色系深色为起点，避免纯黑粗边。地面、装饰草花、树冠、建筑、山体按场景处理，即使可砍伐或可进入也不自动描边；作物线条不得把整片田画成线网。交互识别同时依靠形状、配色和提示，不由描边单独承担 |
| 灯光 | 时间与天气 | 时段与天气由 Ultra Dynamic Sky／Weather 承担；白天暖阳、投影清楚，暗部不发灰 |
| 雾岚 | 深度与气氛 | 高度雾 + 局部雾体，远景淡出 |
| 后期 | 统一 | 曝光稳定（不能让自动曝光大幅漂移把颜色冲掉）、轻微 Bloom、可选远景景深；**关掉后期仍是同一风格** |

各层只做自己那一份，越权算违规，尤其是"用后期滤镜救贴图"。3.0 版"手绘贴图约 60% ＋ 光照与雾岚约 30% ＋ 后期约 10%"的比例自 2026-10-01 起不再使用。若描边或卡通着色最终由后期实现，验收时分开关闭调色、Bloom、景深、雾等气氛效果；另附关闭全部后期的诊断图，不以关闭核心着色后的画面要求其仍有完整描边与分档。

> 2026-09-24 试过的"现成吉卜力风包 + 墨线后期 + 调色"一路，负责人判定与目标完全不沾边：
> 问题不在后期，而在**原包自带的造型语言、饱和色板与写实光影**。所以风格必须从原画与贴图建立。

## 六、审美批准标准

1. **游戏机位下同框**看到角色、农舍、植被、田与作物；单独渲染好看不算。
2. 标准档下**先读到**角色、道路与可交互物，**再读到**装饰细节。
3. **关掉气氛后期和雾**，造型、固有色与贴图仍统一；核心描边／卡通着色若由后期实现，按 §四单独切换并记录。
4. 日夜、行走、工具动作、屋顶与树冠淡出都成立。
5. 原画与确定资产**保留原始笔触**，不自动去噪、磨皮或增强。
6. **美术质量优先**：资源冲突时提方案，不自行降成廉价风格。
7. **描边范围按 §四**，线条不淹没叶簇和作物；同时用轮廓、色块、阶段与提示保证交互可读性。

审美、技术、性能、复用**分别签核**。
