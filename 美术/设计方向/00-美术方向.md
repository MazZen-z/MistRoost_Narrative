## 一、一句话目标

> **固定斜俯视镜头下，正常比例的风格化 3D 角色，行走在分层手绘的 2D 世界里。**
> 画面有中式日常生活气、柔和设色与清晰的玩法可读性；角色、场景、对白立绘看起来属于同一部作品。

---

## 二、技术路线（已定）

| 内容 | 实现 |
|---|---|
| 主角与 NPC | **3D 骨骼角色**，统一人体骨架 + Mutable 部件系统 |
| 角色移动 | Motion Matching Loco（未过 Spike 则降级 BlendSpace / 状态机） |
| 世界场景 | **2D 纹理置于 3D 空间**，用 Masked Static Mesh Cards 承载 |
| Paper2D | 只用于需要逐帧播放的作物、动物与局部特效，**不承担整个场景的组织方式** |
| 碰撞 | 视觉面片与碰撞代理**分离**；角色坐标不为排序而改高度 |
| 对白 | **独立 2D 插画肖像**，不依赖 3D 脸部表情 |
| 镜头 | 固定斜俯视，正交，不自由旋转（参数见 [相机与空间合同](../美术准则/01-相机与空间合同.md)） |

> **路线变更说明**：2026-09-20 前的"完整 3D 环境"路线已退役。变更原因是小团队产能与画风控制力——手绘 2D 场景能直接把"中式设色手绘"画进贴图里，而不依赖复杂的实时着色器去模拟它。**角色仍是 3D**，因为角色需要换装、动作和玩法交互。历史文档见 [生产台账/历史](../生产台账/历史/2026-09-20-模板验证与修改方向-拆分前存档.md)。

## 三、不可随技术路线改变的风格支柱

这五条是**方向本身**，换引擎、换管线、换人都不变。任何一条被违反，不管单看多好，都算不通过。

| 支柱 | 要看到 | 避免 |
|---|---|---|
| **中式日常生活** | 青砖黛瓦、木构格窗、石坎、竹编粗陶、劳动服饰与工具 | 为"国风"堆宫殿飞檐；复制日式障子与町屋 |
| **静谧田园** | 大色块、柔和明暗、前后层次、局部笔触与生活细节 | 强黑描边、塑料高光、写实扫描材质、满屏噪点 |
| **山地与近海** | 半山错层庄园、连续山林、平整村落、森林与海岸贸易 | 把所有区域都做成陡坡，或把整座庄园铺平 |
| **招牌雾岚** | 衬托深度与冷暖的薄雾、适度光束、季节色 | 用浓雾掩盖坏接缝，或遮住目标格与交互物 |
| **温馨与暗涌** | 日常暖色，与少量失控岚气的紧张对比 | 整体转成恐怖游戏或高饱和热带度假风 |

## 四、风格关键词（执行层）

- **中式日常**，不堆砌宫殿、宫灯与符号化"古风"。
- **温暖、柔和、安静**，但保留少量冷色与雾气形成层次。
- 水彩、淡彩厚涂、有色线稿均可，但**必须统一轮廓强度与细节密度**。
- 角色是**正常比例风格化人物**，不使用临时 Q 版精灵作为比例模板。
- **地面安静、交互物清楚、远景柔和**——不能所有区域都同样抢眼。

> 场景线条最终用"淡彩有色线"还是"厚涂无描边"，是 **A-5 未确认问题**，V02 关闭。在此之前不批量铺线。

## 五、参考作品各取什么

| 参考 | 取用 | 不取用 |
|---|---|---|
| 哆啦A梦牧场物语 | 柔和水彩设色、绘画层次、人物与环境的统一感 | 不据观感断言其内部地形、shader 与资产结构 |
| Coral Island | 农场生活模拟的**生产组织**参照：角色/环境/动画/交互一起定标 | 不照搬角色语言、热带文化、内容规模或未公开参数 |
| 静谧田园类作品 | 幽静层次、氛围光、季节色、生活尺度 | 不照搬日式建筑、恐怖基调与剧情骨架 |

> 参考是用来**对齐判断标准**的，不是用来抄的。没有任何一个参考项目公开了可直接复刻的美术 SOP——本项目用自己的规范。

## 六、二维与三维的分工

| 走 2D 手绘 | 走 3D |
|---|---|
| 地表、建筑、植被、道具、远景、前景遮挡 | 主角、NPC、（倾向）岚兽 |
| 作物与动物（选型待 A-8 关闭） | 角色的换装、动作、工具交互 |
| 对白立绘、UI、图标、纹样 | — |
| 概念图与氛围图（服务设计，不构成生产合同） | — |

**农田仍是逻辑格子**：视觉由 2D 地表与状态层表现，格子数据不要求世界由一格一个 Actor 组成。

## 七、画面成分预期

> **画面 ≈ 手绘贴图（80%） + 柔和风格化光照（15%） + 全屏纸纹与设色（5%）。**

三层各司其职：贴图给笔触与设色，光照给体积与时间，后处理给纸感与统一。
**任何一层越权都算违规**——尤其是"用后处理滤镜救丑贴图"。

因为场景是 Unlit 的，这里的"15% 光照"主要指：**角色的独立灯光**、接触阴影、以及写进贴图与遮罩里的受控明暗。

## 八、审美批准标准

1. **同镜头同时**看到角色、农舍、代表植被、土地与作物；分别渲染好看不算整合通过。
2. 正常游戏窗口下**先读到**角色、道路与生活功能，**再读到**装饰细节；远近层次清楚。
3. **关闭辅助 LUT 和纸纹后**仍有中式设色手绘特征；不靠后期滤镜"统一"互相矛盾的资产。
4. 日夜、行走、工具动作、屋顶与树冠遮挡**都成立**；侧面与交互接触点可信。
5. 用户选定原图**保留原始笔触与细节**，不自动去噪、磨皮或增强。缺失原图先恢复，不以新图冒充。
6. **美术质量优先**：资源或预算冲突时提交解决方案，不自行改成廉价/低细节风格。

审美、技术、性能、复用**分别签核**。
