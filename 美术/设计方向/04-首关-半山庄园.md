## 一、这一关是什么

主角的庄园：**半山上的错层台地**，老屋靠山、院坝在前、一大一小两块田、山溪流过屋旁可取水，四个出口顺坡穿林。它是 v0.1 农场验证与众筹 Demo 的**第一张正式地图**。

世界观落点（[世界观](../../剧情/主线剧情/00-世界观.md)）：

| 关卡里的东西 | 世界观依据 |
|---|---|
| 老屋 | 山神把印托付给"最后一个还上山的人"，那人去世后**印留在半山那间老屋里**；"闹鬼"传闻是她在筛人 |
| 山溪与取水潭 | 山上小溪流经主角家附近，开局浇水来源（[地图方向 §一](01-地图方向.md)） |
| 山口石龛 | 岚日"往山口与滩头各放一碗饭"的旧规矩；上坡口是"山口" |
| 两块田 | "一块被认真种着的田，是气能歇脚的地方"；日后巨大作物（灵植）长在这里 |
| 竹林、屋右上杂物区 | 概念图《晨岚初耕》的屋后竹林；杂物区是台地最上一级，清理后成为装饰空间 |
| 鸡舍畜棚区 | 开局送一个鸡舍；畜牧系统的起点（[畜牧](../../策划/游戏玩法/系统/03-畜牧.md)） |

## 二、镜头与朝向约定

- 固定镜头**从南向北**看：屏幕上方 = 北 = 世界 **+X**，屏幕右 = 东 = **+Y**（[合同 §2](../美术准则/01-相机与空间合同.md)）。
- **地势朝北抬升**：前坎 → 大田 → 院坝 → 屋右上杂物区，一级比一级高，挡土墙面全部朝向镜头，不挡人（[合同 §8.1](../美术准则/01-相机与空间合同.md)）。
- 东侧落向海湾、西侧落向山中段采集区，这两个方向的落差从侧面看，不受朝北落差规则限制。
