# 角色与立绘设定

## 一、角色的气质定位

> **会干活的普通人，不是仙侠人物，也不是二头身吉祥物。**

| 要看到 | 避免 |
|---|---|
| 劳动服饰、工具、卷起的袖口、磨损的鞋 | 飘带、法器、过度装饰的"古风"套装 |
| 可信的体态与站姿，有重量感 | 摆拍姿势、悬浮感 |
| 风格化但正常比例，脸部可读 | 自动回到 2 头身 |
| 风格化，不是写实扫描 | 毛孔、写实皮肤次表面、塑料高光 |

**比例基准**：约 6 头身为既有试样起点，**最终以实机同框首件（V04）确定**。
**不得把概念图里的旧 Q 版人物当作模型合同。**

---

## 二、比例与屏幕存在感（AD 必须主动确认）

固定正交镜头下，角色在屏幕上的大小是**设计选择**，不是技术副产品。

按当前 [相机合同](../美术准则/01-相机与空间合同.md)（Ortho Width 1400，Pitch 40°）：

| 角色身高 | 屏幕像素高（1080p） | 占屏幕高 |
|---|---|---|
| 160 cm | 168 px | 15.6% |
| **170 cm** | **179 px** | **16.5%** |
| 180 cm | 189 px | 17.5% |

> **改角色身高对屏幕存在感几乎没用**（160→180 只差 21 px）。真正的旋钮是 **Ortho Width**：
> 1400 → 179 px ｜ 1200 → 209 px ｜ 1000 → 250 px
>
> 所以 V04 要判断的不是"角色多高"，而是"**这张画面里人该占多大**"。定了之后身高只影响碰撞、动作和门高等物理尺度。

## 三、NPC 的识别度原则

固定俯视、角色只占 16% 屏幕高——**脸是看不清的，识别靠轮廓**。

| 级别 | 识别手段 |
|---|---|
| 主角 | 完整换装范围；轮廓由玩家决定 |
| 核心 NPC | **独有轮廓**（发型、体型、标志服饰）+ 独立头脸 |
| 重要 NPC | 人工指定配方，**至少一个独有轮廓特征** |
| 普通 NPC | 共用部件库，但组合由美术指定 |
| 路人 | 才允许受控随机 |

> **重要 NPC 不得由运行时随机组合生成正式身份。** 一个有名字、有台词、玩家会记住的角色，必须有人为它拍板长相。

分级数量与立绘配额见 [3D角色管线 §5](../美术准则/03-3D角色与动画管线.md)。

## 四、立绘的定位

> **立绘是"看清这个人"的唯一机会。** 世界里看轮廓，对话时看脸。

| 要求 | 说明 |
|---|---|
| 身份一致 | 发型、肤色、服装语言、年龄感必须与 3D 角色一致 |
| 表情克制 | 生活气的表情，不是漫画夸张表情包 |
| 光线统一 | 全角色统一主光方向 |
| 构图统一 | 眼线高度、头顶安全区、肩线范围统一 |

C 画面（对白界面模板）的验收就是检查这一条——见 [立绘管线 §6](../美术准则/04-立绘与UI资产管线.md)。

## 五、主角换装与立绘的关系（V06 三选一）

| 方案 | 视觉后果 |
|---|---|
| A. 头肩构图 | 对白里几乎看不到服装，换装的表达全在世界里 |
| B. 叠加层 | 对白能反映帽子/外套/配饰，资产量与兼容性成本上升 |
| C. 身份肖像 | 对白始终是"这个人"，不反映当前穿着 |

**方向建议**：本项目主角换装是玩法内容而非叙事内容，**倾向 C（身份肖像）+ 必要时用 B 补关键剧情装**。最终由 V06 定，**未定前不批量制作主角换装立绘**。

## 六、岚兽

- 岚兽是**世界特征与陪伴感**的载体，不是战斗怪物图鉴。
- 视觉上要能与"失控的岚气"建立联系：雾感、微弱自发光、边缘不实。
- 实现方式（2D逐帧 / 3D烘焙 / 纯3D）是 **A-8 未确认问题**，V07 关闭，**倾向纯 3D**（与角色同管线，便于玩法交互）。
- 关闭前**不批量制作岚兽帧表或模型**。
