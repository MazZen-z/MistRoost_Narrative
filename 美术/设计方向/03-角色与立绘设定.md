## 一、角色的气质定位

> **会干活的普通人，不是仙侠人物，也不是二头身吉祥物。**

| 要看到 | 避免 |
|---|---|
| 劳动服饰、工具、卷起的袖口、磨损的鞋 | 飘带、法器、过度装饰的"古风"套装 |
| 可信的体态与站姿，有重量感 | 摆拍姿势、悬浮感 |
| 风格化但正常比例，脸部可读 | 自动回到 2 头身 |
| 风格化，不是写实扫描 | 毛孔、写实皮肤次表面、塑料高光 |
| 卡通着色 + 细描边（同色系深色），参照《风之繁华集市》（[美术方向 §四、§五](00-美术方向.md)） | 纯黑粗描边、写实明暗 |

**比例基准**：**约六头身**（2026-10-01 负责人定）。这是本项目的成人比例选择，不从截图推断参考游戏相机高度，也不声称俯视能把六头身变成同样的 Q 版比例。屏幕存在感与脸部可读性由本项目机位下的同框首件判断；看脸的镜头方案另定。V04 校身高与表现，不擅改已定头身。图生 3D 的平光输入仍保留六头身要求（[通用 v002 的 C 块](../../../美术资产/_提示词块/00-通用_v002.md)）。
**不得把概念图里的旧 Q 版人物当作模型合同。**

---

## 二、比例与屏幕存在感（AD 必须主动确认）

当前采用珊瑚岛式**固定鸟瞰透视镜头**（FOV 35°、Pitch −37.5°），以 [相机合同 §2](../美术准则/01-相机与空间合同.md) 为唯一参数来源。旧正交、Pitch 40°／50°、Ortho Width 与卡片时代的像素表全部退役，不再用于角色制作。

V04 按相机合同的最近、标准、最远三档实际截图比较，不在本文复制派生数值。合同中的像素高度是估算依据，最终看模型实测；不能以旧“只占屏幕 16%”为由忽略标准档和近档能看见的脸部、手部及衣褶。

**建模参考图用正视的弱透视／正交式视图，实机验收用合同鸟瞰机位**。两者用途不同：不把游戏机位的俯视构图套到人体三视图上。

## 三、NPC 的识别度原则

远档优先靠轮廓和大色块识别；标准与近档补充脸部、发型、手势和衣料的表现。脸部不承担唯一识别责任，也不能以“看不清”为由省略。

| 级别 | 识别手段 |
|---|---|
| 主角 | 完整换装范围；轮廓由玩家决定 |
| 核心 NPC | **独有轮廓**（发型、体型、标志服饰）+ 独立头脸 |
| 重要 NPC | 人工指定配方，**至少一个独有轮廓特征** |
| 普通 NPC | 共用部件库，但组合由美术指定 |
| 路人 | 才允许受控随机 |

> **重要 NPC 不得由运行时随机组合生成正式身份。** 一个有名字、有台词、玩家会记住的角色，必须有人为它拍板长相。

分级数量与立绘配额见 [3D角色管线 §5](../美术准则/03-3D角色与动画管线.md)。

### 3.1 主角首件设计提案（2026-09-22，未定稿）

参考已查看的工作区原图 `概念设计/主角/demo.png` 与 `概念设计/主角/带背景.png`（相对工作区根；不在文档仓库的可分发附件范围），渲染方式按 [美术方向 §四](00-美术方向.md) 的卡通着色与描边（原"绘画材质对齐主角道具基准"一句 2026-10-01 作废）。旧概念仅为构型参考，不提升为已验收角色。

**首轮保留**：温和但有行动力的年轻成年人；有重量感的劳动体态；蓬松短发；暖赭／灰青拼接短衣、暖麻白卷袖、灰蓝短腰带、束口七分裤、编织凉鞋。成年约六头身（2026-10-01 已定）。

**首轮整理**：碎发概括成清楚发块；补丁集中为少数可解释的修补；降低排线、毛边与满身污渍；衣摆止于大腿上部，腰带尾端短而有重量，手臂与裤腿有可读的间隙。背面继承同一衣片构造，不能只设计正面。

主角的辨识靠**发型剪影 + 冷暖拼接短衣 + 卷袖与束脚的劳动轮廓**，不靠繁复首饰。色值及肤色候选仅见 [色彩 §2.4](02-色彩与光线设定.md)。

剧情事实以 [主线](../../剧情/主线剧情/00-主线剧情.md) 为准：主角为海外漂流来者，性别与来处可自定义。本轮男性外观仅为沿用已有图的首件候选；女性及其他体型版本维持同一服装语言，不自动变成裙装或高跟鞋，也不锁死肤色。

旧概念胸前兽纹吊坠不能直接定义剧情中的“印”。首轮人体结构图先去掉鸟和吊坠；后续将印、绳和鸟分别设计。印按剧情应保留“像戒指但偏大”的特征，造型尚未批准；不添加发光神器、血统纹章或感染标记。

NPC 沿用同一绘画语言，靠年龄、体态、发型、衣摆和工作痕迹变化；样例职业只作视觉试样，不扩充正式 NPC 名单或商店功能。

可直接复制的中文／英文主角提示词、NPC 模板、三视图与部件模板见 [角色提示词块](../../../美术资产/_提示词块/04-角色_v001.md)。提示词是本提案的执行翻译，不能代替首件选图。

## 四、立绘的定位

> **立绘是"看清这个人"的唯一机会。** 世界里看轮廓，对话时看脸。

| 要求 | 说明 |
|---|---|
| 身份一致 | 发型、肤色、服装语言、年龄感必须与 3D 角色一致 |
| 表情克制 | 生活气的表情，不是漫画夸张表情包 |
| 光线统一 | 全角色统一主光方向 |
| 构图统一 | 眼线高度、头顶安全区、肩线范围统一 |

C 画面（对白界面模板）的验收就是检查这一条——见 [立绘管线 §6](../美术准则/04-立绘与UI资产管线.md)。

## 五、主角换装与立绘的关系（V06 三选一）

| 方案 | 视觉后果 |
|---|---|
| A. 头肩构图 | 对白里几乎看不到服装，换装的表达全在世界里 |
| B. 叠加层 | 对白能反映帽子/外套/配饰，资产量与兼容性成本上升 |
| C. 身份肖像 | 对白始终是"这个人"，不反映当前穿着 |

**方向建议**：本项目主角换装是玩法内容而非叙事内容，**倾向 C（身份肖像）+ 必要时用 B 补关键剧情装**。最终由 V06 定，**未定前不批量制作主角换装立绘**。

## 六、岚兽

- 岚兽是**世界特征与陪伴感**的载体，不是战斗怪物图鉴。
- 视觉上要能与"失控的岚气"建立联系：雾感、微弱自发光、边缘不实。
- 实现方式**已定为纯 3D**（2026-09-24 全面 3D，原 A-8 关闭），与角色同管线，便于玩法交互。
- 关闭前**不批量制作岚兽帧表或模型**。
