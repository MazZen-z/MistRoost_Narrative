## 〇、一句话原则

**画面 = 手绘水彩贴图（80%） + 柔和风格化光照（15%） + 全屏纸纹与设色 LUT（5%）。**
三层各司其职：贴图给"笔触与设色"，光照给"体积与时间"，后处理给"纸感与统一"。任何一层试图越权（比如用后处理滤镜救丑贴图）都会违反审美批准标准。

## 一、目标画风解构（对照参考截图）

| 特征 | 哆啦A梦牧场物语的做法 | 本项目对应策略 |
|---|---|---|
| 大色块底色＋局部晕染 | 泥土/草地 Albedo 直接画出深浅色斑与湿边 | 贴图规范强制"三层画法"（见 §三） |
| 无黑描边，靠深色湿边分界 | 贴图里画出 edge darkening（边缘沉积） | 贴图画出为主；可选极弱后处理线（淡墨色）辅助剪影 |
| 柔和低对比光照 | 弱两档光影，阴影是低饱和冷色 | 后处理光照提取 + 软阈值 Curve LUT，阴影染青灰/黛蓝而非压黑 |
| 纸张颗粒 | 全屏统一纸纹底噪 | 后处理纸纹层（Bousseau 公式），中式差异化用**宣纸纹理** |
| 高明度、中饱和 | 水彩式"浅底压深"设色 | 色板合同 + LUT 微调，禁止贴图直接用高饱和纯色 |
| 物件轮廓圆润、几何极简 | 模型只管剪影，细节在贴图 | 建模规范：低模+圆滑剪影，禁止用几何雕细节 |
| 远景柔化、雾感 | 远处褪色柔和 | 距离雾 + 雾岚系统（本项目招牌，反而要强化） |

**中式差异化抓手**（与原作拉开差距的地方，不靠改技术栈，靠内容与设色）：
- 纸：西式水彩纸颗粒 → **宣纸细纹＋极少量纤维丝**；
- 色：原作的欧系暖黄绿 → **中式设色**（黛瓦青、赭石、藤黄、竹青、月白），LUT 曲线按二十四节气/季节切换；
- 线：原作几乎无线 → 可在建筑木构、器物上保留**极细淡墨结构线**（画进贴图，不是后处理描边），呼应工笔"勾勒"；
- 雾：加入体积感雾岚与冷暖对比，这是原作没有的记忆点。

## 二、UE 渲染侧实现（后处理栈）

### 2.0 全局设置

- 项目仍走默认 Deferred 管线，**不改引擎源码、不自定义 Shading Model**（独立开发维护成本优先；后处理方案已满足需求）。
- 后处理材质统一 Material Domain = Post Process；涉及光照提取的层 Blendable Location = **Before Tonemapping**；纯装饰层（纸纹）可放 After Tonemapping 测试两种效果。
- 建议**锁定曝光**（Manual Exposure），水彩画风最忌自动曝光把设色冲掉。
- PostProcessVolume 设 Unbound，材质按 Blendable Priority 排序。

### 2.1 后处理栈顺序（自底向上）

```
[场景渲染]
  → PP1 风格化光照（软分档 + 阴影染色）   Before Tonemapping, Priority 0
  → PP2 剪影辅助线（可选，默认关）        Before Tonemapping, Priority 1
  → PP3 距离雾/远景褪色（若不用引擎雾）   Priority 2
  → [Tonemapper + 设色 LUT（Color Grading LUT）]
  → PP4 纸张覆盖（宣纸纹理）             After Tonemapping, Priority 0
```

### 2.2 PP1 风格化光照（核心）

1. **提取光照**：`Desaturate(SceneTexture:PostProcessInput0) ÷ Desaturate(SceneTexture:DiffuseColor)`，Clamp 0–1。得到纯光照灰度图（所有光源、阴影、AO 都包含）。
2. **软分档**：不要用 If 硬阈值。把光照灰度接入 **CurveAtlasRowParameter**（CurveLinearColor 存入 Curve Atlas）：
   - 曲线做 2–3 个"缓坡台阶"：暗部 0–0.35 → 平缓、中间 0.35–0.55 → 较陡过渡、亮部 0.55–1 → 平缓。台阶之间保留 0.05–0.1 的渐变宽度，这就是"水彩感"与"赛璐璐感"的分水岭。
   - 每条曲线=一种光照气质；春/夏/秋/冬/黄昏/夜各做一条，运行时按季节时段切换参数即可。
3. **阴影染色**：最终色 = `Lerp(阴影色 × DiffuseColor, DiffuseColor, 曲线输出)`。阴影色起始值：低饱和青灰 `(0.55, 0.62, 0.68)` 乘法叠加，禁止用黑色。
4. 输出接 Emissive。与 D-030 合同一致：贴图不烘阴影方向，时段色全部由这里与 LUT 承担。

### 2.3 PP2 剪影辅助线（可选开关）

- 论文的 Sobel 方案：SceneDepth 四方向偏移相减求和 → Multiply(范围 0.05) → Power(强度 2) → Clamp。
- 本项目参数偏好：**只用深度线，不用法线线**（法线线会在圆滑水彩物体上产生碎线）；线色=场景色加深 40% 的"淡墨"而非固定黑；强度 ≤0.3；线宽 1–2px 且随距离衰减（600→1000 单位 2px→1px，Clamp+RemapValueRange）。
- 用灰度噪声贴图扰动线宽（论文 §2.2.5）模拟手绘抖动。
- **默认关闭**，首件对比"无线 / 淡墨线"两版后由美术负责人签核定夺。

### 2.4 PP4 纸张覆盖（宣纸）

- 核心公式（Bousseau 2006）：`C' = C − (C − C²) × (d − 1)`，其中 d = 宣纸纹理灰度（0.5 为中性，需把贴图 remap 到约 0.8–1.2 区间）。凹处颜料沉积变深、凸处变浅，比简单 Multiply/Overlay 更像真纸。
- 纹理用屏幕空间 UV（TexCoord × 屏幕宽高比校正），tiling 以 1080p 下颗粒直径 2–4px 为准。
- 强度参数起始 0.10–0.15；给 UI 和天空用 Custom Stencil 排除（论文 §2.9 方法）。
- 宣纸纹理来源：扫描真实宣纸（4K、去光照、无缝化）或 Substance Designer 程序化（Clouds + Directional Warp + 少量纤维划痕）。

### 2.5 设色 LUT（Color Grading LUT）

- 用 UE 标准 Color Grading LUT（256×16）而不是自定义后处理，性能免费。
- 制作法：截取实机画面 → Photoshop 里叠中性 LUT 底图 → 调到目标设色（提亮、降对比、暗部偏青、亮部偏暖黄）→ 导出 LUT。
- 每季节一张 LUT，与 2.2 的光照曲线成对切换。
- 审美标准约定：**关掉 LUT 和纸纹后画面仍须成立**，LUT 只做最后 5% 的统一。

### 2.6 雾岚（招牌层）

- 近中景：ExponentialHeightFog + 少量体积雾，雾色随时段（晨雾偏月白、暮雾偏藤黄灰）。
- 远景褪色：可直接用引擎雾；如需"水彩留白"感，在 PP3 按 SceneDepth 将远景 Lerp 向纸底色（而不是雾色）——远山"化进纸里"是中式差异化的点睛。

## 三、贴图与材质生产流程（画面的 80%）

### 3.1 水彩贴图"三层画法"规范（所有手绘 Albedo 通用）

1. **底色层**：大色块平涂，明度 60–85%，饱和度 30–55%；同一物体不超过 3 个主色。
2. **晕染层**：同色系深 1–2 档，画湿边/色斑/深浅呼吸；笔刷用水彩湿边笔刷（PS：水彩类笔刷开传递+湿边；Procreate：水彩系）。斑块尺度要与游戏内像素密度匹配——以固定斜俯视实机截图为准校笔触大小，**先做 1 块 512 地块贴图进引擎校尺度，再量产**。
3. **沉积层**：仅在轮廓内侧、遮挡缝、地块交界画 edge darkening（深 2–3 档、低流量、窄）。这层代替描边。
- 禁止：直接叠照片纹理、写实材质扫描、自动滤镜"水彩化"、纯黑或纯白。
- 光照禁令（D-030）：不画太阳方向、投影、完整时段色；只允许克制的固有色明暗与 AO。

### 3.2 分层材质系统（量产一致性）

按论文的 Layered Material 工作流建一个小材质层库：

| 材质层 | 内容 | 用途 |
|---|---|---|
| ML_WatercolorBase | 手绘 Albedo + 颗粒微噪声（Triplanar 备选） | 一切物体的底 |
| ML_EdgeDeposit | 曲率/AO 驱动的边缘加深 | 贴图沉积层的程序化补充（下载资产改造时特别有用） |
| ML_Moss / ML_Dirt / ML_Weather | 苔藓、尘土、风化贴花层 | 中式庄园的岁月感；一处制作全场景复用 |
| MLB_MaskBlend | 顶点色/纹理遮罩混合资产 | 层间混合 |
- 主材质只留一个（M_Watercolor_Master），一切物体用实例＋层堆栈，避免材质失控。
- 下载资产（河边小路/花海/风车屋等）**必须**经过：替换为主材质 → 重画或重投影 Albedo 至三层画法 → 才能进正式场景；不允许原样混用（违反"写实扫描材质混搭"禁令）。

### 3.3 Substance Designer 程序化资源清单（一次制作全项目复用）

- T_Paper_Xuan（宣纸，4K，灰度，无缝）
- T_WatercolorGrain（水彩颗粒/色斑，用于 ML_WatercolorBase 微噪声）
- T_LineDistort（描边扰动噪声，若启用 PP2）
- 贴花：苔藓斑、水渍、青苔砖缝

### 3.4 建模与资产规范衔接

- 低模、圆滑剪影优先；硬转折处倒角，避免 Sobel/法线在锐边产生杂线。
- 剪影第一：模型审核先看纯色剪影图。
- 顶点色预留：R=边缘沉积强度、G=苔藓/风化遮罩、B=保留（与分层材质约定一致，写入资产交付合同时统一）。
- 植被叶簇用 Masked 卡片时，卡片贴图同样走三层画法，边缘留 2–3px 深色沉积以代替描边。

## 四、落地路线（建议的验证顺序）

1. **M0 纸上验证（0.5 天）**：拿现有任意场景截图，在 PS 里手动叠：软分档曲线 → 阴影染青 → 宣纸纹理 → 设色调整。确认目标观感成立后再动引擎（便宜且直观）。
2. **M1 后处理栈首件（2–3 天）**：空场景＋几何白模，搭 PP1/PP4＋LUT，接曲线 Atlas；验证 Before Tonemapping 与曝光锁定、TSR 的兼容性。
3. **M2 贴图首件（3–5 天）**：一块 512 地块（泥土＋草）＋一个粗陶罐，走三层画法进引擎，与 M1 叠加看整体；校准笔触尺度。
4. **M3 同框首件（1–2 周）**：按审美批准标准第 1 条——角色（现有试样）、农舍、植被、土地、作物同镜头；出"无线/淡墨线"、"纸纹 0/0.1/0.15" 对比图签核。
5. **M4 规范固化**：把签核后的参数、笔刷、色板写回[色彩与光线设定](../02-色彩与光线设定.md)与[2D场景资产管线](../../美术准则/02-2D场景资产管线.md)，本指南退役归档。

每一步的产出物：对比截图（开/关每一层）、参数表、GPU 耗时（stat gpu / ProfileGPU）。

## 五、常见坑速查

| 坑 | 症状 | 解法 |
|---|---|---|
| 后处理放 After Tonemapping 提光照 | 分档位置随曝光漂移 | 光照提取层必须 Before Tonemapping ＋手动曝光 |
| DiffuseColor 除零 | 自发光/天空处出现噪点 | 除法前对分母 Max(x, 0.001)，天空用 Stencil 排除 |
| 法线描边碎线 | 圆滑物体表面全是杂线 | 弃用法线线或大幅提高阈值；模型硬边倒角 |
| 纸纹在移动时"游泳感" | 屏幕空间纹理与世界脱节 | 正常特征，强度≤0.15 即可接受；不适则改世界空间 Triplanar 弱纸纹 |
| 贴图饱和度过高 | 叠 LUT 后变荧光色 | 贴图阶段就执行色板合同，LUT 不救色 |
| 分档在 TSR 下闪烁 | 台阶边界抖动 | 曲线台阶间保留渐变宽度（软阈值本身即抗闪烁）；必要时 r.TSR 参数微调 |
| 材质实例爆炸 | 每个资产一个特调材质 | 只允许层堆栈差异，master 唯一；进合同管控 |
