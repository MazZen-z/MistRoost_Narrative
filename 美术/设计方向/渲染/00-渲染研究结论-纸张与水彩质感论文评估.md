## 一、被评估的论文是什么

- **标题**：Creating an automated material system for a highly illustrative art style in a game setting
- **作者**：Delphine Decuyper（比利时 Howest — Digital Arts & Entertainment，Game Graphics Production 毕业设计，2021–2022）
- **性质**：本科毕业论文（graduation work），不是学术期刊论文；工程性极强，全程给出 UE 材质节点图，可直接照做。
- **成品演示**：作者在 ArtStation 上公开了对应工程成果 **「UE5 - 2D shader - Giant's Resting Place」**（搜索 Delphine Decuyper ArtStation 可见），即论文的"官方复刻项目"，可作为效果验证参照。
- **案例概念图**：Oswaldo KATO（pixiv id 550944）的水彩插画机器人场景。

### 论文完整技术清单（按原文结构）

| 模块 | 做法 | 关键点 |
|---|---|---|
| 描边 Outlines | 后处理材质里对 **SceneDepth 做 Sobel 边缘检测**，再对 **WorldNormal 做同样操作**取内部结构线，两者取 Max | Blendable Location 必须设 **Before Tonemapping**（避免 TAA 抖动）；线宽随距离用 Clamp+RemapValueRange 衰减（600→1000 单位内 4px→1px）；用灰度噪声贴图扰动线宽模拟手绘 |
| 卡通分档 Cel Shading | 后处理内用 **PostProcessInput0 ÷ DiffuseColor 提取纯光照信息**，再用 If 节点/Floor 分档/**Curve Atlas LUT** 三种方式做色阶 | LUT（CurveLinearColor + CurveAtlasRowParameter）方案控制力最强：档数、每档宽度和颜色全部可由曲线资产驱动 |
| 排线 Hatching | 屏幕空间叠加程序化排线纹理，用于暗部与 AO 区 | Substance Designer 程序化生成排线贴图 |
| 雾与距离淡出 | 后处理内按 SceneDepth 做远景褪色 | 模拟水彩画远景留白 |
| **纸张覆盖 Paper Overlay** | 后处理最上层叠加纸纹贴图（屏幕空间 UV） | 这是"整个画面像画在纸上"的关键一层 |
| 对象屏蔽 | Custom Depth / Custom Stencil 把特定物体排除在某后处理之外 | 可让 UI 层、天空或特定物体不受纸纹/描边影响 |
| 贴图自动化 | **UE Layered Material（分层材质）系统**：底层水彩层＋第二水彩层＋排线＋白色 RimLight＋苔藓贴花，按资产需要堆层 | 参考了 YAGER《The Cycle》的分层材质工作流；一套材质层库全场景复用 |
| 程序化纹理 | Substance Designer 制作**水彩纹理**（色斑/颗粒/边缘沉积）、排线纹理、苔藓贴花 | 水彩感主要靠这层纹理，不靠流体模拟 |
| 建模原则 | 几何只管剪影，细节全部交给贴图；刻意加入不完美（线宽波动、扭曲）避免"CG 感" | 引用 Guilty Gear 的经验：2D 感=艺术家式的刻意不完美 |

## 二、与目标画风（哆啦A梦牧场物语）的对照结论

对照两张参考截图（农田俯视实机图＋农舍场景图）逐项分析：

### 参考画风的实际构成

1. **水彩手绘贴图承担了 80% 的画面效果**——泥土的色斑、深浅晕染、草地的大色块、屋顶茅草的笔触，全部是画在 Albedo 里的，不是实时着色器算出来的。
2. **几乎没有黑描边**——物体边缘靠"水彩边缘沉积"（同色系深一档的柔边）区分，这与论文案例的铅笔描边风格明显不同。
3. **光照极其柔和**——没有硬卡通分档，接近"微弱两档+大量环境光"的状态；阴影是低饱和偏冷的色块，不是黑色。
4. **有轻微纸张颗粒感**——整个画面有统一的纸纹底噪，尤其在大色块区域（泥土地、草地）可见。
5. **饱和度中高、明度高、对比低**——典型水彩上色特征：先铺浅色再局部压深。
6. **远景/边缘有柔化**——截图边缘和远处有轻微的晕染感。

### 论文技术的取舍结论

| 论文模块 | 对本项目 | 理由 |
|---|---|---|
| 纸张覆盖后处理 | ✅ **直接采用**（改用宣纸/水彩纸纹理） | 与目标画风的纸感完全对应；实现成本极低（一张贴图＋一个后处理层） |
| 光照信息提取（PPInput0÷DiffuseColor） | ✅ **采用其技术，改造其风格** | 不做硬分档，改为用 Curve LUT 做**柔和的 2–3 档软过渡**，阴影染色而非压黑 |
| Curve Atlas LUT 控制色阶 | ✅ 采用 | 正是"设色"可控化的最佳载体，换一条曲线=换一种季节/时段色感 |
| 距离雾/淡出 | ✅ 采用 | 与本项目"雾岚"风格支柱天然契合 |
| Layered Material 贴图分层 | ✅ 采用（简化版） | 水彩底色层＋颗粒层＋边缘沉积层＋苔藓/污渍贴花，正是量产一致性的保证 |
| Substance Designer 程序化水彩纹理 | ✅ 采用 | 水彩颗粒、色斑、边缘沉积做成可复用的程序化资源，全项目共享 |
| Custom Stencil 对象屏蔽 | ✅ 采用 | 角色/UI/交互高亮可排除在纸纹与描边之外 |
| Sobel 深度+法线描边 | ⚠️ **弱化采用** | 参考画风无黑描边；但可用**极低强度+同色系深色（淡墨色）**的细线增强剪影可读性，做成可开关参数，实机对比后再定 |
| 排线 Hatching | ❌ 不采用 | 参考画风完全没有排线；且与"静谧田园"支柱冲突（满屏噪点感） |
| 白色 RimLight 层 | ⚠️ 备选 | 参考图中作物受光边缘有轻微亮边，可低强度试用 |

### 总结论

**这篇论文可以用，而且是目前公开资料里与本项目最匹配的一份 UE 全流程参考**——它的价值不在"照抄它的最终效果"（它的成品比目标画风更"素描/钢笔淡彩"），而在于它给出了完整可复制的四件套：**①后处理栈的搭建方法与节点细节 ②光照信息提取与 LUT 分档 ③分层材质量产工作流 ④SD 程序化水彩纹理**。把它的描边/排线模块换成"贴图水彩边缘沉积＋柔光照"，就是哆啦A梦牧场物语的路线。

**必须清醒的一点**：哆啦A梦牧场物语的画面美感主要来自**手绘贴图的质量**，后处理只是统一底色的"最后 20%"。论文本身也承认"贴图和材质才是卖出风格的关键"。因此资产生产流程的重心应放在贴图绘制规范上（见配套指南）。

### 关键理论/公式

- **Bousseau et al. 2006《Interactive watercolor rendering with temporal coherence and abstraction》**：经典水彩渲染论文，纸张颗粒-颜料沉积公式 **`C' = C − (C − C²) × (d − 1)`**（C=原色，d=纸纹噪声值）。这一个公式即可实现"颜料在纸面凹陷处沉积变深"的效果，应作为我们纸纹后处理的核心算法（比论文里的简单叠加更正确）。
- **《Towards Photo Watercolorization with Artistic Verisimilitude》**：wet-in-wet 湿画法边缘羽化的方向模糊做法。

## 四、风险与边界

1. **后处理≠风格**：审美批准标准第 3 条已约定"关闭辅助 LUT 和纸纹后仍有中式设色手绘特征"。纸纹、LUT 只允许做"统一与点睛"，禁止靠它掩盖贴图质量问题。
2. **Before Tonemapping 的代价**：光照提取要求后处理在 tonemap 前执行，需在验证场景确认与曝光/自动曝光、Lumen 的兼容性（建议锁定曝光）。
3. **TAA/TSR 与屏幕空间纸纹**：屏幕空间纸纹在相机移动时"纸不动画面动"，这是该画风的正常特征（哆啦A梦牧场物语同样如此），但需实机确认不晕眩；备选方案是纸纹强度调低至 0.05–0.1。
4. **性能**：论文实测该后处理栈在游戏场景可跑，但每叠一层后处理多一个全屏 pass；本项目固定斜俯视、场景规模可控，风险低，仍需按流程准则做 GPU 分析。
5. **论文性质**：这是毕业设计不是权威规范，其节点做法（如 If 节点分档）有更优替代（LUT），采纳时以本文档的取舍表为准。
