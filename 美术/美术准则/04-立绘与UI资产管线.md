# 立绘与UI资产管线

> 编号：ART-STD-005 · 版本：1.0 · 更新：2026-09-20 · Owner：立绘/UI美术（会签：美术负责人、程序、本地化）
> 类型：**流程规范**。
> 冻结等级：**冻结项 7**。

---

## 1. 这条管线的唯一验收标准

> **玩家看到对话框里的人，必须一眼认出这就是刚才在地里干活的那个人。**

立绘不是独立插画。它和 3D 角色是同一个人的两种呈现，发型、肤色、服装语言、年龄感必须一致。

---

## 2. 立绘画布与构图

### 2.1 尺寸

- **先按 UI 实际显示尺寸确定 Master**，不要用"统一 1024 以上"这种没有依据的标准。
- 建议保留 **2048 级分层 Master**，再按 UI 导出适合尺寸。
- 立绘**不适用**世界贴图密度规则（那是 3D 场景资产的规则，见 [相机合同 §5](01-相机与空间合同.md)）。

### 2.2 全角色统一项

以下四项必须全项目统一，否则切换角色时画面会跳：

| 统一项 | 说明 |
|---|---|
| 眼线高度 | 所有角色的眼睛落在同一条水平线上 |
| 头顶安全区 | 头顶到画布上沿的留白一致 |
| 肩线范围 | 肩膀宽度与下沿裁切位置一致 |
| 光线方向 | 主光方向一致，不逐张自由发挥 |

### 2.3 表情切换

表情切换时**头部、眼睛、肩膀不得跳位**。做法：表情作为**分层替换**（眼/眉/嘴），不是整张重画。

### 2.4 文字

**普通文本一律不得烘进图片。** 理由：本地化、字号调整、排版修改都会因此变成重画。
可烘进图片的只有：作为美术元素的纹样、招牌上的装饰性字（且必须登记，本地化时单独处理）。

---

## 3. 表情集合

通用核心表情：

| 表情 | 代码 |
|---|---|
| 中立 | `Neutral` |
| 开心 | `Happy` |
| 担忧 / 难过 | `Concerned` / `Sad` |
| 生气 | `Angry` |
| 惊讶 | `Surprised` |

- 角色专属表情按剧情增加。
- **不是每名 NPC 都机械生产同样数量。** 数量由 [NPC 分级](03-3D角色与动画管线.md) 和剧情实际用量决定。

---

## 4. 主角换装同步（必须三选一并固定）

主角会换装，立绘要不要跟着变？三个方案，**选一个，写死，然后才允许批量生产**：

| 方案 | 做法 | 代价 |
|---|---|---|
| **A. 头肩构图** | 立绘只展示头肩，尽量减少服装可见区域 | 构图受限，服装是卖点时吃亏 |
| **B. 叠加层** | 帽子、外套、配饰做立绘叠加层 | 每件装备多一份立绘资产，组合要验兼容 |
| **C. 身份肖像** | 对白固定用身份肖像，**不承诺反映当前穿着** | 最省；玩家可能觉得不一致 |

**未选定前，不批量制作主角换装立绘。** 关闭批次 **V06**。

## 5. UI 与图标

### 5.1 原则

- UI 与世界画面**共享色板**（见 [色彩与光线设定](../设计方向/02-色彩与光线设定.md)），但 UI 的对比度要更高——UI 要在任何时段任何天气下可读。
- 图标在**实际显示尺寸**下验收，不看 512 大图。
- 夜晚、雨雪、雾天下 UI 可读性必须单独检查（见 [验收门禁](07-验收门禁与评分表.md)）。

### 5.2 导入预设

| 类型 | sRGB | 压缩 | Mip |
|---|---|---|---|
| 立绘 | 开 | UserInterface2D | 视需要 |
| UI 元件 / 图标 | 开 | UserInterface2D | **关** |

### 5.3 画幅检查

至少检查 **16:9** 与**一个较窄画幅**。窄画幅下立绘不能被对话框吃掉脸。

---

## 6. C 画面（对白界面模板）交付清单

同一角色，一次交齐：

1. 3D 世界中的角色截图
2. 中立立绘
3. 开心 / 悲伤 / 生气中的**两种**表情
4. 实际对话框：姓名 + 正文 + 选项按钮
5. 16:9 正常画幅
6. 至少一个较窄画幅检查

缺任何一项，C 画面不算完成。

---

## 7. 常见错误速查

| 症状 | 原因 | 对策 |
|---|---|---|
| 换角色时画面"跳" | 眼线/肩线不统一 | §2.2 |
| 换表情时头在动 | 表情整张重画 | §2.3 分层替换 |
| 本地化要重画立绘 | 文字烘进了图 | §2.4 |
| 立绘和 3D 角色不像一个人 | 没做 C 画面同框验收 | §6 |
| 图标在游戏里看不清 | 只在大图下审过 | §5.1 按实际尺寸验收 |
