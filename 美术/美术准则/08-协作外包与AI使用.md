# 协作、外包与 AI 使用

> 编号：ART-STD-009 · 版本：1.0 · 更新：2026-09-20 · Owner：制作/资产管理（会签：美术负责人、法务口径）
> 类型：**流程规范**。长期项目一定会有外部产能进出，规则要先于第一次合作存在。

---

## 1. 外包首件合同

**永远不要一次性发包一整批。** 流程固定为三段：

```text
①试稿（1件，付费）→ ②首件（1件，完整走一遍管线）→ ③批量
```

### 1.1 发包前必须给到对方的材料

| 材料 | 出处 |
|---|---|
| 风格定义与参考 | [设计方向](../设计方向/00-美术方向.md) |
| 色板 | [色彩与光线设定](../设计方向/02-色彩与光线设定.md) |
| 相机与尺寸合同 | [相机与空间合同](01-相机与空间合同.md) |
| 该类资产的管线规范 | [2D场景](02-2D场景资产管线.md) / [3D角色](03-3D角色与动画管线.md) / [立绘UI](04-立绘与UI资产管线.md) |
| 命名与交付格式 | [命名目录与资产卡](05-命名目录与资产卡.md) |
| 验收标准 | [验收门禁与评分表](07-验收门禁与评分表.md) |
| **一件已通过的同类参考资产**（含源文件） | 台账 |

最后一项最重要：**给一件做对了的东西，胜过十页规范。**

### 1.2 分阶段评审点

| 阶段 | 评审什么 | 拒收后果 |
|---|---|---|
| 草图 / Blockout | 构图、比例、轮廓 | 改，不计入交付 |
| 中期 | 色彩、细节密度、层级 | 改 |
| 交付 | 全套硬门禁 + 评分 | 返工或拒收 |

**不在评审点上的中间修改不接受**——否则会变成无限沟通。

### 1.3 交付必须包含

源文件（可重新导出）· 导出件 · 资产卡 · 授权声明 · 同框截图。
**缺源文件的交付一律不接收**，无论成品多好看。

## 2. 授权与来源

| 来源 | 要求 |
|---|---|
| 自绘 | 记录作者与日期 |
| 已购 | 保留发票/许可证文本，记录许可范围（是否可用于商业、是否可再分发） |
| CC0 / 免费 | 记录来源 URL、下载日期、许可文本快照 |
| AI 辅助 | 见 §3 |

- 第三方原包放 `下载资产/`，**保留原始包**，不直接当已验收资产。
- 授权信息写进资产卡，**不只存在某个人的记忆里**。
- 许可存疑的资产一律不进正式内容。

## 3. AI 协作的边界

AI（含本项目中的 Claude Code、图像生成工具）在本管线中的定位：

> **AI 是能力和数据，不是批准。**

### 3.1 允许

- 生成概念图、氛围图、构图草案、配色试验
- 辅助切片、批量重命名、格式转换、检查脚本
- 起草与整理文档
- 探查引擎状态、生成报告

### 3.2 禁止

- **持有任何批准权**。AI 不签 DoD、不判硬门禁通过。
- 自动扩大工作范围（未被要求就改别的资产）。
- 执行下载脚本或引入未审查的第三方内容。
- 用 AI 生成结果直接充当最终运行资产**而不经过人工统一**（笔触、轮廓、细节频率必须回 Photoshop 统一，同 [2D场景管线 §10](02-2D场景资产管线.md) 对预渲染的要求）。

### 3.3 必须记录

AI 参与的资产，资产卡必须写清：

| 字段 | 内容 |
|---|---|
| 工具与版本 | |
| 提示词 | 完整保存 |
| 人工修改范围 | 改了哪些部分、改了多少 |
| 原图 | 保留，**不自动去噪、磨皮或增强** |

**用户选定的原图保留原始笔触与细节。** 缺失原图先恢复，不以新图冒充。

### 3.4 概念图的效力

概念图**服务设计，不构成生产合同**。

概念图不证明：模型拓扑、UV、碰撞、许可、性能，也不自动扩充已确认的 NPC 名单、职业或商店功能。概念图里的人物比例、光影、器物是参考，不自动成为资产规格。

## 4. 多人协作的文件纪律

| 规则 | 理由 |
|---|---|
| 二进制资产**按唯一 Owner 串行编辑** | UE 资产、PSD 无法合并 |
| 评审前**冻结本批 AssetID、文件与导入预设** | 否则评的和交的不是同一个东西 |
| UE 内改名**只用编辑器**，走重定向与依赖检查 | 文件管理器改名会断引用 |
| 提交时附**依赖清单** | 回滚时要能一起回 |

---

## 5. 一人多职时的诚实原则

小团队一个人兼多职是常态。规则是：

- **兼任必须在任务单注明**，不能凭空填写不存在的人员签字。
- 大型工程的门禁与追踪**保留**（它们的价值不来自人数）。
- 不制造虚假多部门会签，但也**不因为只有一个人就跳过评审**——[隔天复看规则](07-验收门禁与评分表.md) 就是为一人项目设计的。
