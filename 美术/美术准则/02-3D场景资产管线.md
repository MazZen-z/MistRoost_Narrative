# 3D场景资产管线

> 编号：ART-STD-003 · 版本：3.6 · 更新：2026-10-01 · Owner：TA（会签：美术负责人、场景美术、关卡）
> 类型：**流程规范**。场景里的一切（地形、建筑、植被、道具、作物、水、远景）怎么从一张原画变成关卡里能用的 3D 资产。
> 前置：[相机与空间合同](01-相机与空间合同.md)（尺度、密度、关卡度量、遮挡规则）。
> 取代：v2.0《2D场景资产管线》（2D 分层卡片路线，2026-09-24 随全面 3D 删除，见 Git 历史）。
> 冻结等级：**冻结项 3/6**。

---

## 1. 一句话原则

> **造型管剪影，贴图管画意，灯光管时间，后期只做统一。**

- 固有色与笔触**画进 BaseColor**，不靠后期滤镜去"模拟"。风格以 [美术方向](../设计方向/00-美术方向.md) 的主参考（《风之繁华集市》）为准；2026-10-01 起四件道具不再是美术标准。
- 模型只负责在游戏机位下读得清的剪影与体块；小于约 5 cm 的细节在 12–21 m 外看不见，**画出来，不建出来**。
- 光照是实时的：贴图里**不烘死方向光和投影**，否则一到夜晚就穿帮。

## 2. 资产分类

| 类型 | 例子 | 核心规则 |
|---|---|---|
| **地形** | 山体、台地、坡、溪床 | Landscape + 高度图；台地与田块内部水平（[合同 §6](01-相机与空间合同.md)） |
| **地表材质** | 草、泥路、夯土院坝、石板、田土 | 可平铺材质层 + 宏观变化；田土层只管画面，能不能种由关卡田块决定（[合同 §7.1](01-相机与空间合同.md#71-田块可耕区)） |
| **状态层** | 翻耕、浇水、积雪、泥泞 | **数据驱动**的贴花或材质参数，不画进基础地面 |
| **关卡套件** | 石坎、挡土墙、台阶、篱笆、田埂、水沟、踏石、小桥 | **模块化**，1 m 网格对齐，按 §4.3 规格 |
| **建筑** | 主角老屋、柴房、鸡舍、门楼、院墙 | 主立面朝南（朝镜头）；屋顶与檐廊可被淡出 |
| **植被** | 树、竹、灌木、草丛、花 | 树冠与树干同一资产但材质支持淡出；草走 Foliage／Landscape Grass |
| **道具与可交互物** | 出货箱、水缸、取水石台、晒架、石磨、神龛 | 底部中心 Pivot，带交互锚点与简单碰撞 |
| **作物** | 萝卜、玉米、辣椒各阶段；巨大作物 | 每阶段一个网格，Pivot 一致（§8） |
| **动物** | 家畜、猫狗、神兽 | 纯 3D 骨骼，与角色同管线（[3D角色管线](03-3D角色与动画管线.md)） |
| **水** | 溪流、池塘、海 | 样条网格／水体材质；取水点有可站立的岸 |
| **远景** | 远山、海、云岚 | 低模或远景卡片（常规 3D 远景手法），只在远档与地图边缘出现 |

## 3. 四条来源

| 路 | 适用 | 流程 |
|---|---|---|
| **A. AI 生模**（Tripo 等） | 道具、作物、单体建筑、石块、小件 | 原画 → 生模 → **清理**（§3.1）→ 贴图去光与统一 → 导出 |
| **B. 外包建模** | 主角老屋、关卡套件、复杂建筑、角色 | 原画 + 三视图 + 规格表 → 草模评审 → 中模 → 交付（[协作外包](08-协作外包与AI使用.md)） |
| **C. 第三方包改贴图** | 剪影合用的植被、石头、通用道具 | **先核授权** → 剪影判断 → 重画贴图 → 换母材质（§3.2） |
| **D. 自制**（Blender） | 白模、模块套件、简单件 | 直接按本管线 |

### 3.1 AI 生模的清理清单（主角道具已验证过这条路）

`美术资产/主角物品/工具/` 四件道具是 A 路线的历史实例，**只说明流程，不定义新资产风格或技术预算**：既有记录为 Tripo 输出约 1.0–1.1 万三角面、最长边归一到 1 m、带一张 4096² 烘焙贴图（打包进 `.blend`，本轮未重测）。正式入库前逐项做：

1. **缩放到真实尺寸**（生模统一归一化，锄头不是 1 m、水壶也不是）。
2. **减面／重拓扑**到 [性能合同 §2](06-性能预算与技术合同.md) 的档位；关节类、会变形的件必须重拓扑。
3. **检查 UV**：自动 UV 的碎岛会让重画贴图极难，需要时重展。
4. **贴图去光**：原画里的方向光和投影被烤进了贴图，要去掉或减弱到只剩柔和的固有明暗。
5. **统一色板**：按 [色彩与光线](../设计方向/02-色彩与光线设定.md) 的现行约束及新首件校色，不照旧道具 HEX 或旧明度范围。
6. **贴图降到合同密度**（[合同 §5](01-相机与空间合同.md)），4096² 对 1 m 道具是 8 倍余量。
7. 源文件（原画、生模原件、清理后工程）全部保留，资产卡记工具与提示词。

### 3.2 第三方包改贴图的接入清单

> 2026-10-01（美术方向 4.0）：风格化植被、地编、通用小道具**优先购买**与主参考同类的商用包，按下列清单接入；中式建筑、器物与角色自己做。

1. **授权**：原包与许可证放 `下载资产/`，许可范围写进资产卡；**许可存疑的不进正式内容**。
2. **剪影判断**：只看模型在游戏机位下的剪影与体块是否符合设计方向（中式日常、低矮质朴）；西式、奇幻、高饱和造型只改贴图救不回来。
3. **贴图**：风格已与主参考同类的包，用 `MF_Env_ColorAdjust` 校进色板即可；风格不同的，按 §5 重画 BaseColor，不直接调色了事。
4. **换母材质**：换到本项目母材质（§6），这样才有遮挡淡出通道；原包材质不接淡出。
5. **尺度与 Pivot**：按真实尺寸与本项目 Pivot 规则重设。
6. **碰撞与锚点**：重做简单碰撞，补交互锚点。

## 4. 建模规则

### 4.1 通用

| 项 | 规则 |
|---|---|
| 单位与尺度 | 1 UU = 1 cm，**真实尺寸**，导出前核对 |
| 朝向 | 资产正面朝 **+X**（UE 惯例）；关卡里要正对镜头的件摆 **Yaw 180°** |
| Pivot | 独立件：底部中心；模块件：模块网格角点 |
| 剪影 | 在 [合同 §2.1](01-相机与空间合同.md) 标准档的屏幕尺度下验剪影；大体块倒角要圆润，避免 CG 硬边 |
| 背面 | 固定机位看不到朝北的面：**不可移动的布景件**朝北面可降贴图档、简化；**可旋转摆放的件**（家具、加工器）四面完整 |
| 面数 | 只引用 [性能合同 §2](06-性能预算与技术合同.md)，本节不另设数字 |

### 4.2 建筑

- 主屋、柴房、鸡舍等：**墙体 / 屋顶 / 檐廊 / 门窗**分开，屋顶与檐廊能单独淡出。
- 门洞、台阶、窗台按 [合同 §6](01-相机与空间合同.md) 度量。
- 内部：v0.1 只做"开放式卧床凹间"一类从院子能直接看见的内部，不做完整室内。

### 4.3 关卡套件（石坎、台阶、篱笆）

| 件 | 规格 |
|---|---|
| 挡土墙 / 石坎 | 长 **2 m / 4 m** 两档，高 **1 / 2 / 3 m** 三档；直段、内角、外角、端头、收顶 |
| 台阶 | 宽 **1.5 m / 2.5 m**；每级 15–18 cm 高、30–35 cm 深；起步与收口件 |
| 篱笆（竹、木） | 段长 **2 m**，高 0.9–1.1 m；直段、转角、门 |
| 田埂 / 水沟 | 段长 2 m；水沟宽 0.4–0.6 m |
| 小桥 / 踏石 | 桥跨 2–4 m、宽 1.2–1.6 m；踏石间距 ≤ 0.6 m |

模块接缝要能在 1 m 网格上无缝拼接，接缝处贴图连续。

## 5. 贴图与画意

- **BaseColor 就是画**：饱满明快的大色块，加少量笔触、色斑和透明叠色；不画厚涂油画肌理。材质结构线（木纹、砖缝、叶脉）可以画，方向性投影与屏幕外描边不画进贴图。参照 [美术方向 §四](../设计方向/00-美术方向.md)。
- **明暗与描边**：范围及形态以 [美术方向 §四](../设计方向/00-美术方向.md) 为准，不把“可交互”直接等同于全物体描边。运行时实现由 [渲染落地计划 第 5 步](../设计方向/渲染/02-渲染落地计划.md) 比选；矿石与作物可保留渐变和大切面，图生 3D 输入按 [通用 v002 的 M 块](../../../美术资产/_提示词块/00-通用_v002.md) 去掉外描边与硬光照分档。
- **不烘方向光与投影**；只保留柔和的固有明暗与凹处的淡 AO。
- **色板**：按 [色彩与光线 §二](../设计方向/02-色彩与光线设定.md) 的现行约束与新首件锚点；旧道具色值、留白、L 0.24–0.80 与禁纯黑／纯白的全局门槛已退役。
- **高光克制、材质有区分**：一般哑光环境以 Roughness 约 0.8–0.9、Specular 约 0.25 作起始值；金属、晶体、釉陶按材质保留概括高光，不把所有资产刷成相同哑光。避免镜面塑料感与写实扫描噪点；最终在同框首件校准。
- **法线贴图少用**：画意靠颜色，不靠微表面。
- **细节分配 70 / 25 / 5**：70% 安静大色块，25% 结构与中等笔触，5% 焦点细节；可交互物附近的地面对比更低，目标物自身对比更高。
- 世界画面不叠纸纹（[色彩与光线 §七](../设计方向/02-色彩与光线设定.md)）。

## 7. 日夜、季节、天气

**核心原则：变化来自实时光照与可维护的参数、替换件，不能只靠全屏滤镜。**

- **日夜**：太阳与天光随时段；窗户、灯笼、炉火走 `E_` 自发光；夜间交互物可读性补偿。
- **季节**：植被叶色或替换件、地表覆盖、花期与落叶、冬季积雪层、作物可种季节、建筑道具上的局部覆盖。
- **天气**：雨雪用 Niagara，但地面与角色仍需湿润／积雪反馈；粒子不遮挡目标格、成熟作物与对话 UI。
- **岚（雾）**：用高度雾与局部雾体表现，衬托深度与冷暖；**不用浓雾掩盖接缝，不遮目标格与交互物**。
- **气氛后期**只做最终统一（曝光、色调），**不承担**亮灯、积雪、湿润、换季。关掉气氛后期，底层造型与贴图仍统一；核心描边／卡通着色若用后期实现，单独切换验证（[美术方向 §四](../设计方向/00-美术方向.md)）。

## 8. 作物与动物

作物数据与表现分离：

```text
CropID
  StageID
    VisualAsset（静态网格）
    Pivot（根部中心，各阶段一致）
    Footprint（占格）
    RandomVariant（2–3 个轻微变体）
    SeasonVariant
    HarvestReadability（成熟期不看文字也能认出）
```

- 原画造型可参考 `美术资产/作物/` 的生长阶段，旧设色不再是风格标准；新出图用 [通用 v002](../../../美术资产/_提示词块/00-通用_v002.md)，按主参考及同框首件判断。
- **画面尺寸**：成熟作物约占一格宽的 **3/4**（对标 Coral Island，2026-09-25 负责人定）。作物表 `HeightM` 仍填真实高，统一夸张倍数在项目设置 `CropVisualScale`（白萝卜实测 2.4 倍 = 0.77 格宽）。
- 现在的作物是 2D 立卡占位：画里的土堆中心按 `CardGroundAnchor` 对到格子中心。换成 3D 网格后按上面的 Pivot（根部中心）放，这两项就不用了。
- 风动优先用材质顶点动画，不做骨骼。
- **巨大作物（灵植）**是独立资产，占多格，不是普通作物放大。
- **动物全部纯 3D**（原 A-8 关闭）：家畜、村里的猫狗、神兽都走 [3D角色管线](03-3D角色与动画管线.md)。

## 9. 导入 UE

### 9.1 贴图导入预设（固定，不逐张改）

| 类型 | sRGB | 压缩 | Mip |
|---|---|---|---|
| 颜色（BaseColor） | **开** | Default（BC7） | 保留 |
| 遮罩、数据 | **关** | Masks（BC4/BC5） | 保留 |
| 法线（若有） | 关 | NormalMap | 保留 |
| UI／立绘 | 开 | UserInterface2D | 视需要 |

### 9.2 网格导入

- FBX（或 glTF）导入，单位 cm，**导入后在编辑器里量一遍真实尺寸**。
- 简单碰撞：`UCX_` 凸包或导入后生成 Box/Capsule；不用逐面碰撞。
- LOD 与 Nanite 策略见 [性能合同 §2](06-性能预算与技术合同.md)。
- 目录与命名见 [命名目录与资产卡](05-命名目录与资产卡.md)，**每件有资产卡**。

### 9.3 装配回检（DoD 的一部分）

在目标关卡、游戏机位下截图：**标准档同框** · 角色站在前面 · 角色站在后面（验淡出） · 夜晚。
任何偏离预设的手工操作**必须写进资产卡**，否则按硬门禁判失败。
