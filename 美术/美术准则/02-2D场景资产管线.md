# 2D场景资产管线

> 编号：ART-STD-003 · 版本：1.0 · 更新：2026-09-20 · Owner：场景美术（会签：TA）
> 类型：**流程规范**。从"画一张图"到"UE 里能走人的场景"的全过程。
> 前置：[相机与空间合同](01-相机与空间合同.md)（所有尺寸与倾角来自那里）。

---

## 1. 一句话原则

> **画面是画出来的，不是渲染出来的；但画面要能拆成可复用的件，不能是一张切碎的截图。**

一张漂亮的 Paintover 不是资产。资产是：**可独立替换、可复用、有 Pivot、有碰撞、有状态通道、能重新导出**的件。

---

## 2. 资产分类表

| 类型 | 例子 | 核心规则 |
|---|---|---|
| **远景板** | 天空、山、远村、海 | 少量大图、弱对比、可做视差、**不承担碰撞** |
| **地表基底** | 草地、泥地、石地 | 可拼接 Patch，**不画死完整地图** |
| **地表边界** | 道路边、田埂、溪岸 | 与基底分离，便于改布局 |
| **状态层** | 翻耕、浇水、积雪、泥泞 | **数据驱动**，不写进基础地面 |
| **建筑主体** | 房屋、商店、亭台 | 主体 / 屋顶前檐 / 入口 / 碰撞**四者分开** |
| **植被** | 树干、树冠、灌木、花簇 | 接地部分与遮挡部分分开 |
| **普通道具** | 箱、井、摊位、石头 | 底部中心 Pivot，记录交互点与碰撞 |
| **动态资产** | 作物、动物、水、旗帜 | Flipbook 或材质动画，**不绑死在场景图里** |
| **前景遮挡** | 树冠、屋檐、桥洞、矮墙 | 写深度或受控排序，可淡出但**不关必要碰撞** |

**分类决定了它走哪条子流程**，填资产卡时第一栏就是这个。

## 3. 第一阶段：Photoshop 母版

### 3.1 主画面 PSD 结构（强制）

```text
00_Guide            CameraSafeArea / GridAndScale / CharacterHeight
01_Background       Sky / Mountains / AtmosphericFog
02_Ground           BaseGround / RoadPatch / TerrainEdges / FarmStatePreview
03_Midground        BuildingBase / TreeTrunk / Props
04_CharacterRef     CharacterRender / ContactShadow
05_Foreground       RoofOrEave / TreeCrown / ForegroundOccluder
06_DynamicMasks     NightTint / Emission / Wetness / Season
07_UI               InteractionPrompt / TargetTile
08_Notes
```

- 画布 **1920×1080**，RGB 8-bit，保存时启用最大兼容性。
- 组名只用 ASCII。**同一工程内不允许两套命名并存**；沿用旧命名的过渡文件必须在资产卡里登记更名映射。
- 母版路径：`美术资产/_模板验证/PSD母版_<版本>/`。

### 3.2 绘制顺序

1. **先灰度**定角色、道路、建筑入口、交互物的视觉层级。
2. **再定冷暖与饱和度**，不先堆纹理。
3. 大色块与轮廓 → 中等结构 → **只在焦点区**加小细节。
4. 压低地面细节，保证角色、成熟作物、入口优先可读。
5. **关掉纸纹、LUT、雾层复查**：底层资产必须本身就属于同一风格。
6. 把批准的画面**拆解回可生产资产**，不直接把整张截图切成地图。

### 3.3 细节分配 70 / 25 / 5

- **70%** 大色块与安静区域；
- **25%** 结构、材质、中等笔触；
- **5%** 高对比焦点与故事细节。

地面不能遍布同强度的草叶碎石。**可交互目标附近的纹理对比要更低，目标物自身对比要更高**——这是玩法可读性，不是审美偏好。

## 4. 第二阶段：切片

### 4.1 切片清单（先列表，后切图）

PSD 定版 → 冻结图层 → 产出一份**切片清单**，每行包含：

`切片名 | 资产分类 | 世界尺寸(m) | 贴图尺寸(px) | 绘制视角 | Pivot | 是否遮挡件 | 碰撞需求 | 状态层需求`

没有清单就开始切图，一定会漏件、重名、尺寸对不上。

### 4.2 反变形（按绘制视角）

严格执行 [相机与空间合同 §6](01-相机与空间合同.md)：

- **地面族**（基底、边界、状态层、接触阴影、目标格）：纵向 **拉伸 1.556×** 后存 Master。
- **立卡片族 / 远景板**：**不变形**。

### 4.3 透明与扩边

- 无损 **RGBA**，**Straight Alpha**（非预乘）。
- 透明边缘做**颜色扩展（edge padding）**，防止 Mip 产生黑边白边。
- 图集单元之间预留 **8–16 px** 扩边。
- 源图**统一正向保存**；垂直翻转由固定导入规则处理，**不逐张临时决定**。
- JPEG 只作预览，**永远不是 Master**。

## 5. 第三阶段：导入 UE

### 5.1 导入预设（固定，不逐张改）

| 纹理类型 | sRGB | 压缩 | Mip | 备注 |
|---|---|---|---|---|
| 颜色（BaseColor） | **开** | Default / BC7 | **保留** | |
| 遮罩、数据（Mask/状态） | **关（线性）** | Masks / BC4 | 保留 | |
| Normal（若有） | 关 | NormalMap | 保留 | 本路线通常不用 |
| UI / 立绘 | 开 | UserInterface2D | 视需要 | 不进世界 px/m 规则 |

### 5.2 落位与装配

1. 按 [命名目录与资产卡 §3](05-命名目录与资产卡.md) 放进对应 UE 目录。
2. 建 Cards 网格 + 材质实例。
3. 摆放：立卡片 **Pitch −40°**、地面 **Pitch −90°**、Pivot 抬高 **+1 cm**。
4. 遮挡件设 **PDO = 110 cm**，配套碰撞代理前缘外扩 **≥110 cm**。
5. 碰撞代理用 Box/Capsule，Rotation 0°，真实世界高度。
6. 填交互锚点。
7. 填**资产卡**。

### 5.3 回检（DoD 的一部分）

**UE 截图与 PSD 同区域并排对比**，差异记入 [生产台账](../生产台账/00-首件与批次台账.md)。

> 任何偏离预设的手工操作**必须写进资产卡**，否则按硬门禁判失败。理由：手工操作在下一次重导入时一定会丢。

---

## 6. 地表 Patch 规则

- 单块贴图边长 **≤ 2048 px**（按 137 px/m ≈ 15 m）。
- 相邻 Patch 留 **8–16 px** 扩边，**必须在 UE 内拼合验收**，不能只看单块。
- 大地面**切成可流送 Patch**，禁止一张超大完整地图。
- Patch 的接缝走向尽量跟随道路、田埂、岸线这类天然边界，**不要用规则网格切在空旷草地中间**。

## 7. 材质约定

| 母材质 | 用途 | Blend | Shading |
|---|---|---|---|
| `M_Env_Card_Masked` | 全部立卡片、地面、前景遮挡 | **Masked** | **Unlit** |
| `M_Env_Card_Translucent` | 必须半透明者（水面、雾片、淡出遮挡） | Translucent | Unlit |
| `M_Env_Backdrop` | 远景板 | Masked / Opaque | Unlit |

**默认一律用 Masked。** Translucent 逐个登记、逐个批准（见 [性能预算](06-性能预算与技术合同.md)）。

母材质必须暴露的参数（前缀见 [命名规范](05-命名目录与资产卡.md)）：

| 参数 | 前缀 | 作用 |
|---|---|---|
| 时段色 Tint | `G_` | 全局日夜 |
| 环境光补偿 | `G_` | 夜间可读性补偿 |
| 湿润 / 积雪 | `S_` | 状态层混合 |
| 自发光 | `E_` | 窗户、灯笼、炉火 |
| 遮挡偏置 | `S_` | PDO，默认 110 |
| 季节变体权重 | `S_` | 见 §8 |

## 8. 日夜、季节、天气的通道约定

**核心原则：变化必须来自可维护的参数、遮罩和替换层，不能只靠全屏滤镜。**

### 8.1 日夜（至少拆成 6 条）

全局时段色 · 角色灯光 · 窗户/灯笼/炉火 Emission · 天空与远景替换或渐变 · 地面湿润反光 · **夜间交互物可读性补偿**。

### 8.2 季节（季节不是四个 LUT）

至少评估：植被叶色或叶片替换 · 地面覆盖变化 · 花期与落叶 · 冬季积雪边缘 · 作物可用季节 · 建筑道具上的局部覆盖。

### 8.3 天气

- 雨雪可用 Niagara，但**地面和角色仍需湿润/积雪/色调反馈**。
- 粒子**不得遮挡**目标格、作物成熟状态、对话 UI。
- 前景雨雪 / 世界粒子 / 远景雾**分别控制**，避免整屏同一速度和尺度。

### 8.4 全屏后期的边界

全屏 LUT 与纸纹**只做最终统一**，**不承担**窗户亮灯、积雪、湿润、植被换季。
判据：关掉全部后期层，画面仍应是同一个风格、仍能读出时段与季节的大方向。

## 9. 作物与动物

### 9.1 作物

生长阶段与动画帧**分开**：

```text
CropID
  StageID
    VisualAsset
    OptionalIdleAnimation
    RandomVariant
    Pivot
    Footprint
    SeasonVariant
    HarvestReadability
```

- 所有阶段**根部 Pivot 一致**。
- 成熟阶段在正常镜头下**无需文字也能辨认**。
- 同阶段给 2–3 个轻微随机变体，减少整齐复制感。
- 风动优先用材质或少量循环帧，**不为每个阶段做大帧表**。

### 9.2 动物

不能只写"Idle / Walk / Eat / Sleep"。至少定义：需要 4 向还是 8 向 · 哪些方向允许镜像 · 每状态帧数与帧率 · 转向/受击/互动/睡眠切换 · 脚底 Pivot 与接触阴影 · 与前景和角色的深度关系。

### 9.3 动物与岚兽的实现选型

| 选项 | 成本 | 风险 | 适用 |
|---|---|---|---|
| A. 2D 逐帧 | 帧量大（方向 × 状态） | 风格最易统一 | 普通动物、群聚小怪 |
| B. 3D 烘焙转 2D | 建模＋烘焙＋修帧 | 烘焙风与手绘风打架 | 动作复杂的动物 |
| C. 纯 3D | 与角色同管线 | 与2D场景融合需全套空间合同 | 岚兽（重要玩法实体，**倾向 C**） |

关闭批次 **V07**。关闭前不批量做动物帧表。无论选哪项，§9.2 检查项照样执行。

## 10. Blender 的边界

当前主路线是**直接分层 PSD**，不做 Blender 灰盒。Blender 是**可选辅助**，只在下列情况使用：

- 复杂建筑透视容易画错；
- 同一建筑需要多个受控方向；
- 需要 Normal / Depth / Object ID / Emission Mask / Shadow Mask；
- 需要批量预渲染树木、道具或可复用结构；
- 需要确认 3D 角色与建筑入口、工具、家具的真实尺度。

用 Blender 时：固定相机角度与焦距、输出透明无损 RGBA、保留 Blend 源与相机渲染预设。
**预渲染结果必须回 Photoshop 统一轮廓、笔触、色块、细节频率与边缘软硬**，不能直接作最终画面。

固定镜头下**不默认生产多方向**。只有玩家能旋转、或同一资产确实需要多朝向时才做 2 向 / 4 向。

## 11. 常见错误速查

| 症状 | 原因 | 对策 |
|---|---|---|
| 地面又扁又短 | 从 Paintover 直接切地面，压缩了两次 | §4.2 纵向拉伸 1.556× |
| 树和房子整体偏高，人显矮 | 卡片按字面高度建，没乘 0.766 | [相机合同 §3.3](01-相机与空间合同.md) |
| 角色走到树后，头从树前面穿出来 | 没设遮挡偏置 | [相机合同 §5.3](01-相机与空间合同.md)，PDO=110 |
| 卡片底边与地面闪烁 | 共面 Z-Fighting | Pivot 抬高 +1 cm |
| 贴图边缘有黑边/白边 | 没做颜色扩展 / 用了预乘 Alpha | §4.3 |
| Masked 边缘闪烁 | texel:pixel 远离 1:1 | 按 137 px/m 重导出运行贴图 |
| 夜晚只能靠整体压暗 | 通道没拆 | §8.1 拆满 6 条 |
| 改一处布局要重画一大张图 | 地面画死了 | §6 切 Patch，基底与边界分离 |
