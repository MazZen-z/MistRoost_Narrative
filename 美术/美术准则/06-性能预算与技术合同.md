## 1. 预算是设计约束，不是优化目标

预算写在这里的意义是：**在开始画之前就知道能画多少**。事后优化永远比事前约束贵。

## 2. v0.1 硬数字（验证庭院范围内）

| 项 | 预算 | 测量方式 |
|---|---|---|
| DrawCall | **≤ 300** | `stat RHI` |
| 角色单体三角面 | **≤ 30k** | 资产统计 |

**Cards 单材质批次合并优先**：同一母材质的卡片尽量共用材质实例与图集，让它们合批。

## 3. 纹理预算的算法

不要凭感觉估。按 [相机与空间合同 §4](01-相机与空间合同.md) 的密度反推：

```text
运行时贴图像素数 ≈ 世界面积(m²) × (137 px/m)²
```

| 内容 | 估算 |
|---|---|
| 14 m × 8 m 验证庭院地面 | 112 m² × 18.8k px/m² ≈ 2.1 Mpx ≈ **8 MB**（BC7 未压缩前 RGBA8） |
| 一栋 6 m 宽民房 | 约 1024×1024 ≈ **1.4 MB** |
| 一棵乔木（干+冠） | 约 1024×1024 ×2 ≈ **2.8 MB** |

**超预算的处理顺序（不许跳步）**：

1. 降**远景**密度（远景板本来就该低密度）
2. 降**地面**密度（地面天然在深度方向过采样 1.55×）
3. 降**特效**
4. ——到这里还不够，才允许动**角色与交互物**

角色和交互物是玩法可读性的载体，**最后才动**。

## 4. 渲染技术红线

| 项 | 规则 |
|---|---|
| 环境 Blend Mode | 默认 **Masked**。Translucent **逐个登记、逐个批准** |
| 环境 Shading | **Unlit** |
| 深度写入 | 环境卡片**必须写深度**，遮挡靠真实空间关系 |
| 排序 | **禁止**按屏幕 Y 动态改角色世界 Z |
| 曝光 | **Manual 锁定**。自动曝光会把设色冲掉 |
| 全屏 LUT | 只做最终统一，**不承担**亮灯/积雪/湿润/换季 |
| AA | 待 C-3 关闭。检查 Masked 边缘闪烁 |

### 4.1 Translucent 登记表

每一个 Translucent 材质都要有理由。允许的类别：

| 类别 | 理由 |
|---|---|
| 水面 | 需要透出水下 |
| 雾片 / 岚气 | 需要叠加 |
| 淡出中的前景遮挡 | 淡出过程必须半透明 |
| UI | 不进世界排序 |

不在表里的一律用 Masked。新增类别需 TA 批准并追加本表。

## 5. 与玩法数据的边界

> **材质和动画不能承载玩法唯一权威。**

换 Mesh、换 LOD、换动画、换显示组件，**不得改变**：物品数量、格子数据、任务进度、奖励结果。

美术资产可以表达状态（翻耕了、浇水了、成熟了），但**状态的真值在数据层**，美术读它，不写它。
