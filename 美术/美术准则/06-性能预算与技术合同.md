## 1. 预算是设计约束，不是优化目标

预算写在这里的意义是：**在开始做之前就知道能做多少**。事后优化永远比事前约束贵。

- 不透明静态件（主屋、石坎、岩石）**可以**用 Nanite；需要淡出的 Masked 件用 Nanite 有额外开销，见 P-5。
- 非 Nanite 件至少 2 级 LOD；植被 LOD 过渡用母材质的抖动过渡，不许明显跳变。

## 3. 纹理预算的算法

按 [相机与空间合同 §5](01-相机与空间合同.md) 的密度反推，不要凭感觉估：

```text
单件贴图边长 ≈ 最大可见边长(m) × 目标密度(px/m)，取 2 的幂
```

| 例 | 估算 |
|---|---|
| 3 m 门楼 × 256 px/m | 768 → **1024²** |
| 0.6 m 水缸 × 512 px/m | 307 → **512²** |
| 10 m 主屋 × 256 px/m | 2560 → 拆分为墙／屋顶两张 **2048²**，或用平铺材质 + 小贴花 |

**超预算的处理顺序（不许跳步）**：

1. 降**远景**（远山、地图边缘件）
2. 降**地面平铺密度**与宏观图分辨率
3. 降**特效**
4. ——到这里还不够，才允许动**角色与交互物**

## 4. 渲染技术红线

| 项 | 规则 |
|---|---|
| 当前渲染配置（2026-09-24 实查 `DefaultEngine.ini`） | Lumen 全局光照与反射、虚拟阴影贴图（VSM）、Substrate、DX12、无静态光照 |
| 环境着色 | 常规受光材质 + 手绘贴图；**不用 Unlit 场景** |
| Blend Mode | 默认 **Opaque／Masked**。Translucent **逐个登记、逐个批准**（§4.1） |
| 曝光 | **固定曝光或锁定范围**；自动曝光会冲掉设色 |
| 全屏后期 | 只做最终统一，**不承担**亮灯、积雪、湿润、换季（[3D场景管线 §7](02-3D场景资产管线.md)） |
| 遮挡 | 挡住角色的件走母材质淡出通道（[相机合同 §8.3](01-相机与空间合同.md)） |
| AA | 待 C-3：开放给玩家选，默认值未定 |

### 4.1 Translucent 登记表

| 类别 | 理由 |
|---|---|
| 水面 | 需要透出水底 |
| 雾片 / 岚气 | 需要叠加 |
| UI | 不进世界排序 |

不在表里的一律用 Opaque / Masked；遮挡淡出用**抖动 Masked**，不用 Translucent。新增类别需 TA 批准并追加本表。

## 5. 与玩法数据的边界

> **材质和动画不能承载玩法唯一权威。**

换 Mesh、换 LOD、换动画、换显示组件，**不得改变**：物品数量、格子数据、任务进度、奖励结果。
美术资产可以表达状态（翻耕了、浇水了、成熟了），但**状态的真值在数据层**，美术读它，不写它。
