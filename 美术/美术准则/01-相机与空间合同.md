## 1. 为什么这份合同排在所有美术规范前面

固定机位决定了三件事，美术、关卡、程序都要按它来：

- **看得见什么**：一屏多大、角色在屏幕上多高、哪些面永远看不见（背面、北向落差下方）。
- **做多细**：贴图密度只需满足这个机位下的像素覆盖，多了浪费、少了发糊。
- **地形怎么起伏**：地势朝远离镜头的方向抬升才不会挡住角色（§8）。

**所以相机不是"先随便摆一个"，相机是合同。** 代码里的默认值就是本表，改一处必须两处同改（§11）。

### 2.1 派生量（不要再另行估算）

纵向 FOV = 2·atan(tan17.5° × 9/16) = **20.11°**（半角 10.06°）；横向取景宽 = 臂长 × **0.6306**。
`cos37.5° = 0.7934`（竖直物体的屏幕压缩）、`sin37.5° = 0.6088`（地面纵深的屏幕压缩）。

| 派生量 | 近 2000 | **标准 2700** | 远 3400 |
|---|---:|---:|---:|
| 横向取景（枢轴深度） | 12.6 m | **17.0 m** | 21.4 m |
| 屏幕密度（枢轴深度，1080p） | 152 px/m | **113 px/m** | 90 px/m |
| 屏幕底边处密度（最近点，1080p / 4K） | 171 / 342 px/m | **129 / 258 px/m** | 104 / 207 px/m |
| 相机离地 | 13.1 m | **17.4 m** | 21.7 m |
| 相机在角色后方（水平） | 15.9 m | **21.4 m** | 27.0 m |
| 可见地面：角色前方（屏幕下方） | 3.9 m | **5.5 m** | 7.2 m |
| 可见地面：角色后方（屏幕上方） | 9.4 m | **12.1 m** | 14.7 m |
| 170 cm 角色屏幕高 / 占屏 | 205 px / 19.0% | **152 px / 14.1%** | 121 px / 11.2% |

> 平地时角色大约在**屏幕下三分之一**，身后看得远、身前看得近——这是鸟瞰机位的正常构图，关卡的兴趣点应放在角色"前进方向（北）"。

### 2.2 透视有多强

同屏地面最远点与最近点的视距比 **1.60 : 1**（只取决于俯角与纵向半视角，与臂长无关）。
即画面顶部的地面物体只有底部的约 62% 大。**这是完整 3D，不需要任何换算**：建模按真实尺寸，透视由相机给。

### 2.3 为什么不让玩家转镜头、为什么远近只在设置里

- 珊瑚岛同样只给固定机位与设置里的远近，理由是方向感与性能（负责人实测确认，2026-09-24）。
- 游戏内滚轮已分给快捷栏（`IMC_OnFoot`：`MouseWheelAxis → IA_HotbarCycle`）。
- 旧的滚轮缩放组件 `UMistCameraZoomComponent` **已不被玩家角色使用**（仅用户沙盒 `BP_Player_BaseValidation` 引用），属待清理遗留。

## 3. 比例与世界尺度

| 项 | 值 |
|---|---|
| 单位 | **1 UU = 1 cm**。建模、导出、导入一律真实尺寸，不做任何屏幕换算 |
| 角色 | **成人比例**（不做 Q 版）。基准身高 **170 cm**（最终值待 V04，见 §10 C-1） |

| 可耕地判定 | 关卡里摆的**田块** `AMistFarmPlot`（矩形 + 排除格 + 田面高度），运行时查表，不打射线、不看物理材质，见 [§7.1](#71-田块可耕区) |

## 4. 移动速度与取景（未关闭，见 C-2）

取景宽度决定"横穿一屏要几秒"，速度要按它定，不能照搬旧值。

| 移动速度 | 标准档横穿 17.0 m | 判断 |
|---:|---:|---|
| 220 cm/s（v3.3 为旧窄镜头定的值） | **7.7 秒** | 旧镜头只有 6.4 m 宽，新镜头下明显偏慢 |
| 400 cm/s | 4.3 秒 | 牧场类常见走速区间 |
| 800 cm/s（Mover 默认） | 2.1 秒 | 偏快 |

- 当前工程值：`BP_Chr_Player` → `CharacterMover` → `CommonLegacyMovementSettings`，v3.3 登记为 **220 / 1100 / 1400**（速度 / 加速 / 减速）；**本轮未在编辑器里复核**。
- 建议：加速度按"0.2 秒到顶速"反推（= 速度 ÷ 0.2），刹停距离保持小于 1 格。具体取值由负责人实玩决定。
- NPC 与玩家同值。

## 5. 贴图密度与尺寸档

按 §2.1 最坏情况（近档、屏幕底边、4K 342 px/m）定上限，按标准档定常用值：

| 用途 | 目标密度 | 说明 |
|---|---|---|
| 环境模型（建筑、石坎、树干、大道具） | **256 px/m**（2.56 px/cm） | 标准档 4K 底边需 258 px/m，1080p 近档底边 171 px/m，均覆盖 |
| 小件（≤1 m 的道具、作物、可交互物） | **512 px/m** | 焦点物，允许更细 |
| 地形与地表材质（可平铺） | 平铺 **512 px/m**，配**宏观变化**贴图 | 防平铺感；宏观层 ≤ 20 px/m |
| 远处山体、背景件 | 64–128 px/m | 只在远档与地图边缘出现 |
| 角色 | 见 [3D角色管线](03-3D角色与动画管线.md) | — |

- 贴图边长取 2 的幂，单张 ≤ **2048**（地形宏观图、角色主体可例外，须登记）。
- **世界尺寸决定贴图尺寸，不要反过来**：3 m 宽的门楼 × 256 px/m ≈ 768 px → 用 1024。

## 6. 关卡度量（Level Metrics）

以胶囊半径 42 cm、半高 96 cm、Mover 默认 `MaxWalkSlopeCosine 0.71`（**可走坡度 ≤ 44.8°**）与 `MaxStepHeight 40 cm` 为物理上限；**设计值一律比物理上限保守**：

| 项 | 设计值 | 说明 |
|---|---|---|
| 主路坡度 | **≤ 15°** | 日常往返路线 |
| 坡道（无台阶） | **≤ 25°** | 超过即改台阶 |
| 台阶 | 踏高 **15–18 cm**、踏深 **30–35 cm**，宽 **≥ 150 cm**（主路 ≥ 200 cm） | 每 10–12 级设一平台 |
| 台地落差（石坎、挡土墙） | **0.8–3.0 m**，不可走，用台阶/坡道连接 | 落差朝向见 §8.1 |
| 主路宽 | **200–300 cm**（2–3 格） | 两人并行 + 工具动作不擦边 |
| 次路宽 | **120–160 cm** | — |
| 最小通行净宽 | **≥ 100 cm** | 胶囊直径 84 cm + 余量 |
| 门洞 | 宽 **≥ 100 cm**、高 **≥ 210 cm** | 成人比例 |
| 篱笆 / 矮墙 | 0.8–1.1 m | 不挡视线，可作边界 |
| 田块 | **内部必须水平**，格线对齐世界 1 m 网格；田块之间可有高差 | 格子按地面射线判定，坡上无法耕作 |
| 溪流 | 可涉水段深 ≤ 30 cm；不可涉段配桥或踏石 | 取水点须有可站立的岸 |

## 7. 碰撞与交互

- 碰撞用简单代理（Box / Capsule / 凸包），**不用逐面碰撞**；地形用 Landscape 自身碰撞。
- 树冠、屋檐等"镜头与角色之间"的遮挡件**无碰撞或只有很薄的碰撞**，靠 §8.3 淡出；淡出不关碰撞。
- 可交互物（门、床、出货箱、水缸、取水点、作物）有交互锚点，命名见 [命名目录与资产卡 §7](05-命名目录与资产卡.md)。
- `PM_Env_Soil`（Soil 表面）只给脚步声、落地特效用，**不决定能不能锄**。

### 7.1 田块（可耕区）

对标 Coral Island：可耕格是编辑器里配出来的数据，运行时只查表（Stairway Games 2020-04 开发日志）。本项目把数据放在关卡里的田块 Actor 上。

- **摆放**：`AMistFarmPlot` 的位置 = 田的西南角（松手自动对齐 1 m 格），高度 = 田面；大小拖视口里的对角角点或填 `SizeInTiles`。不规则的田拼几块，或填 `ExcludedTiles`。
- **归属**：生成脚本只在关卡里还没有田块时铺第一次，之后田块归编辑器管，脚本不覆盖。`PlotId` 全局唯一，改名会丢这块田的格子状态。
- **地形改了之后**：选中田块点「检查地面」，高差超过 2 cm、坡度超过 5° 或探不到地面的格标红（容差在项目设置「MistRoost - Farm Grid」的 Plot Check）；修法是拖田块、点「对齐田面高度」或「排除问题格」。Map Check 也会报。
- 同一处平面位置只归一块田，田不能上下叠放。
- 野外挖掘点、树、石头这类工具目标**不放田块**，另走工具目标层，统一入口 `UMistToolUseComponent::CanUseHandItemOnTile`（[程序设计准则 §6](../../../MistRoost/程序设计准则.md)）。

## 8. 镜头遮挡规则（本机位最重要的关卡约束）

### 8.1 地势朝北抬升

镜头从南向北俯看。**地势朝北（远离镜头）抬升**时，台地的挡土墙面朝镜头、看得见、不挡人；**朝北下降**的落差会把下方地面藏起来：

| 落差高度 | 墙根后被遮住的地面深度（屏幕中线 / 屏幕上沿视线） |
|---:|---|
| 0.5 m | 0.65 m / 0.97 m |
| 1.0 m | **1.30 m** / 1.93 m |
| 2.0 m | 2.61 m / 3.85 m |
| 3.0 m | 3.91 m / 5.78 m |

**规则**：可走区、田块、交互物**不得**紧贴高于 0.5 m 的朝北落差的下方；必须有时，把被遮住的那一条做成不可走的植被带。东西向落差从侧面看，不受此限。

### 8.2 高物件

- 屋顶、树冠、檐廊、竹林这类高于角色头顶的件会挡住角色——**允许**，由 §8.3 淡出处理。
- 挡板式大体量（整面山壁、厚墙）在角色与镜头之间时不淡出，关卡上避免这种布局。

### 8.3 遮挡淡出（已实装）

| 项 | 值 |
|---|---|
| 探测 | `UMistOcclusionFadeComponent`：从相机向角色做球形扫描，半径 35 cm，高度 −40 / +60 cm 两条，每 0.05 秒 |
| 淡出 / 淡入 | 0.25 / 0.4 秒 |
| 通道 | Custom Primitive Data 或 Per-Instance Custom Data 第 **0** 位（`CustomDataIndex = 0`） |
| 材质 | 环境母材质 `M_Env_Master3D`：抖动淡出，最多淡到 **30%** 可见（`MaxOcclusionFade 0.7`），阴影不跟着淡 |
| 排除 | Actor 带 Tag `NoOcclusionFade` 的不淡 |
| 不支持 | 地形（Landscape）不淡出——所以 §8.1 的地势规则必须遵守 |

> 第三方包自带材质不接这个通道，**不会淡出**；接入正式关卡前要换到母材质或补接通道（见 [3D场景资产管线](02-3D场景资产管线.md)）。

## 9. 农田格显示规则（已实装）

- **何时显示**：手持锄头 / 水壶 / 种子，且角色周围 **3×3 格**内有田块的格。出生时不常驻。
- **有效 / 无效色**：手上的东西对这一格有事可做才是有效色（`UMistToolUseComponent::CanUseHandItemOnTile`）。
- **显示几格**：默认只亮目标一格；工具升级后按 `DT_ToolDefs` 的 `AreaSize` 同时亮 X×Y 格，与工具实际作用范围共用 `FMistToolDef::GetAreaTiles`。
- **够得着的范围**：`ReachRadiusTiles = 1`（角色周围 3×3）。键鼠时鼠标所指的格被夹进这个范围；**手柄时用角色面前那一格**，不看停在屏幕上的鼠标（按最近一次输入的设备判定，与[操作与输入方案](../../策划/游戏玩法/11-操作与输入方案.md)一致）。

### 12.1 作废的 v3.x 数值（不得再引用）

FOV 30° · Pitch −50° · 臂长 900–2200 / 默认 1200 / 滚轮缩放 · 299 px/m 屏幕密度 · Master 400 / 运行时 300 px/m 卡片密度 · 卡片高度 ×0.643 · 地面反拉伸 ×1.305 · 遮挡偏置 K = 130 cm（PDO） · 立卡片 Pitch −50° / 地面 −90° · 卡片 Pivot +1 cm · 地表 Patch 上限 6.8 m · 验证庭院 11.8 × 6.6 m。

> 技术发现仍然有效、换路线也不变的一条：**UE 的 Pixel Depth Offset 只能把像素往远推**（引擎钳制为 `max(SceneDepth + PDO, SceneDepth)`），不能用来把物体"拉近"。
