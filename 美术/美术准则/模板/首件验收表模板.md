## 三、硬门禁

### 空间与比例
- [ ] 相机参数已记录且稳定
- [ ] 角色与建筑、门洞、台阶比例可信
- [ ] 真实尺寸建模，导入后量过
- [ ] 走到屋顶、树冠后面会淡出，不闪、不关碰撞
- [ ] 不漂浮，阴影方向正确
- [ ] 可走区没被朝北落差挡住

### 风格
- [ ] 角色与场景像同一幅画
- [ ] 交互物与成熟作物可读
- [ ] 夜晚不只靠压暗
- [ ] 季节不只靠换色
- [ ] 关掉后期后仍是同一风格

### 技术
- [ ] Masked 边缘无不可接受闪烁
- [ ] 无未记录的手工操作
- [ ] 状态层未画进基础地面
- [ ] 会挡住角色的件带淡出通道
- [ ] 面数、贴图密度在合同内

### 可维护
- [ ] 源文件可重建
- [ ] 资产卡填完，命名通过
- [ ] 上一批 DoD 已关闭
