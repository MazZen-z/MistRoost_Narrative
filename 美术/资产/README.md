# 美术资产索引

> 本目录管理现存参考资料和新资产交付合同，不是完整运行资产源库。

## 三个目录，三种效力（不要混用）

2026-09-21 曾将 `美术资产/` 作为确定资产目录。**2026-10-01 风格基准更新后，目录位置本身不能证明资产符合新方向**：既有资产保留生产记录，是否可作新批次依据需看其明确批准范围与当前验收状态。

| 目录 | 性质 | 能不能当依据 |
|---|---|---|
| **`美术资产/`**（工作区根） | DCC 源、导出、资产卡、旧批次与新候选 | 仅已通过当前方向验收的资产可在其批准范围内作依据；**不按目录自动认定风格与数值权威** |
| `Docs/美术/资产/概念参考/`（本目录） | 概念参考，含 AI 生成图 | **不能。**只定氛围，不定规格，也不代表方向已批准 |
| `下载资产/`（工作区根） | 第三方原始包 | **不能。**未验收，不得直接进正式内容 |
