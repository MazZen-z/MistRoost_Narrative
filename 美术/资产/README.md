## 三个目录，三种效力（不要混用）

2026-09-21 负责人确认：**`美术资产/` 下存放的是「确定资产」**——已经定案、可以直接作为生产依据的东西。

| 目录 | 性质 | 能不能当依据 |
|---|---|---|
| **`美术资产/`**（工作区根） | **确定资产**：DCC 源、导出、资产卡 | **能。风格与数值以此为准** |
| `Docs/美术/资产/概念参考/`（本目录） | 概念参考，含 AI 生成图 | **不能。**只定氛围，不定规格，也不代表方向已批准 |
| `下载资产/`（工作区根） | 第三方原始包 | **不能。**未验收，不得直接进正式内容 |
