## 校验与同步

```bash
# 在文档仓库根（Docs）运行，Node.js 18+，无需npm依赖或网络
node 工具/validate-docs.mjs
# 完整同级工作区校验（包括程序链接与根层镜像）
node 工具/validate-docs.mjs --workspace
# 修改项目总准则正本后，按需同步到父目录入口
node 工具/sync-root-guideline.mjs --check
node 工具/sync-root-guideline.mjs --write
```

本地验证与GitHub Actions是不同证据；工作流只有推送后才运行。本轮不默认commit／push，不修改远端分支保护。迁移映射、备份边界、检查结果与后续提交步骤见[迁移验收报告](项目管理/mcp-3D文档迁移与验收.md)。
