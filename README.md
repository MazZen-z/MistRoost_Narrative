## 同级工作区布局

```text
_My_Game_Project/
├─ 游戏制作准则.md      文档正本的同字节入口副本
├─ Docs/               本仓库（不再套一层Docs）
├─ MistRoost/          UE代码仓库，文档仅保留程序设计准则.md
├─ 美术资产/            正式DCC源／导出／本地资产库
└─ 下载资产/            第三方原包
```

[程序设计准则（同级工作区链接）](../MistRoost/程序设计准则.md)属于代码仓库。本仓库单独克隆或在GitHub阅读时，相邻仓库文件无法直接由相对链接访问，请打开上方程序仓库并按`程序设计准则.md`、`Tools/…`路径查找；尚未提交的本地文件不会自动出现在GitHub。此类链接由校验器单列为跨仓依赖。

## 校验与同步

```bash
# 在文档仓库根（Docs）运行，Node.js 18+，无需npm依赖或网络
node 工具/validate-docs.mjs
# 完整同级工作区校验（包括程序链接与根层文件）
node 工具/validate-docs.mjs --workspace
```

本地验证与 GitHub Actions 是不同证据；工作流只有推送后才运行。不默认 commit／push，不修改远端分支保护。
