# 玩法 · 供奉与技能

> 状态：🌱 草稿 · 最后更新：2026-09-09
> 相关：[游戏总览](../00-游戏总览.md) · [种田](02-种田.md)

## 原始设想（来自笔记）

- **供奉**：通过向**神龛供奉**（**完成一定季节目标**）获得**技能点提升**，类似「静谧田园」。

## 结构化拆解

- **循环**：季节目标（如某季产出/收集/建设指标）→ 向神龛供奉 → 获得技能点 → 解锁/强化能力。
- **气质**：神龛 = 中式民俗信仰载体（土地神/山神/海神…），契合近海山谷背景与 [岚气](01-岚气与岚兽.md) 世界观。
- 💡 技能树候选方向：种田 / 畜牧 / 采矿战斗 / 钓鱼 / **符咒**（画符效率与品质）/ 社交。
