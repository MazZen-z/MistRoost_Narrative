## 一、岚气：灵气体系的世界观（来自笔记「总结」）

用一套稳定的说法给「灵气体系」定名，让玩法名词能被玩家快速读懂：

- **以岚养灵**：灵气不是凭空出现，而是像「雾岚」一样在环境里**生成、沉降、被收集**；
  玩家通过生活与经营让环境中的灵性更浓，从而支持灵气相关机制（资源 / 成长 / 供给）。
- **以岚育兽**：岚兽培育的关键变量来自「**岚气 / 灵气的环境状态**」；
  玩家不只是喂食，更是在用岚气**塑造与驯养**它们的成长节奏与品质。
- **岚气滋养，岚兽相随**：强调「**氛围 → 滋养 → 关系**」的连续感——
  当岚气稳定、岚兽状态良好，玩家的陪伴与亲密关系也随之增强。

> 整体体验贴合基调：**温馨惬意为主、略带紧张张力**。

### 岚气的玩法钩子（💡 待细化）
- 岚气是**环境状态量**（某地/某田/某棚的「灵性浓度」），受玩家经营影响。
- 可能的产出/消耗：滋养 [灵田](02-种田.md) 与岚兽成长；作为画 [符咒](00-核心-符咒系统.md) 的「灵墨」。
- ❓ 岚气如何被玩家感知与「收集」（可视化雾气？采集点？季节波动？）待定。

## 二、岚兽：有元素之力的特殊动物

### 概念
- **来源**：普通动物在**达成某条件时有概率进化**为岚兽，或**孵化时直接概率进化**（详见 [畜牧](03-畜牧.md)）。
- **本质**：具备一定**元素之力**的特殊动物。示例——
  - **鸡**：两个特殊分支 →「**水形态**的鸡」与「**土形态**的鸡」。
- **定位**：接近 **NPC / 伙伴**，而不只是产出机器。

### 能力：帮工
- 可协助完成牧场内的一些任务，例如：**浇水**（水形态）、**挖掘**（土形态）。
- **每天有工作时间限制**（不是无限劳力）。

### 关系：主动亲密
- 会**主动向玩家发起亲密指令**：贴贴、邀请玩游戏等。
- **小游戏**：岚兽每天有概率在**被摸时**主动邀请玩家一起玩小游戏 →（暂定）**音游**。

### 词条属性
- 岚兽带有**词条属性**，覆盖**工作 / 战斗**等维度（与 [矿洞战斗](05-矿洞与战斗.md) 的岚兽协战相通）。

## 三、岚气的两面：岚兽 vs 妖魔化（已定）

岚气对动物有**正反两条路径**，这是世界观与主线威胁的关键：

| | 触发 | 结果 | 立场 |
|---|---|---|---|
| **正向** | 正常岚气滋养 | 普通动物 → **岚兽**（元素之力、伙伴/帮工）| 玩家的伙伴 |
| **负向** | **失控岚气** | 普通动物 → **妖魔化**（黑化、更强力的怪物）| 敌人 |

- **妖魔化**（玩家原话）：失控岚气会导致普通动物「**妖魔化**」，可理解为**更强力的黑化怪物**。
- **失控岚兽 = 妖魔化的强敌**：矿洞中作为**类 Boss** 出现；战斗胜利后可**净化**（去除妖魔化）并**驯服/契约**，
  转化为玩家一方。是 [契约符](00-核心-符咒系统.md) 的施展对象。
- 预计 Boss 级不超过**十只**（详见 [矿洞与战斗](05-矿洞与战斗.md)）。
- 与主线「[妖魔气息 / 岚气失控](../剧情/00-主线剧情.md)」直接呼应：**妖魔气息 = 失控岚气，其表征就是动物妖魔化。**
