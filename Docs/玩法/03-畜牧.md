# 玩法 · 畜牧

> 状态：🌱 草稿 · 最后更新：2026-09-09
> 相关：[岚气与岚兽](01-岚气与岚兽.md)（岚兽的能力/亲密/词条详见此文） · [种田](02-种田.md)

## 原始设想（来自笔记）

- **普通畜牧**：与牧场物语 / 星露谷物语系列**基本一致**。
- **岚兽概念由剧情触发**：普通动物在**达成某一条件**时有概率进化为岚兽，或**孵化时直接概率进化**。
- **岚兽栏位**：每个畜棚 / 鸡舍有**固定的岚兽栏位**，例如：
  - 初级鸡舍：只能供养 **1 只**
  - 中级：**2 只**
  - 顶级：**3 只**

## 结构化拆解

### 普通畜牧循环（对标星露谷/牧场物语）
- 建造/升级畜棚与鸡舍 → 购入动物 → 喂养、清洁、亲密 → 产出（蛋/奶/毛等）→ 加工/售卖。
- 💡 具体动物种类、饲料、产出链待列表（可沿用同类成熟设计再中式化）。

### 岚兽进化（本作特色）
| 要素 | 设想 |
|---|---|
| 触发方式 A | 普通动物**达成某条件**后**概率**进化 |
| 触发方式 B | **孵化时**直接**概率**进化 |
| 前置 | 「岚兽」概念**由剧情解锁**后才开放 |
| 容纳 | 受畜舍**岚兽栏位**上限约束（初 1 / 中 2 / 顶 3）|

> 岚兽本身的**元素分支 / 帮工 / 亲密 / 音游小游戏 / 词条**统一记录在
> [岚气与岚兽](01-岚气与岚兽.md)，本文只负责「**畜牧循环 + 进化入口 + 栏位**」。
