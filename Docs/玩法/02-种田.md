## 原始设想（来自笔记）

- **灵田概念**：有「**灵田**」的概念，会**逐步解锁**；灵田的产出可以**帮助岚兽成长**。
- **前期普通田地**：前期是普通田地，用于种植**基础作物**，做**料理 / 售卖 / 送礼**等。
- **工业附加玩法**：**腌菜 / 酿酒 / 蜂房**等，类星露谷物语（详见 [工具与生产加工](07-工具与生产加工.md)）。
- **料理**：以**带额外 Buff 的料理**居多。

## 结构化拆解

### 田地两层结构
| 层级 | 解锁 | 产出用途 |
|---|---|---|
| 普通田地 | 前期即有 | 基础作物 → 料理 / 售卖 / 送礼 |
| 灵田 | 逐步解锁 | 特殊产出 → **滋养岚兽成长**（与 [岚气](01-岚气与岚兽.md) 联动）|

### 与符咒的联动
- **降雨符** → 免去人工浇水 / 满足作物需水 / 推动天气（见 [符咒系统](00-核心-符咒系统.md)）。
- 💡 候选：丰收符、催熟符、防虫/防妖符等（待定）。

### 料理
- 定位：**功能性 Buff 料理**为主（战斗前、下矿前、社交前的增益）。
- 💡 与 [矿洞战斗](05-矿洞与战斗.md)、[亲密系统](01-岚气与岚兽.md) 形成正循环。
