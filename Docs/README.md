## ✅ 已拍板的关键决定（2026-09-09）

1. **符咒 = 便利玩法层。** 不是「囤积型稀缺资源」，而是**为玩家提供便捷的消耗性道具**
   （对标星露谷的炸弹 / 梯子），用手绘符咒的形式表现。由玩家在**小游戏里亲手画**，
   **消耗岚气 + 一定资源**。四类用途：**传送 / 生活帮助 / 战斗帮助 / 资源采集帮助**。
   与岚气的关系＝**岚气是灵墨，符咒是用岚气写成的一次性便利术**。详见 [符咒系统](玩法/00-核心-符咒系统.md)。
2. **术语统一为「岚兽」**（弃用「灵兽」）。
3. **威胁 = 失控岚气 → 动物「妖魔化」。** 失控岚气会让普通动物妖魔化（黑化、更强力的怪物）；
   「妖魔气息」即失控岚气。岚气对动物有正反两路：正常→[岚兽](玩法/01-岚气与岚兽.md)（伙伴），失控→妖魔化（敌人）。
4. **背景地形 = 架空 + 重庆式山地 + 海滩**（不强绑真实朝代/地名；命名待定）。
5. **实现优先级：先做基础种田框架**（移动+格子+计时产出），**符咒后置**为可嵌入 Feature。
6. **新增两个底层系统**：[运气系统](框架/00-运气系统.md)（概率闸口）、[计时与产出](框架/01-计时与产出系统.md)（时间→产出抽象）。
