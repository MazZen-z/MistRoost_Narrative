## 主轴（来自笔记「主线剧情」）

- 主角**从小在村子长大**；玩家操控的是**成年后**的主角。
- 一次**上山砍柴时跌落山谷**，被村中**猎户的狗**找到。
- 进村后，**村长严肃告知**：主角已被**失控的岚气感染**，需要**被隔离**，
  并让主角去**管理一座荒芜的庭院**。
- 谁知庭院里藏着**净化失控岚气的秘密**。
- **主线前几天**：主角可**上山学习净化能力**。
- 之后：在**日常生活中**逐步解开**村子的秘密**、以及**岚气失控的原因**。
- 结局：**解除危机，享受田园生活**。

> **剧情节奏参考「静谧田园」。**

## 威胁定义（已定）

- 主线概括为「**探寻妖魔气息**」。**妖魔气息 = 失控岚气**：失控岚气会让普通动物**妖魔化**
  （黑化、更强力的怪物，详见 [岚气与岚兽](../玩法/01-岚气与岚兽.md)）。
- 主角自身「**被失控岚气感染**」→ 需隔离 → 却在庭院里发现**净化**之法，正是化解这一威胁的钥匙。
- 主线**比重较少、线性、碎片化**；核心仍是生活模拟，推进「随玩家心情来」。

## 结构化梳理（叙事节点）

| 阶段 | 事件 | 玩法解锁/锚点 |
|---|---|---|
| 序 | 跌落山谷 → 被猎户的狗发现 → 进村 | 引出 [猎户与大黄](01-剧情碎片.md) |
| 起 | 村长告知「被岚气感染 / 隔离」→ 接管荒芜庭院 | 家园/农场起点 |
| 承（前几天）| 上山**学习净化能力** | 开启 [岚气/净化](../玩法/01-岚气与岚兽.md) 相关玩法 |
| 转（日常中）| 碎片化揭开**村子秘密 + 岚气失控之因** | 穿插 [矿洞失控岚兽](../玩法/05-矿洞与战斗.md) |
| 合 | **解除危机** → 回归田园 | 结局与后续 sandbox 生活 |
