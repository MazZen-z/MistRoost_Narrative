# 岚栖 / MistRoost · 游戏总览

> 状态：🌱 草稿 · 最后更新：2026-09-09
> 相关：[符咒系统](玩法/00-核心-符咒系统.md) · [岚气与岚兽](玩法/01-岚气与岚兽.md) · [主线剧情](剧情/00-主线剧情.md) · [美术方向](美术/00-美术方向.md)

## 一句话定位

一款 **UE 制作的 2.5D 手绘风格中式种田生活模拟游戏**：以星露谷物语式的生活经营为骨架，
以**玩家手绘符咒**为核心差异，围绕种田、畜牧、钓鱼、矿洞、岚兽与轻量剧情，
讲述一个近海山谷里「以岚养灵、与兽相随」的惬意故事。

## 设计支柱（Pillars）

1. **生活模拟为主体。** 核心体验是经营与生活，剧情推动「随玩家心情来」，不逼迫、不赶路。
2. **符咒是灵魂差异。** 一套「便利玩法层」，让玩家**亲手画符**来省去繁琐操作（浇水、敲矿…），
   对标星露谷的炸弹/梯子——把「便利」变成有仪式感的创造行为（消耗岚气+资源）。
3. **岚与岚兽的温柔陪伴。** 岚气滋养环境，岚兽像伙伴/半 NPC 一样主动亲近玩家。
4. **中式田园气质。** 手绘渲染、静谧惬意，区别于日式同类的清新，走更「中式」的质感。
5. **近海 = 全球化窗口。** 靠海的地理让不同国家的人来贸易/交流，天然支持多元内容与海外宣发。

## 基调（Tone）

> **温馨惬意为主，略带紧张张力。**（源自笔记「总结」）

- 主体是松弛的田园经营；
- 「妖魔气息 / 岚气失控」提供恰到好处的悬念与目标感，但**比重轻、线性、碎片化**。

## 背景设定

- **架空的类中式世界**（偏架空，**不强绑真实朝代**，给设计留自由度）。
- **地形（已定方向）**：参考**重庆式山地**——山城、立体高差、坡地、层叠院落的空间感；**外加海滩地图**。
  近海（山谷 + 海岸）→ 有**不同国家的人来贸易或交流**（服务全球化宣发，也丰富角色/商品/事件）。
- **地名 / 村名待定** ❓（地形母题已定，命名与建筑风格细化在 [美术方向](美术/00-美术方向.md)）。
- 世界观灵性说法：**「以岚养灵 / 以岚育兽 / 岚气滋养，岚兽相随」**（详见 [岚气与岚兽](玩法/01-岚气与岚兽.md)）。

## 美术方向（摘要）

- **2.5D**：3D 场景 + **2 头身角色**，整体**手绘渲染**。
- 参考「**静谧田园**」的静谧田园气质，但**更偏中式**（参考偏日式，需做中式化改造）。
- 详见 [美术方向](美术/00-美术方向.md)。

## 技术与工程现状

- 引擎：**Unreal Engine**（`MistRoost.uproject`，模块 `MistRoost`，依赖 UMG / AIModule，启用 StateTree / GameplayStateTree）。
- 当前工程基于 **UE 俯视角（Top-Down）示例项目**（`Content/TopDown`、`Variant_Strategy`、`Variant_TwinStick`）。
  模板为**点击移动**（NavMesh）——种田游戏建议改**直接移动**，详见 [实现路线](框架/02-技术架构与实现路线.md)。
- 现阶段：文档归档已完成，**进入实现规划**——先做「移动 + 种田」MVP（见 [实现路线](框架/02-技术架构与实现路线.md)）。
- 长期约定：**边做边同步文档**（功能 / 剧情 / 数值 / 大模块）。

## 目标与差异化总结

- **对标框架**：星露谷物语 / 牧场物语（生活经营 + 探索）。
- **风味参考**：静谧田园（节奏与静谧感）。
- **不可替代的记忆点**：**亲手画的符咒**（把「便利」变成玩家的创作）+ **中式岚与岚兽**的温柔陪伴。
