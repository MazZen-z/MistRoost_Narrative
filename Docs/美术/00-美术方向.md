## 一、目标一句话

**2.5D 手绘、斜俯视的中式静谧田园**：3D/伪 3D 场景 + **2 头身角色**，
画面像一幅会呼吸的工笔/水墨田园画，**氛围光**丰富、**雾岚**缭绕（呼应「岚栖」），
温馨为主、**略带暗涌的紧张感**。

> ⚠️ **差异化提醒（重要）**：该作前提与我们的主线**高度雷同**——
> 「主角在山中迷路/受伤被村民救助 → 获得破旧小屋 + 荒废庭院去开垦」。
> 我们要**有意识地拉开差距**：靠 **符咒 + 岚气/岚兽 + 妖魔化 + 中式** 立住原创性，
> 剧情细节（岚气感染/隔离、净化秘密、近海多国贸易）也要走自己的路。参考它的**美术与节奏**，别照搬它的**设定骨架**。

## 三、参考图拆解（玩家提供的 4 张截图）

**1）秋日庭院（黄昏/夜）**
- 斜俯视等距视角；**手绘厚涂**背景；红枫 + 黄银杏满地落叶。
- 日式瓦顶木屋 + 障子拉门 + 石垣挡墙；**强氛围光**（丁达尔光束、斑驳树影）。
- 2 头身角色立于院中；整体**幽静、微暗、怀旧**——恐怖底色的来源。

**2）白日农场**
- 稻田 + 翻耕垄沟（萝卜/白菜/卷心菜）；奶牛（黑白+棕）、绵羊；木栅栏、牛奶罐。
- 明亮、翠绿、生活气；**同一套等距 + 手绘**语言。

**3）餐馆对话场景**
- 室内等距场景（吧台/厨师/桌椅）+ **前景大幅精细立绘**（花衬衫老者、两名年轻角色）+ 日文对话框。
- 关键：**双层角色表现** ——世界内是 2 头身小人，**对话时切精细全身立绘**。

**4）白日农舍**
- 木构瓦顶农舍；菜圃（萝卜/白菜/卷心菜）+ 花圃（红郁金香/白雏菊）+ 稻田 + 石板路 + 水井。
- **雾岚丝缕** + 丁达尔光；氛围与生活感兼具。

### 由此确定的美术语言
- **相机**：固定**斜俯视 / 等距**（约 30–45°），不自由旋转。
- **渲染**：**手绘厚涂 / 工笔感**背景，笔触柔和、植被层次丰富、**季节色**强烈。
- **光影**：重**氛围光**（光束、斑驳、雾气、冷暖对比），敢用偏暗调营造张力。
- **角色**：世界内 **2 头身**；**对话切精细立绘**（建议我们沿用这套双层表现）。
- **UI**：克制、留白，文本框简净。
